# Glossary UX & Content Repair — Sprint 1

## 범위와 기준선

- 시작 기준선: `24e52f0` (`main`, 원격과 동기화된 깨끗한 작업 트리)
- 이번 스프린트는 사전 전체 재작성 대신, 용어 탐색 흐름과 우선순위 높은 상세 설명을 고치는 범위로 한정했다.
- 상세 설명 보유 항목은 84개, 인덱스/성숙화 대상은 430개다. 남은 항목을 한 번에 확장하지 않았다.

## 발견 UX

- 용어 화면을 `용어 찾기`로 바꾸고, 한국어·영어·약어 검색 안내와 예시를 추가했다.
- 첫 화면에는 자주 찾는 핵심 용어만 보여 주며, 검색 또는 필터를 사용하면 전체 사전에서 결과를 찾는다.
- 분야·과정·미션·중요도·상세 설명·웹툰 필터는 접힌 `필터` 안으로 옮겼다.
- 빈 결과는 자연스러운 다음 행동 안내를 제공한다.
- `Pilot` 같은 내부 표기를 웹툰 화면과 홈 화면에서 제거했다.
- 검색 점수 로직에서 일치하지 않는 핵심 용어가 결과에 섞이는 회귀를 발견해 수정하고 테스트를 추가했다.

## 개념 연결 학습 형식

| 연결 | 이번 학습 형식 |
| --- | --- |
| AJAX / XHR / Fetch | 방식과 도구를 구분하는 계층 + 실제 요청 흐름 |
| Callback / Promise / async-await | 같은 작업을 세 가지 코드 형태로 비교 |
| Event family | 클릭부터 핸들러 실행까지의 흐름 + `preventDefault()`와 `stopPropagation()` 구분 |
| HTML / DOM | HTML 소스에서 DOM 구조가 만들어지는 흐름 |
| SPA / MPA | 링크 클릭 뒤 문서/화면 전환을 나란히 비교 |
| var / let / const | 실전 선언 코드와 스코프·재선언·재할당 비교표 |

기존 공통 관계 도식은 본문을 방해하지 않도록 각 페이지 마지막의 `기술 관계 보기`에 접어 두었다. 사용자에게 보이는 제목과 요약도 자연스러운 한국어로 정리했다.
