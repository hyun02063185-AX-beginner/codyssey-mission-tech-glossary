### 기본 도구와 보조 도구

- **항상 노출:** 세 가지 보기, 확대·축소, 읽기 크기·전체 보기, 개념 설명 버튼, 탐색 도구 버튼. PC 두 폭은 한 줄, 모바일은 두 줄이다. 기본 도구는 페이지 스크롤 중에도 sticky로 접근 가능하다.
- **탐색 도구 안:** 통신 흐름, 검색, 보충 개념, 목록 선택, 영역 이동, 전체 지도 초기화. 기능을 유지했다. 도구는 지도 높이를 줄이지 않는 overlay이며 목록·검색·흐름 선택 뒤 접힌다.
- **활성 상태:** 탐색 도구를 접어도 선택한 흐름의 이름·A/R/W 단계와 보충 켜짐·검색어가 기본 도구 아래에 표시된다. 버튼에도 활성 항목 수가 표시된다.
- **지도 아래:** 짧은 조작 문장과 `사용법·관계 범례` 펼침만 남겼다. 영역 이동과 목록은 탐색 도구로 옮겼다.
- **지도 크게 보기:** 화면 내부 집중 모드로 전환한다. 선택·강조·확대 배율을 유지하며 설명 패널도 사용한다. 일반 보기 버튼으로 복귀하고, 패널 밖에서는 Escape로 복귀할 수 있다. 기본 화면의 662px 캔버스를 먼저 확보했다.

### 크기 변경과 카메라

- 개념지도 페이지에만 `#root` 높이 자동·overflow visible 정책을 적용한다. 집중 모드에서만 내부 전체 화면과 body 스크롤 잠금을 사용한다. `.mission-concept-map`이 사라지면 정책도 적용되지 않는다.
- PC는 창 높이를 기준으로 충분한 캔버스 높이를 배정하고, 작은 높이에서는 최소 약 560px 공간을 페이지 스크롤로 확보한다. 모바일은 `clamp(380px,65svh,640px)`로 조정한다. 집중 모드는 남는 내부 높이를 채운다.
- 크기 변경 때 **Fit은 다시 Fit**, **수동 확대는 배율 유지**, 노드 선택은 패널에 가려지지 않게 위치를 보정한다. 보기·필터·흐름을 바꿀 때는 기존 선택 정책에 따라 시점을 계산한다.
- 패널의 실제 layout offset과 크기로 가용 영역을 계산한다. 모바일 하단 시트와 sticky 도구가 선택 노드를 가리지 않는지 브라우저에서 확인했다. 패널 입장 애니메이션의 transform은 크기 계산에 사용하지 않는다.
- ResizeObserver는 실제 치수가 바뀔 때만 상태를 갱신한다. 지도 크기가 변하지 않는 도구 열기·닫기는 카메라를 바꾸지 않는다. 크기 변경 후 `viewBox`가 안정되는지 검사했다.
