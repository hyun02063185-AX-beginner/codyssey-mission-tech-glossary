## 교육 내용 수정

**R4 · I10의 레인 상자가 학습 정보를 보여 주지 않음 (S1-4·S6-1·S6-2)**
`overview`에서 각 단계의 레인 상자가 “현재 단계”/“전체 흐름의 주체”만 표시합니다. 캡션이 약속한 “그 단계에서 오가는 데이터”가 보이지 않습니다. 아래 내용을 단계별로 보여 주고, 그 단계에 할 일이 없는 주체는 흐리게만 처리하세요(채움 문구 없음).

| 단계 | 사용자 | Git | Python | 외부 AI | 오가는 데이터 |
| --- | --- | --- | --- | --- | --- |
| 1 명령 | `python3 main.py commit` 입력 | — | `argparse`로 `commit` 읽기 | — | 명령줄 글자 → `args.command` |
| 2 변경 읽기 | — | `status`·`diff`·`diff --cached` 결과를 stdout으로 | `subprocess`로 실행, Git 문맥 만들고 검사 | — | Git 출력 → Git 문맥(이번 실행 535자) |
| 3 요청 | — | — | HTTPS POST: 헤더에 키, JSON 본문에 `system`+`user` | 요청 받아 초안 작성 | 요청 JSON |
| 4 응답·검증 | — | — | `content` 꺼내 형식 검사 → stdout 초안, stderr 요청 횟수 | 응답 JSON 반환 | 응답 JSON → 초안 |
| 5 판단 | 초안을 diff와 비교, 커밋·push·PR 직접 | — | — | — | 초안 → 사람의 결정 |

`pipeline`에서도 레인 상자의 채움 문구를 없애고, **그 단계에서 데이터가 있는 곳**의 주체만 강조하세요(예: 3단계 `result.stdout`은 Python, 8단계 응답 `content`는 외부 AI → Python).

**R5 · I3에 파이프의 돌아오는 길이 그려지지 않음 (S3-3)**
현재 화살표는 Python → 운영체제 → Git 방향뿐이라, 이 화면의 핵심인 “Git의 출력이 파이프를 지나 Python 메모리로 들어온다”가 그림에 없습니다. 4–6단계에서 다음을 그려 주세요.
- Git → **stdout 파이프** → Python 메모리 `result.stdout = ' M README.md\n'`
- Git → **stderr 파이프** → `result.stderr = ''` (두 파이프는 따로)
- Git 종료 → 운영체제 → `result.returncode = 0`
- 3단계(파이프 연결)에서 두 파이프가 생기는 모습. 값은 R6·Lab 04 재현값과 같게.

**R6 · I9 사례 버튼이 무엇을 시험하는지 알 수 없음 (S5-3)**
`C1`–`C6`, `P1`–`P5`만 보여 학습자가 고를 근거가 없습니다. [설계 §4 I9](../../content/mission-stories/main-m06/design-v0.4.md#4-상호작용-설계-i1i10)에 추가한 사례 이름을 버튼에 함께 표시하세요. C6에는 “공식 본문 규칙에는 어긋나지만 검증기에 그 규칙이 없어 통과(G4)” 설명을 붙이세요. P1은 How to Test의 교체 전과 후를 나란히 보여 주세요.

## 화면 조작 수정

**R7 · 선택된 상태가 선택되지 않은 버튼보다 약해 보임**
도식 전환 버튼에서 선택된 버튼은 밝은 배경, 선택되지 않은 버튼은 진한 채움이라 처음 보는 학습자는 반대로 읽기 쉽습니다(S1-4·S3-3·S4-5·S5-3에서 확인). **v0.4 스토리 범위에서만** 선택 상태를 더 강하게(채움·굵기·표시 기호 등, 색만으로 구분하지 않음) 바꿔 주세요. v0.3 Lab의 기존 모양은 유지합니다.

**R8 · S4-5 선택값 컨트롤 정렬**
`temperature 사용`·`max_tokens 사용` 체크박스가 라벨에서 멀리 떨어져 가운데에 있습니다. 체크박스를 라벨 바로 앞에 두고, 체크하지 않았을 때 슬라이더와 선택 상자를 비활성으로 보여 주세요(값이 요청에 들어가지 않는다는 것과 일치).
