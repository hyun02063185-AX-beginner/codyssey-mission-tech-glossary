# Open-book Experience v0.2 Review

- 검색: 공백·하이픈·대소문자 정규화와 주요 한국어 별칭을 지원하고 M01 관련 용어를 우선한다.
- Drag lookup: `https://usr.codyssey.kr/*`에서만 2~100자 선택어를 storage로 전달한다.
- Unknown term: 기본 검색 제공자 새 탭 검색을 사용한다.
- 권한: sidePanel, storage, contextMenus, search 및 Codyssey 단일 host만 사용한다.
- Quick Terms: 기존 M01 Context Layer의 23개 ID를 그대로 사용한다.
- 제한: 실제 Chrome에서 확장 새로고침 후 drag→panel 자동 검색과 default search 동작을 재확인해야 한다.
