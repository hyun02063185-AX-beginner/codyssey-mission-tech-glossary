# 08. M01 Knowledge Map seed history

The original M01 Knowledge Map foundation was promoted to the field-level Frontend Knowledge Map in the v1 migration. This document remains only as a record of the initial M01 seed decisions; it is not the current data or route contract.

The current architecture, source paths, node-role model, overlay contract, and canonical URLs are documented in [09_frontend_knowledge_map_architecture.md](09_frontend_knowledge_map_architecture.md).

M01 is now represented as a derived overlay over the shared Frontend field map. Existing M01 Open-book content and its 23 Quick Terms remain the source for that overlay; they were not edited in the migration.
