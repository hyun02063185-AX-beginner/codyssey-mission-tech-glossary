# 00. 프로젝트 정의와 원칙

## 1. 프로젝트명

**코디세이 기술용어 사전**

영문명: **Codyssey Mission Tech Glossary**

별명: **버티다 보면 아는 말 사전**

캐치프레이즈:

> **미션 하나, 용어 하나. 버티다 보면 실력이 된다.**

영문 저장소명:

`codyssey-mission-tech-glossary`

---

## 2. 프로젝트 한 문장 정의

코디세이 미션 요구사항에 등장하는 기술용어와 핵심 배경 개념을
**미션 수행과 동료평가에 실제로 사용할 수 있는 형태로 정리한 미션 기반 기술용어 사전**이다.

---

## 3. 문제 정의

코디세이 미션은 짧은 요구사항 안에도 다양한 기술용어와 배경지식을 요구한다.

초보 학습자는 다음 문제를 반복해서 겪는다.

1. 미션 문서를 읽는 것 자체가 어렵다.
2. 한 용어를 검색하면 설명 안에서 또 다른 모르는 용어가 등장한다.
3. 검색 결과는 현재 미션에서 필요한 수준보다 지나치게 깊거나 넓다.
4. 구현은 했지만 사용한 기술을 설명하기 어렵다.
5. 동료평가를 할 때 무엇을 확인하고 질문해야 하는지 판단하기 어렵다.
6. 이전 미션에서 본 개념과 현재 미션의 개념을 서로 연결하기 어렵다.

---

## 4. 목표

### 학습자 관점

- 미션에서 모르는 용어를 빠르게 찾는다.
- 쉬운 설명부터 기술적인 설명까지 단계적으로 이해한다.
- 해당 용어가 현재 미션에서 왜 필요한지 파악한다.
- 관련 개념으로 자연스럽게 확장한다.

### 동료평가 관점

- 평가 전에 핵심 개념을 짧게 복습한다.
- 상대방의 이해를 확인할 질문을 참고한다.
- 구현 유무뿐 아니라 개념 이해 여부까지 대화할 수 있다.

### 프로젝트 관점

- 예비과정 3개와 본과정 13개, 총 16개 미션의 기술용어를 하나의 체계로 연결한다.
- 일부 난해한 개념은 유머가 가미된 웹툰으로 시각화한다.
- 장기적으로 검색·필터·미션 연결·관련 개념 탐색이 가능한 웹서비스로 발전시킨다.

---

## 5. 하지 않는 것

이 프로젝트는 다음을 목표로 하지 않는다.

- 컴퓨터 과학 전체 용어를 모두 수록하는 백과사전
- 공식 코디세이 평가 기준을 대체하는 자료
- 용어 정의만 나열한 일반 사전
- 모든 용어를 웹툰으로 만드는 콘텐츠 프로젝트
- AI가 만든 설명을 검수 없이 자동 게시하는 서비스

---

## 6. 핵심 원칙

### P1. 정확성 우선

설명 자체는 정확하고 진지해야 한다.
유머는 개념을 왜곡하지 않는 범위에서만 사용한다.

### P2. 미션 맥락 우선

각 항목은 가능하면 다음 질문에 답해야 한다.

> **그래서 이 용어가 이 미션에서 왜 필요한가?**

### P3. 쉬운 설명에서 정확한 설명으로

한 줄 설명 → 쉬운 설명 → 기술적 설명 순서로 깊이를 조절한다.

### P4. 동료평가에 실제로 사용 가능해야 함

핵심 용어에는 다음 중 하나 이상을 제공한다.

- 이해 확인 질문
- 흔한 오해
- 평가 시 확인할 포인트

### P5. 실제 등장 용어와 배경 개념을 구분

문서에 직접 등장하지 않은 배경지식을 실제 등장 용어처럼 섞지 않는다.

### P6. 동일 용어는 한 번만 정의

용어 본체는 하나로 관리하고 여러 미션의 사용 맥락을 연결한다.

### P7. 웹툰은 선택적 학습 장치

비유·상황극·시각화가 실제 이해에 도움이 되는 개념에만 사용한다.

---

## 7. 기본 콘텐츠 톤

### 사전 설명

- 정확함
- 짧고 명확함
- 초보자 친화적
- 과도한 전문용어 사용 금지
- 전문용어를 사용할 경우 관련 용어로 연결

### 브랜드/웹툰

- 어렵고 진지한 기술 학습의 긴장을 낮추는 정도의 유머
- 웹툰 유머 비율 약 30~50%
- 개념을 웃기는 것이 아니라 **개념이 사용되는 상황을 웃기게 표현**

---

## 8. 프로젝트 성공 기준

초기 버전이 성공했다고 판단하려면 최소한 다음이 가능해야 한다.

- 미션별 핵심 용어를 볼 수 있다.
- 분야별로 용어를 다시 탐색할 수 있다.
- 같은 용어가 여러 미션에서 어떻게 쓰이는지 알 수 있다.
- 핵심 용어에는 미션 맥락과 동료평가 질문이 있다.
- 일부 핵심 개념에는 웹툰 설명이 연결된다.
- 원천 데이터와 검수된 사전 데이터를 구분해서 관리한다.
