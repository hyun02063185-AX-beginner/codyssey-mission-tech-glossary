# 01. 정보 구조와 사용자 흐름

## 1. 핵심 탐색 축

서비스는 최소 두 가지 탐색 방식을 제공한다.

### A. 미션별 보기

사용자가 지금 수행 중인 미션에서 필요한 용어만 빠르게 확인한다.

예:

- 예비 M01
- 예비 M02
- 예비 M03
- 본과정 M01
- ...
- 본과정 M13

각 미션 페이지에는 다음을 제공한다.

- 핵심 용어
- 보조 용어
- 요구사항상 필요한 배경 개념
- 웹툰 설명이 있는 용어
- 동료평가 핵심 질문

### B. 분야별 보기

여러 미션에 흩어진 개념을 기술 분야 기준으로 연결한다.

초기 분류 후보:

- Computer Basics
- Linux / OS
- Container
- Network
- Web
- Programming
- Data
- Git / Collaboration
- Server / Infrastructure
- Database
- Security
- AI / Hardware
- Tools

분류 체계는 전체 16개 미션 용어를 추출한 후 최종 조정한다.

---

## 2. 용어 상세 페이지

용어 상세 화면의 권장 정보 순서:

1. 표준명 / 영문명
2. 한 줄 설명
3. 태그: 분야 / 난이도 / 등장 미션
4. 쉽게 설명하면
5. 정확한 설명
6. 이 미션에서 왜 필요한가
7. 예시 / 명령 / 코드
8. 관련 용어
9. 흔한 오해
10. 동료평가 이해 확인 질문
11. 웹툰 설명
12. 더 깊게 보기

웹툰이 있는 경우에도 정확한 설명이 먼저 또는 바로 이어서 확인 가능해야 한다.

---

## 3. 주요 사용자 흐름

### Flow 1. 미션 수행 중 검색

미션 문서 → 모르는 용어 발견 → 검색 → 한 줄 설명 확인 → 미션 맥락 확인 → 관련 용어 확인

### Flow 2. 동료평가 준비

평가할 미션 선택 → 핵심 용어 목록 → 동료평가 질문 → 필요한 용어 상세 복습

### Flow 3. 분야별 복습

분야 선택 → 용어 목록 → 개념 간 관계 탐색 → 여러 미션에서의 사용 맥락 비교

### Flow 4. 웹툰으로 개념 이해

용어 상세 → 웹툰 보기 → 유머/비유로 직관 형성 → 정확한 설명 재확인

## 4. 검색·필터 후보

향후 웹 UI에서는 다음 필터를 고려한다.

- 과정: 예비 / 본과정
- 미션
- 분야
- 난이도
- 중요도
- 출처 상태
- 웹툰 있음/없음
- 동료평가 질문 있음/없음

---

## 5. 개념 연결

사전은 가나다순 목록에서 끝나지 않는다.

예:

Network
- IP
  - Port
    - Socket
      - TCP
      - Server
- DNS
  - Domain

각 용어는 `related_terms`로 연결하며,
관계 유형이 필요한 경우 다음을 고려한다.

- prerequisite: 먼저 알면 좋은 개념
- related: 관련 개념
- contrast: 자주 비교되는 개념
- deeper: 더 깊게 볼 개념

---

## 6. 초기 화면 구성 원칙

초기 웹 버전은 다음 세 화면만으로도 시작 가능하다.

1. 홈 / 검색
2. 미션별 용어 목록
3. 용어 상세

분야별 탐색, 개념 지도, 웹툰 모아보기는 데이터가 안정된 뒤 확장한다.
