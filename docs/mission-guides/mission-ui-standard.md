# 미션 공통 UI 기준

이 문서는 B1-1을 포함한 신규 미션의 화면 재사용 기준이다. 교육 운영과 자료별 역할은 [학습 운영 정책](learning-operation-policy.md), 승인·통합 절차는 [workflow](workflow.md)를 따른다. 콘텐츠 원문과 지도 데이터의 승인 절차를 대신하지 않는다.

## 공통 화면 구조

`미션 학습 → 미션 소개 → 미션 스토리 / 개념지도 / 학습가이드`를 기본 진입 동선으로 사용한다. 목록의 추천 카드와 미션 카드는 모두 해당 `/missions/:missionId` 소개로 연결한다. 기존 Story·지도·장면·단계 직접 주소는 유지하며 소개로 강제 이동시키지 않는다.

소개 화면은 기존 `MissionDetailPage`를 사용한다. 미션 번호·제목, 기존 핵심 질문, 세 자료의 공통 카드 순으로 배치한다. 명칭은 **미션 스토리 · 개념지도 · 학습가이드**로 통일한다. 제공되지 않는 자료는 준비 중으로 표시하고 링크·클릭 동작을 만들지 않는다. 미승인 핵심 질문을 새로 작성하지 않고 준비 상태를 표시한다. 지식 확장과 관련 용어는 자료 카드 아래에 보존한다. 별도 체험 자료도 기존 동작을 유지한다.

## 메뉴 모드

| 모드 | 적용 화면 | 메뉴 |
| --- | --- | --- |
| Standard | 용어사전, 미션 목록·소개, 학습가이드, 기존 기술지도 | 기존 사이트 전체 메뉴 |
| Learning Focus | 미션 스토리, 미션 개념지도 | 소개로 돌아가기, 현재 미션·자료, 학습자료 메뉴 |

`LearningFocusNav`를 공유한다. Story나 지도 위에 사이트 전체 메뉴를 중복 표시하지 않는다. 자료 메뉴에는 실제 제공되는 자료만 넣는다. 맥락이 있는 경우 검증된 고정 경로와 허용된 상태를 전달한다. 외부 URL이나 임의 return URL을 복귀 주소로 사용하지 않는다. 발표자 창은 투영 화면과 구분하며 공통 메뉴를 주입하지 않는다.

## Story 유형의 허용 범위

B2-1의 8 Scene·128단계 슬라이드, 발표자 창·정답 공개·복습 계약을 보존한다. B3-1의 5 Scene과 네트워크 구조도, 요청·응답 강조·장면 이동을 보존한다. 공통화는 메뉴와 외부 화면 구조에 한정한다. 서로 다른 강의 형식을 단일 렌더러로 바꾸지 않는다. 교육 원문·해시를 UI 작업에 맞춰 자동 갱신하지 않는다.

## 개념지도 Map-first

- 남은 viewport를 Canvas에 배정한다. 고정 540px 같은 일괄 높이를 쓰지 않는다. 메뉴와 도구의 실제 높이를 함께 측정한다.
- 선택 없는 기본 화면에서 상세·관계 패널과 보조 도구를 닫는다. 선택 주소는 유지하며 명시적인 개념·관계 탐색에는 해당 설명을 제공할 수 있다.
- PC는 오른쪽 보조 패널, 모바일은 하단 시트를 사용한다. 패널을 닫으면 Canvas가 즉시 공간을 회수하고 크기를 다시 계산한다. 선택 노드는 패널 뒤에 숨지 않아야 한다.
- 검색·필터·범위 선택은 컴팩트하게 제공하고 설명·범례는 필요할 때 펼친다. 전체 맞춤과 읽기 크기, 글자 확대와 표시 공간 확대를 구분한다.
- 전체 화면 탐색은 사이트 내부의 viewport 모드로 제공할 수 있다. 진입 시 패널을 접고 선택 상태를 유지한다. 종료 시 패널·초점·지도 중심을 복구한다. Escape와 버튼 모두 지원한다.
- 이동·확대·축소·맞춤, 키보드 선택과 터치 이동을 유지한다. 정보량을 작은 글자로 무조건 줄이지 않는다.

B2-1의 45개념·7개 영역 집중·24관계·10비교·P1~P3와 Story·용어 왕복을 보존한다. B3-1의 일반망·AWS 관점, 원본 노드·관계·좌표·통신 흐름과 Story 복귀를 보존한다. 엔진·데이터·관계 유형을 합치거나 UI 통일을 위해 좌표를 바꾸지 않는다. 지도는 의미 관계이며 실제 실행·통신 허용 순서와 다름을 안내한다.

## 기본 디자인

Standard 화면은 기존 사이트 테마의 surface/text/accent 토큰을 사용한다. 학습 메뉴는 밝은 배경 `#f4f7f3`, 본문 `#213b3a`, 강조 `#155d55`, 경계 `#cfddd8`를 사용한다. 승인된 Story 및 지도별 관계 색상은 보존한다. 초점은 3px 외곽선으로 표시한다.

시스템 한글 폰트 또는 기존 Pretendard를 사용한다. 메뉴 14~15px, 자료 설명·상세 본문은 기존 16px 수준을 유지한다. 선택 노드의 실제 읽기 크기를 따로 검증한다. 6~8px 도구 간격, 12~20px 카드·패널 여백과 8~16px 모서리를 사용한다. 주요 버튼·메뉴 터치 영역은 최소 44×44px다. 좁은 화면에서 줄바꿈·접기·하단 시트를 사용하고 가로 넘침을 만들지 않는다.

## 신규 미션 등록·검증

신규 B1-1 등은 먼저 이 기준에 따라 기존 소개 화면, 자료 등록과 `LearningFocusNav`를 재사용한다. 승인된 자료의 실제 경로만 등록한다. 교육 형식이나 그래프 엔진은 해당 미션의 목적에 맞게 유지한다. 예외는 이유와 Owner 검토 근거를 해당 미션 상태 문서에 기록한다.

통합 시 실제 App의 1280×720, 360×800, 390×844에서 다음을 검증하고 PASS·FAIL·SKIP을 구분한다.

1. 용어사전 → 미션 목록 → 소개 → Story와 세 카드의 제공 상태.
2. 지도 진입·선택·상세 닫기·패널 공간 회수·전체 화면·확대·맞춤·이동.
3. Story → 지도 → 용어 → 원래 학습 위치 왕복 및 직접 주소·새로고침·이력 이동.
4. 고유한 강의·지도 데이터·발표자 계약과 다른 미션·학습가이드 회귀.
5. 실제 Canvas 폭·높이 및 상단 메뉴 높이, PC·모바일 화면 캡처의 시각 검수.

자동 테스트·빌드만으로 시각 QA 완료를 선언하지 않는다. 승인된 콘텐츠 QA는 변경 범위가 없음을 확인한 뒤 재사용하며, 변경된 외부 UI와 왕복 동선은 새로 검증한다.
