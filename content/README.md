# Term Content

기술 검수까지 진행할 용어별 콘텐츠 초안을 저장합니다.

용어 콘텐츠는 `terms/<canonical-term-id>.md` 파일로 작성합니다. 이 안내 문서는
`terms/` 밖에 두어 canonical `readme`의 향후 콘텐츠 파일 `terms/readme.md`와
대소문자를 구분하지 않는 파일시스템에서 충돌하지 않게 합니다.

예:

- `terms/docker-image.md`
- `terms/container.md`
- `terms/shell.md`
- `terms/terminal.md`
