# Webtoon Content

웹툰 후보, 스크립트, 생성 프롬프트, 검수 결과를 관리합니다.

웹툰은 사전 설명을 대체하지 않고 이해를 돕는 보조 콘텐츠로 사용합니다.

## 제작 도구 실행 규칙

- 웹툰의 기본 독자는 L0입니다. 한 작품의 중심 용어는 하나로 두고, 비유 뒤에 정확한 핵심과 비유의 한계를 확인합니다.
- `candidate`·콘셉트·대본·프롬프트·이미지 시안은 배포 승인 상태가 아닙니다. 기술 검수, 한글 검수, 모바일/PC 시각 QA, 대체텍스트, Owner 콘텐츠 승인과 공개 승인을 각각 확인한 버전만 통합합니다.
- 모바일 세로 1열×4컷 규격과 공통 캐릭터는 아직 Owner 승인 대기입니다. 기존 이미지를 자동 재배치하거나 교체하지 않습니다.
- 대본, 편집 가능한 원본, 배포 이미지, 버전과 검수 결과를 연결해 보존합니다. 공개 뒤 오류가 발견되면 직전 승인 버전으로 롤백할 수 있어야 합니다.
- 사람이 읽는 정책과 17편 감사 결과는 [Notion 운영 정책](https://app.notion.com/p/3ff62d4e038081eba245ca77a511aa52)과 [관리대장](https://app.notion.com/p/3ff62d4e038081d1b86ef87316fe1b4e)에서 관리합니다.
