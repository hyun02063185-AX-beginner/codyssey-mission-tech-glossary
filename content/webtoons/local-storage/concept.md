# localStorage 웹툰 콘셉트

## 학습 목표

브라우저에 값을 저장해 새로고침 후에도 유지하는 Web Storage를 이해한다.

## 초보자 오해

화면에서 바꾼 설정(예: 다크모드)은 새로고침해도 당연히 유지된다고 생각한다.

## 기술적 핵심

localStorage는 origin 단위로 key/value 문자열을 저장하는 브라우저 Web Storage다. 새로고침과 탭 종료 후에도 값이 유지되며, 비밀번호 같은 민감정보 저장은 권장하지 않는다.

## 비유의 한계

"브라우저 안의 메모장" 비유로 기억하되, 서버가 아니라 사용자 브라우저에 저장되고 origin이 다르면 공유되지 않는다는 점을 정확히 설명한다.

## 대체 텍스트

다크모드 설정이 새로고침 후 사라지는 문제를 localStorage로 해결하는 4컷 웹툰
