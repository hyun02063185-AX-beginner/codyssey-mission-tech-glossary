# Docker 이미지 — 노을 사진이면 되나요?


Docker 이미지를 가져오라는 말에 멋진 노을 사진을 준비했습니다. 같은 이름이어도 쓰임이 다르네요.


## 1컷 · 메이커 작업실 입구·전신

학생이 노을 사진이 든 액자를 들고 자신 있게 들어옵니다. 동료는 공구 선반 옆에서 컴퓨터를 가리킵니다.

초보자: 이미지 가져오랬죠? / 노을 사진이에요!

동료: 사진 말고, / Docker 이미지요.

## 2컷 · 파일 묶음 화면·근접

모니터에 프로그램 파일·톱니바퀴 설정·라이브러리를 상징하는 작은 도형을 담은 묶음 아이콘이 보입니다. 학생의 옆얼굴과 동료의 손만 등장합니다.

초보자: 그럼 뭘 / 담은 건데요?

동료: 프로그램 실행에 쓸 / 파일과 설정 묶음이요. (화면 밖)

## 3컷 · 뒤 어깨너머·파일 묶음과 실행 화면

두 사람의 뒤 어깨너머로 모니터를 봅니다. 이미지 묶음 표시와 분리된 앱 창이 나란히 있고 앱 창에 실행 상태를 나타내는 초록 점이 보입니다.

초보자: 이걸 바탕으로 / 프로그램을 실행해요?

동료: 컨테이너라는 공간을 / 만들어 실행하죠.

## 4컷 · 작업실 벽·옆뒤 모습

학생이 작업실 벽에 노을 사진 액자를 걸고, 동료는 뒤에서 두 손을 모으고 웃으며 감상합니다.

초보자: 그럼 노을 사진은 / 어디에 쓰죠?

동료: 그건 작업실 / 인테리어 담당이죠!


## 쉬운 뜻

Docker 이미지는 컨테이너를 만드는 바탕이 되는 읽기 전용 파일·설정 묶음이에요. 프로그램 코드와 실행에 필요한 라이브러리 같은 파일을 담을 수 있어요. 이미지를 바탕으로 컨테이너라는 실행 공간을 만들고, 그 안에서 프로그램을 실행합니다.


## 비유의 경계

이 편의 ‘이미지’는 사진 파일을 뜻하지 않아요. 그림 속 묶음 아이콘은 파일·설정을 표현한 비유이며, 이미지 자체가 실행 중인 프로그램은 아니에요. 실행에는 Docker 같은 도구와 호환되는 환경이 필요합니다. 이미지에 사진 파일이 포함될 수 없다는 뜻도 아닙니다.
