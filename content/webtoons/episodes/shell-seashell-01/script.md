# 셸 — 바다에서 주웠어요


셸을 준비하라는 말에 소라 껍데기를 가져온 학생. 컴퓨터의 셸은 다른 일을 합니다.


## 1컷 · 해변 카페 입구·전신 대각선

학생이 큰 소라 껍데기를 자랑스럽게 들고 해변 카페로 들어옵니다. 동료가 테이블의 컴퓨터 쪽으로 안내합니다.

초보자: 셸 준비하랬죠? / 바다에서 주웠어요!

동료: 그 셸 말고, / 컴퓨터의 셸이요!

## 2컷 · 옆모습과 화면·한 인물

학생이 카페의 데스크톱 화면에 보이는 글 입력 창을 살펴봅니다. 동료의 손만 오른쪽에서 들어와 화면을 가리킵니다.

초보자: 글을 쓰면 / 컴퓨터가 일해요?

동료: 셸이 명령을 해석해 / 실행을 요청해요. (화면 밖)

## 3컷 · 키보드와 결과·탑뷰 근접

초록 소매의 손이 키보드로 명령을 입력하고 화면에 파일 목록이 나타납니다. 화면 밖 대화로 결과를 확인합니다.

초보자: 파일 목록을 보라는 / 명령을 넣었더니… (화면 밖)

동료: 폴더 속 파일들이 / 나왔죠? (화면 밖)

## 4컷 · 바닷가 테라스·낮은 시점

학생이 컴퓨터를 떠나 테라스 난간에서 소라를 귀에 대고 듣습니다. 동료가 뒤쪽 카페 문가에서 웃습니다.

초보자: 그럼 이 조개는 / 어디에 쓰죠?

동료: 파도 소리 듣는 건 / 그쪽이 잘하겠네요.


## 쉬운 뜻

셸은 입력한 명령을 해석하고, 프로그램 실행 같은 작업을 요청하는 프로그램이에요. 파일 목록을 보거나 다른 프로그램을 실행하는 데 쓸 수 있어요.


## 비유의 경계

이 편은 글로 명령을 입력하는 셸을 다뤄요. 터미널은 입력과 결과를 주고받는 창이고, 셸은 그 안에서 명령을 해석하는 프로그램이에요. 일상적인 말이나 음성이라면 무엇이든 알아듣는다는 뜻은 아니며, 사용하는 셸에 맞는 명령을 입력해야 해요.
