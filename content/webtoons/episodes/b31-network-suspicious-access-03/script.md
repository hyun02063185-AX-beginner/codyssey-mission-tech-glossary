# 3편 — 수상한 택배기사 (DRAFT)

원본 이미지에서 직접 전사. 줄바꿈은 새 판형에 맞춰 조정하며 문구·사건 순서는 유지한다.

## 1. 수상한 택배기사

왼쪽 택배기사가 상자를 들고 집을 방문한다. 생각 속에서는 웃으며 지하 창고의 과자·초콜릿·컵케이크를 노린다.

- 택배기사 (speech): 김정현님 / 택배 / 왔습니다!
- 택배기사 (thought): (사실 지하 창고 / 간식을 노리는 중…)
- 표지: 외부 요청
- 표지: 김정현
- 표지: 경계 라우터 / (현관)
- 표지: 과자
- 시각 정보: 생각 말풍선은 대사가 아니라 속셈. 간식 상상 그림.
- 교육 개념: 겉보기 택배기사와 실제 접근 목적 차이

## 2. 창고로 몰래 이동

왼쪽 택배기사가 거실을 벗어나 지하 창고로 몰래 가려 하고 오른쪽 강아지가 화를 내며 막는다.

- 택배기사 (speech): 어… 그냥 / 잠깐 / 창고만…
- 방화벽 강아지 (speech): 잠깐! / 손님은 / 거실까지만!
- 표지: 수상한 접근 차단
- 표지: DMZ / (손님 공간)
- 표지: 자료망 / DB / (지하 창고)
- 표지: 방화벽
- 시각 정보: 거실의 파란 점선 경계. 창고 사슬과 빨간 금지 표식. 방화벽 조끼.
- 교육 개념: 외부에서 자료망 직접 접근 차단

## 3. 방화벽의 설명

왼쪽 택배기사가 땀을 흘리고 강아지가 DMZ와 자료망의 차이를 설명한다. 오른쪽에는 외부→DMZ→자료망/DB 경로의 허용·차단 구조도가 있다.

- 방화벽 강아지 (speech): 거실은 / 손님 공간 / (DMZ)이에요.
- 방화벽 강아지 (speech): 지하 창고는 / 중요한 자료망이라 / 외부 손님은 / 직접 못 들어가요!
- 표지: 방화벽
- 구조도: 외부(인터넷) / = 외부 요청 → DMZ / (거실, 손님 공간) → 자료망 / DB / (지하 창고)
- 시각 정보: 구조도: 외부(인터넷)=외부 요청 ↓ DMZ(거실, 손님 공간) 초록 체크 ↓ 자료망/DB(지하 창고) 자물쇠·빨간 X.
- 교육 개념: DMZ와 내부 자료망의 분리

## 4. 정체 들통!

왼쪽 택배기사가 땀과 침을 흘리며 비밀 작전 종이를 들고 있다. 가운데 강아지가 웃고 오른쪽 김정현이 손가락을 들고 설명한다. 창고에는 간식이 보인다.

- 방화벽 강아지 (speech): 외부 손님은 / DMZ까지만!
- 김정현 (speech): 겉보기엔 / 택배기사여도, / 창고 직접 접근은 / 막아야 해!
- 표지: 자료망 / DB / (지하 창고)
- 표지: 과자
- 표지: (비밀 작전) / 창고 간식 리스트✓ / • 과자 전부! / • 초콜릿 / • 컵케이크…♡
- 표지: 김창현
- 표지: 방화벽
- 시각 정보: 간식 생각 그림·과자 봉지. 비밀 작전의 체크와 하트. 마지막 명찰은 원본대로 김창현(다른 컷 김정현과 불일치, Owner 확인 대기).
- 교육 개념: 외형을 믿어 내부 자료망을 직접 허용하지 않음

## 하단 요약

외부 요청은 DMZ까지, 자료망(DB)은 직접 접근 금지!

웃었으면 됐고, 이제 진짜 뜻을 봅시다.
