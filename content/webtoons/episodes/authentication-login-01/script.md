# 인증 — 매일 보는데, 또 누구세요?


분명 내 계정인데 왜 다시 확인할까요? 로그인에서 본인인지 확인하는 인증을 만납니다.

## 1컷 · 개발실·넓은 장면

초록 후드의 학습자가 로그인 화면 앞에서 자기 계정인데 왜 확인하는지 묻습니다. 노란 카디건의 개발자 동료가 뒤쪽에서 답합니다.

학습자: 분명 제 계정인데, / 왜 또 확인해요?

개발자 동료: 접속한 사람이 / 본인인지 확인해야죠.

## 2컷 · 로그인 화면·근접

아이디 입력란과 비밀번호 점 표시가 있는 화면을 가까이 봅니다. 학습자와 동료의 손만 등장하며 실제 비밀번호는 보이지 않습니다.

학습자: 이름만 적으면 / 제 계정 아닌가요? (화면 밖)

개발자 동료: 이름은 남도 알죠. / 본인이라는 증거가 필요해요. (화면 밖)

## 3컷 · 확인 완료·어깨너머

학습자의 어깨너머로 신원 확인이 완료된 계정 화면을 봅니다. 동료가 화면 밖에서 확인의 의미를 설명합니다.

학습자: 로그인됐어요! / 저라고 확인된 거죠?

개발자 동료: 네, 이렇게 신원을 / 확인하는 게 인증이에요. (화면 밖)

## 4컷 · 화면 앞·표정 근경

학습자가 화면을 바라보며 매일 쓰는 컴퓨터와 아직 서먹하다고 농담합니다. 동료는 가까운 책상 모서리에 기대어 웃습니다.

학습자: 컴퓨터랑 매일 보는데 / 아직도 서먹하네요.

개발자 동료: 친분보다 / 확인 절차가 먼저죠.

## 쉬운 뜻

인증은 사용자가 주장한 신원이 맞는지 확인하는 과정이에요. 로그인할 때 비밀번호나 인증 기기 같은 수단으로 본인임을 확인하는 것이 한 예예요.

## 비유의 경계

인증은 이름을 입력하는 것만으로 끝나지 않으며, 비밀번호 외에도 다양한 방법이 있어요. 인증됐다고 모든 기능을 사용할 권한이 생기는 것은 아니에요. 이 편은 신원 확인에 집중하고, 허용할 행동의 판단은 인가 편에서 다뤄요.
