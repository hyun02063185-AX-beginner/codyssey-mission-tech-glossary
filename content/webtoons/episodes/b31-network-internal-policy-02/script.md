# 2편 — 내부 구역 사이의 접근 통제 (DRAFT)

원본 이미지에서 직접 전사. 줄바꿈은 새 판형에 맞춰 조정하며 문구·사건 순서는 유지한다.

## 1. 서재에서 배고픔

김정현이 2층 서재의 책상과 노트북 앞에서 배를 잡고 배고파한다. 책·컵·창문과 집 대문 명패가 보인다.

- 김정현 (speech): 아… / 배고프다! / 지하 창고에 / 간식 있지?
- 김정현 (speech): 같은 집 안인데 / 그냥 가면 / 되겠네!
- 표지: 업무망 / (2층 서재)
- 표지: 김정현
- 표지: 김정현
- 시각 정보: 노트북의 방패 그림과 배고픔을 나타내는 효과.
- 교육 개념: 업무망에서 자료망으로 이동하려는 상황

## 2. 말티즈의 제지

왼쪽 김정현이 놀라 묻고 중앙 강아지가 계단 아래 지하 창고 앞에서 제지한다. 오른쪽에 자료망/DB 표지가 있다.

- 김정현 (speech): 어? / 나 이 집 / 사람인데도?
- 방화벽 강아지 (speech): 잠깐! / 지하 창고는 / 그냥 못 가요!
- 표지: 내부 이동도 검사
- 표지: 자료망 / DB / (지하 창고)
- 표지: 방화벽
- 시각 정보: 강아지 조끼의 방화벽 표기. 창고의 잠긴 문.
- 교육 개념: 내부 구성원도 접근 통제 적용

## 3. 규칙 설명

왼쪽 강아지가 지시봉으로 업무망→방화벽→자료망/DB 구조도를 설명하고 오른쪽 김정현이 이해한다.

- 방화벽 강아지 (speech): 서재는 / 업무 공간, / 지하 창고는 / 중요한 자료 / 공간이에요.
- 방화벽 강아지 (speech): 집 안 사람이어도 / 규칙과 허용이 / 있어야 들어가요!
- 김정현 (speech): 아~ 내부망에서 / 자료망 갈 때도 / 확인하는구나!
- 표지: 방화벽
- 구조도: 업무망 / (2층 서재) → 방화벽 → 자료망 / / DB / (지하 창고)
- 시각 정보: 구조도: 업무망(2층 서재) → 불꽃 방패 방화벽 → 자료망/DB(지하 창고). 강아지가 지시봉으로 가리킨다.
- 교육 개념: 업무망에서 자료망 통신도 정책 필요

## 4. 허용 후 통과

김정현이 열린 지하 창고에서 간식 봉지를 들고 웃고 강아지가 옆에서 웃는다. 창고에는 과자와 상자가 있고 문에는 자물쇠·키패드가 있다.

- 방화벽 강아지 (speech): 필요한 / 목적이면 / 통과!
- 김정현 (speech): 이제 이해했어! / 내부망에서 / 자료망 갈 때도 / 방화벽을 / 거치는구나!
- 표지: 자료망 / DB / (지하 창고)
- 표지: 간식
- 표지: 방화벽
- 시각 정보: 강아지 조끼의 방화벽. 허용된 창고 문. 노란 간식 봉지.
- 교육 개념: 필요한 목적과 허용 정책으로 통과

## 하단 요약

내부망 → 자료망도 방화벽과 정책을 통과!

웃었으면 됐고, 이제 진짜 뜻을 봅시다.
