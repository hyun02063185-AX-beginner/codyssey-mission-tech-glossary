# 오픈소스 — 고쳐 써도 되는 거였어요?


글씨가 너무 작은 프로그램. 공개된 코드를 살펴보고 직접 고쳐 쓰며 오픈소스의 의미를 알아봅니다.

## 1컷 · 공동 개발 공간·화면 앞 낮은 시점

학습자가 프로그램의 아주 작은 글씨를 읽으려고 모니터에 가까이 다가갑니다. 기술 멘토가 옆에서 소스 코드 화면을 가리킵니다.

학습자: 프로그램은 좋은데 / 글씨가 너무 작아요.

기술 멘토: 오픈소스라면 코드를 / 살펴보고 고칠 수 있죠.

## 2컷 · 공개 코드와 이용 조건·화면 근접

코드 저장소 화면에 코드 파일과 이용 조건 문서가 나란히 있습니다. 학습자와 멘토의 손이 코드와 문서를 각각 가리킵니다.

학습자: 만든 코드를 / 공개해 둔 거예요? (화면 밖)

기술 멘토: 네, 라이선스에 따라 / 수정·공유할 수 있어요. (화면 밖)

## 3컷 · 수정과 실행·어깨너머 사선

학습자가 코드 일부를 바꾸고 프로그램을 실행합니다. 왼쪽 코드 화면과 오른쪽의 글씨가 커진 프로그램 화면을 함께 보며 멘토가 개선 제안 가능성을 설명합니다.

학습자: 글씨를 키운 버전을 / 직접 만들었어요!

기술 멘토: 이런 개선을 원작에 / 제안할 수도 있어요.

## 4컷 · 복도에서 본 커다란 글씨·넓은 반전

학습자와 멘토가 문 밖 복도에 서 있습니다. 안쪽 대형 모니터에 글자 하나가 화면을 가득 채울 만큼 크게 표시되어 복도에서도 눈에 띕니다.

학습자: 글씨가 이제 / 복도에서도 보여요!

기술 멘토: 다음 수정은 / 크기 조절이겠네요.

## 쉬운 뜻

오픈소스 소프트웨어는 소스 코드를 공개하고, 라이선스가 정한 조건에 따라 사용·수정·재배포할 수 있게 한 소프트웨어예요. 코드를 공부하거나 필요한 기능을 고치고, 개선 사항을 제안할 수도 있어요.

## 비유의 경계

코드를 인터넷에서 볼 수 있다는 사실만으로 오픈소스가 되는 것은 아니에요. 오픈소스는 사용·수정·재배포의 권리가 라이선스로 허용되어야 하며, 저작권과 라이선스 조건은 유지돼요. 단순히 무료라는 뜻도 아니에요. 수정 제안이 원본 프로젝트에 반드시 채택되는 것은 아니며 프로그램을 직접 고치고 실행하려면 기술과 실행 환경이 필요해요.
