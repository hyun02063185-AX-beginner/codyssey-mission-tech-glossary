# GitHub — 압축 파일은 이제 그만!


수정할 때마다 압축 파일을 보내던 개발자. GitHub에서 작업을 공유하고 검토해 봅니다.

## 1컷 · 팀 작업 공간·서 있는 중경

노란 카디건의 개발자 동료가 전송할 파일과 압축 파일 목록을 보며 난감해합니다. 갈색 재킷의 기술 멘토가 옆의 공유 작업 화면을 가리킵니다.

개발자 동료: 수정할 때마다 / 압축해서 보내요?

기술 멘토: GitHub에 저장소를 / 공유해 보죠.

## 2컷 · 공유 저장소·어깨너머

개발자의 어깨너머로 온라인 저장소의 파일 목록과 의견 표시를 봅니다. 멘토의 손이 화면 한쪽을 가리킵니다.

개발자 동료: 팀원도 같은 곳에서 / 변경을 볼 수 있네요!

기술 멘토: 코드를 검토하고 / 의견도 나눌 수 있어요. (화면 밖)

## 3컷 · 변경 제안·화면과 손 근접

화면의 두 버전 차이와 검토 의견, 합치기 동작을 나타내는 표시를 가까이 보여 줍니다. 두 인물의 손만 보입니다.

개발자 동료: 바로 덮어쓰지 않고 / 수정 제안을 보내요? (화면 밖)

기술 멘토: 네, 함께 검토한 뒤 / 합칠 수 있어요. (화면 밖)

## 4컷 · 회의 보드·옆모습 반응

개발자가 진짜 최종을 뜻하는 파일 메모 더미를 내려놓고 웃습니다. 멘토가 정돈된 공유 작업 보드를 가리킵니다.

개발자 동료: 파일명에 진짜 최종은 / 이제 빼도 돼요?

기술 멘토: 네, 그 이름도 / 이제 은퇴시켜요.

## 쉬운 뜻

GitHub는 Git 저장소를 온라인에 두고, 코드를 공유·검토하며 함께 개발할 수 있게 하는 서비스예요. 변경 제안에 의견을 나누고 검토한 뒤 합칠 수 있어요.

## 비유의 경계

Git은 변경 이력을 관리하는 도구이고, GitHub는 Git 저장소를 호스팅하며 협업 기능을 더하는 별도 서비스예요. 내 컴퓨터의 변경이 저절로 공유되는 것은 아니에요. 공유 범위와 접근 권한도 설정해야 합니다.
