# 1편 — 정상적인 외부 요청 (DRAFT)

원본 이미지에서 직접 전사. 줄바꿈은 새 판형에 맞춰 조정하며 문구·사건 순서는 유지한다.

## 1. 집을 찾아온 손님

왼쪽 택배기사가 웃으며 상자를 들고 김정현의 집 대문을 방문한다. 오른쪽에 집 외관·현관·명패·경계 라우터가 있다.

- 택배기사 (speech): 김정현님 / 택배 / 왔습니다!
- 표지: 외부에서 들어온 요청
- 표지: 김정현
- 표지: 경계 라우터 / (현관)
- 시각 정보: 현관의 라우터 아이콘. 웃는 택배기사와 배달 상자.
- 교육 개념: 외부 요청과 경계 라우터

## 2. 말티즈의 확인

왼쪽 택배기사가 상자를 들고 방문 목적을 답하고, 오른쪽 현관의 흰 말티즈가 진지하게 확인한다.

- 택배기사 (speech): 택배 / 전달하러 / 왔어요!
- 방화벽 강아지 (speech): 잠깐! / 왜 오셨죠?
- 표지: 허용된 요청인지 확인
- 표지: 방화벽
- 표지: 방화벽
- 시각 정보: 말티즈 조끼의 방패. 방화벽 표지판의 불꽃 방패.
- 교육 개념: 방화벽의 요청 목적 확인

## 3. 거실까지만 입장

왼쪽 택배기사와 강아지 뒤에 거실·소파가 있고, 오른쪽 위층 서재와 지하 창고로 가는 길은 사슬과 금지 표식으로 막혀 있다.

- 방화벽 강아지 (speech): 손님은 / 거실까지만!
- 택배기사 (speech): 아, 안쪽까지는 / 못 가는군요.
- 표지: DMZ / (손님 공간)
- 표지: 업무망 / (2층 서재)
- 표지: DB / (지하 창고)
- 표지: 방화벽
- 시각 정보: 거실 바닥의 파란 점선 경계. 업무망·DB 진입로 각각 사슬과 빨간 진입 금지 표시.
- 교육 개념: DMZ까지만 허용하고 내부 업무망과 DB 보호

## 4. 거실에서 전달 완료

왼쪽 택배기사와 가운데 김정현이 거실에서 상자를 주고받고, 오른쪽 강아지가 두 앞발을 들고 웃는다.

- 김정현 (speech): 여기서 / 받으면 / 됩니다!
- 방화벽 강아지 (speech): 외부 손님은 / DMZ까지!
- 표지: 김정현
- 표지: 방화벽
- 시각 정보: 택배 상자 전달로 마무리. 강아지 조끼의 방화벽 표기.
- 교육 개념: 외부 요청의 전달 지점은 DMZ

## 하단 요약

외부 요청은 DMZ까지, 내부 업무망·DB는 보호!

웃었으면 됐고, 이제 진짜 뜻을 봅시다.
