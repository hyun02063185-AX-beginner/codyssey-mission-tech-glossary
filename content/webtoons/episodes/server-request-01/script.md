# 서버 — 제 노트북은 퇴근 못 해요?


노트북을 끄자 친구가 접속하지 못합니다. 요청을 받고 응답하는 서버의 역할을 알아봅니다.

## 1컷 · 개발 동아리실·퇴근 직전 넓은 장면

학습자가 닫은 노트북을 가방에 넣으려다 휴대전화의 접속 실패 화면을 보고 놀랍니다. 기술 멘토는 책상 옆에 서서 노트북을 가리킵니다.

학습자: 노트북을 끄니까 / 친구가 접속을 못 해요!

기술 멘토: 그 노트북이 지금 / 서버 역할을 하거든요.

## 2컷 · 노트북과 휴대전화·손 근접

다시 연 노트북과 휴대전화를 가까이 봅니다. 두 기기 사이에는 요청과 응답을 뜻하는 반대 방향 화살표 두 개가 있고 녹색 후드와 갈색 재킷의 손만 보입니다.

학습자: 서버는 꼭 큰 컴퓨터 / 아니었어요? (화면 밖)

기술 멘토: 요청을 받아 처리하는 / 역할을 말하기도 해요. (화면 밖)

## 3컷 · 요청·응답 흐름 보드·어깨너머

학습자의 어깨너머로 보드를 봅니다. 휴대전화에서 노트북으로 향하는 파란 화살표와 웹 페이지 그림을 실어 반대로 돌아오는 초록 화살표가 있습니다. 멘토가 두 흐름을 짚습니다.

학습자: 페이지를 보여 달라는 / 요청을 받으면… (화면 밖)

기술 멘토: 필요한 내용을 담아 / 응답을 보내요.

## 4컷 · 출입문 옆·표정과 동작의 대비

가방을 멘 학습자가 문가에서 책상 위의 열린 노트북을 돌아보며 난처하게 웃습니다. 기술 멘토가 웃으며 아직 동작하는 노트북을 가리킵니다.

학습자: 제 노트북은 저보다 / 늦게 퇴근하네요.

기술 멘토: 접속을 받으려면 / 서버가 동작해야죠.

## 쉬운 뜻

서버는 다른 프로그램이나 기기의 요청을 받아 정보나 기능을 제공하는 프로그램, 또는 그 프로그램을 실행하는 컴퓨터를 말해요. 웹 서버가 브라우저의 요청에 응답해 페이지 내용을 보내는 것이 한 예예요.

## 비유의 경계

서버가 반드시 크고 특별한 컴퓨터인 것은 아니에요. 노트북도 서버 프로그램을 실행하면 서버 역할을 할 수 있어요. 이 이야기는 학습용 노트북 한 대에서 웹 서버를 실행한 상황이며, 모든 서버가 웹사이트를 제공하거나 항상 같은 기기에서 실행되는 것은 아니에요. 서버 중단 뒤에도 브라우저에 이미 받은 내용이 남을 수 있지만 새 요청은 처리할 수 없어요.
