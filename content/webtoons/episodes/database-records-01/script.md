# 데이터베이스 — 주문 내역을 외우라고요?


지난달 주문을 찾느라 채팅을 끝없이 올리던 개발자. 기록을 정리해 저장하고 조건으로 찾아봅니다.

## 1컷 · 주문 관리 앱 개발실·모니터 옆 중경

노란 카디건의 개발자 동료가 길게 이어진 주문 채팅 기록을 보며 지칩니다. 기술 멘토가 정돈된 주문 관리 화면을 제안합니다. 두 사람은 가게 직원이 아니라 주문 앱을 만드는 기술 팀입니다.

개발자 동료: 지난달 주문 찾다가 / 채팅 끝까지 왔어요.

기술 멘토: 데이터베이스에 / 기록을 모아 봐요.

## 2컷 · 정리된 주문 기록·위에서 내려보기

키보드와 주문 기록 화면을 위에서 봅니다. 날짜·상품·금액을 구분한 열과 여러 행이 있고 개발자와 멘토가 각 항목을 손으로 짚습니다. 개인정보는 표시하지 않습니다.

개발자 동료: 날짜·상품·금액을 / 나눠서 저장해요? (화면 밖)

기술 멘토: 네, 새 기록도 넣고 / 내용도 고칠 수 있죠. (화면 밖)

## 3컷 · 조건 검색·개발자의 어깨너머

개발자의 어깨너머로 달력 조건을 선택한 화면을 봅니다. 많은 기록 중 일부만 결과로 남고 멘토의 손이 조건과 결과를 가리킵니다.

개발자 동료: 지난달 주문만 / 바로 찾았어요!

기술 멘토: 조건에 맞는 기록을 / 꺼내 본 거예요. (화면 밖)

## 4컷 · 휴게 공간과 기록 화면·옆모습

개발자 동료가 자리에서 일어나 머리를 가리키며 안도합니다. 기술 멘토가 정리된 주문 관리 화면을 가리키며 웃습니다.

개발자 동료: 제 머리 용량이 / 드디어 늘었네요!

기술 멘토: 머리보다 기록 보관법이 / 바뀐 거죠.

## 쉬운 뜻

데이터베이스는 필요한 정보를 저장하고 찾고 고칠 수 있도록 체계적으로 모아 둔 데이터예요. 보통 데이터베이스 관리 프로그램을 통해 주문 내역처럼 계속 쌓이는 기록을 다뤄요.

## 비유의 경계

이 편에서는 주문 기록을 표로 보여 주지만 모든 데이터베이스가 표 모양인 것은 아니에요. 데이터베이스는 데이터의 모음이고, 저장·조회·수정을 처리하는 소프트웨어는 데이터베이스 관리 시스템(DBMS)이에요. 채팅이나 스프레드시트도 기록을 보관할 수 있지만 여기서는 업무 데이터를 일정한 구조와 조건으로 관리하는 상황을 보여 줍니다. 올바른 기록 입력과 관리가 저절로 보장되는 것은 아니에요.
