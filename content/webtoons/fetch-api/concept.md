# fetch 웹툰 콘셉트

## 학습 목표

브라우저에서 HTTP 요청을 보내고 Promise로 응답을 처리하는 Web API를 이해한다.

## 초보자 오해

fetch는 GET으로 서버에서 데이터를 받아오는 기능일 뿐이라고 생각한다.

## 기술적 핵심

fetch는 HTTP 요청을 보내는 Web API로 GET 외 다양한 method를 지원하고 Promise를 반환한다. HTTP 4xx/5xx 응답은 자동으로 reject되지 않으므로 응답 상태를 직접 확인해야 한다.

## 비유의 한계

"택배 주문" 비유로 기억하되, 요청 성공 여부는 HTTP 상태 코드로 직접 확인해야 한다는 점을 함께 설명한다.

## 대체 텍스트

브라우저가 fetch로 서버에 요청하고 데이터를 응답받는 과정을 설명하는 4컷 웹툰
