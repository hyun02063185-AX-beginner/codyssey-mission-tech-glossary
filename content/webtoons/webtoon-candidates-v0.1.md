# Webtoon Candidates v0.1

## 현재 선정 기준 — 2026-10-21 Owner 조정

미션에 등장한 용어로 대상을 제한하지 않는다. 일반적으로 자주 듣지만 역할을 설명하기 어려운 기술용어 중, **자주 접하는 작동 개념**을 우선한다. 콘텐츠 선정용 세분화 수준이며 canonical taxonomy나 학습 난이도 등급은 아니다.

- 첫 제작 묶음: **서버·데이터베이스·API·오픈소스**. 네 편의 원고·그림·출처는 `common-terms-four.json`과 각 작품 폴더에서 관리한다.
- 어떤 역할인지, 왜 필요한지, 어떤 상황에서 쓰이는지에 집중한다. 미션 수행을 위한 명령·옵션이나 세부 구현 설명은 중심 소재로 삼지 않는다.
- 포트 매핑·바인드 마운트·파일 권한·MAC 연산·엡실론 등 기존 세부 후보는 이력으로 보존하며 다음 묶음의 기본 추천으로 자동 선택하지 않는다. React state·외래 키도 별도 재검토 대상으로 둔다.
- 고정 기술 배역을 사용하고 배역 조합·배경·행동·카메라를 다양화한다. 일상어 말장난보다 실제 기술 사용 상황에서 시작한다.

아래 v0.1 목록은 초기 기획 이력이다. Git·GitHub·셸·터미널·Docker 이미지·인증은 이미 공개되었으므로 미제작 후보로 다시 세지 않는다.

유머 수준은 약 30~50%이며, 기술 설명보다 상황을 웃기게 표현한다.

## Pilot 선정

### 실제 이미지 Pilot (Web 연결 완료)

- `local-storage` (localStorage)
- `javascript` (JavaScript)
- `dom` (DOM)
- `defer` (defer)
- `fetch-api` (fetch)

HTML/CSS는 후보로 유지하되 이번 실제 이미지 Pilot에는 포함하지 않는다.

### 후속 후보 (콘셉트 준비 완료 · 이미지 준비 중)

- `docker-image`, `shell`, `git`, `react-state`, `foreign-key` — 실제 이미지 생성 전 콘셉트를 준비한 상태이며, 후속 이미지 제작 후보로 보존한다.
