# defer 웹툰 콘셉트

## 학습 목표

script 다운로드와 실행 시점을 HTML 파싱과 분리하는 defer 속성을 이해한다.

## 초보자 오해

script는 어디에 두든 HTML 파싱에 영향을 주지 않는다고 생각한다.

## 기술적 핵심

defer는 외부 script의 다운로드를 HTML 파싱과 병렬로 진행하고, 실행은 문서 파싱 완료 후로 미룬다. defer script가 여러 개면 문서에 적힌 순서대로 실행된다.

## 비유의 한계

defer가 "스크립트를 느리게 만든다"는 뜻은 아니다. 파싱을 막지 않고 다운로드한 뒤 문서 파싱 후 실행하는 순서 문제임을 정확히 설명한다.

## 대체 텍스트

JavaScript 실행 시점과 defer 속성을 설명하는 4컷 웹툰
