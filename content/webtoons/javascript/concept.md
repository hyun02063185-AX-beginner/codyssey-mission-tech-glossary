# JavaScript 웹툰 콘셉트

## 학습 목표

웹페이지에 사용자 행동과 동작을 더하는 프로그래밍 언어의 역할을 이해한다.

## 초보자 오해

JavaScript는 웹페이지에서만 쓰는 언어라고 생각한다.

## 기술적 핵심

JavaScript는 범용 프로그래밍 언어다. 브라우저에서는 이벤트·DOM·Web API와 함께 페이지를 동적으로 만들며, 브라우저 밖(Node.js 등)에서도 실행된다.

## 비유의 한계

"웹페이지를 움직이게 하는 것"은 입문 설명일 뿐, 범용 언어라는 점을 함께 설명한다.

## 대체 텍스트
