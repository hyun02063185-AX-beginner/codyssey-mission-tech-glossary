# 게임 엔진 — 설치했는데, 게임은요?


게임 엔진을 설치했으니 내 게임도 생겼을까요? 도구와 완성된 작품 사이의 이야기를 풀어 봅니다.

## 1컷 · 동아리방·서 있는 중경과 깊이

초록 후드의 학습자가 빈 게임 편집 화면 앞에서 당황합니다. 노란 카디건의 개발자 동료가 뒤쪽 기획 보드 옆에서 웃으며 답합니다.

학습자: 게임 엔진 깔았어요! / 게임은 어디 있죠?

개발자 동료: 만들 도구를 / 준비한 거예요.

## 2컷 · 편집 화면·근접

모니터를 가까이 보여 줍니다. 게임 장면, 소리 표시, 물체가 바닥에 닿는 표시가 보이며 두 사람의 손만 화면 양쪽에서 들어옵니다.

학습자: 화면도 소리도 / 전부 직접 만들어요? (화면 밖)

개발자 동료: 화면·소리·충돌 같은 / 기능을 제공해요. (화면 밖)

## 3컷 · 레벨 스케치·위에서 내려보기

학습자와 동료가 위에서 내려다보이는 작업대에서 발판·목표 지점을 그립니다. 옆 화면에는 그들이 만드는 단순한 게임 장면이 보입니다.

학습자: 그 기능을 써서 / 제 게임을 만드는군요!

개발자 동료: 네, 규칙과 이야기는 / 우리가 만들어요.

## 4컷 · 소파와 작업 자리·대각선

학습자가 소파에서 게임 패드를 쥐고 느긋하게 기다립니다. 동료는 비어 있는 개발 작업 자리를 가리키며 웃습니다.

학습자: 그럼 제 게임은 / 언제 나오죠?

개발자 동료: 개발자가 소파에서 / 일어나면요.

## 쉬운 뜻

게임 엔진은 게임의 화면 그리기, 소리 재생, 물체의 충돌 처리 등에 쓰이는 기능을 제공하는 소프트웨어 기반이에요. 개발자는 이런 기능을 이용해 게임의 규칙과 콘텐츠를 만들어요.

## 비유의 경계

제공하는 기능은 엔진마다 달라요. 엔진을 사용해도 기획·제작·검수는 필요해요. 이 편에서는 소프트웨어에서 쓰는 여러 ‘엔진’ 중 게임 엔진을 다뤘어요.
