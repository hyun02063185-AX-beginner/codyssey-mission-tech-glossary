# 클라우드 — 제 노트북만 야근하나요?


노트북에서 계산이 오래 걸리자 클라우드 자원을 써 보기로 합니다. 계산이 끝나면 사람도 끝일까요?

## 1컷 · 대학 연구 공간·넓은 장면

학습자가 노트북에서 오래 진행되는 계산을 보며 당황합니다. 기술 멘토는 떨어진 작업 자리에서 다른 계산 자원을 제안합니다.

학습자: 계산이 안 끝나요. / 노트북도 뜨거워요!

기술 멘토: 클라우드의 계산 자원을 / 써 볼까요?

## 2컷 · 원격 자원 화면·어깨너머

학습자의 어깨너머로 브라우저의 서버 자원 화면을 봅니다. 멘토의 갈색 소매 손이 인터넷을 통해 쓰는 원격 자원 표시를 가리킵니다.

학습자: 제 노트북 말고, / 어디서 계산해요?

기술 멘토: 인터넷으로 연결한 / 서버 자원을 써요. (화면 밖)

## 3컷 · 자원 조절·손과 화면 근접

화면에 필요한 계산 자원의 크기를 조절하는 막대와 사용량 표시가 보입니다. 두 사람의 손과 화면에 집중합니다.

학습자: 필요한 만큼 / 자원을 더 쓸 수 있어요? (화면 밖)

기술 멘토: 늘리거나 줄일 수 있죠. / 비용도 확인하면서요. (화면 밖)

## 4컷 · 계산 결과와 쉬려는 학습자·옆모습

계산 결과 그래프가 도착하자 학습자가 의자를 젖히고 쉬려 합니다. 멘토는 결과가 담긴 종이를 들고 검토를 제안합니다.

학습자: 계산은 맡겼으니, / 저는 쉬어도 되죠?

기술 멘토: 결과 해석은 / 우리 몫이에요.

## 쉬운 뜻

클라우드는 네트워크를 통해 서버·저장 공간 같은 컴퓨팅 자원을 필요에 맞게 제공받는 방식이에요. 이 편은 인터넷으로 사용하는 서비스를 예로 들었어요. 필요한 자원을 늘리거나 줄여 사용할 수 있어요.

## 비유의 경계

장비는 실제 데이터센터 등에 있어요. 자원이 저절로 무한히 늘어나는 것은 아니며 서비스의 설정과 한도가 있어요. 자원·시간·요금제 등에 따른 비용이 발생할 수 있어요.
