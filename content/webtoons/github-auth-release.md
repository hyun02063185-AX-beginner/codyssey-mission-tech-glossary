GitHub는 온라인 저장소·수정 제안·검토·합치기의 역할에 집중하고 Git과의 경계는 쉬운 뜻·비유 한계에 둔다. 인증은 신원 확인이며, 인가는 요청별 허용 여부 판단이다. 인가의 그림은 로그인 확인과 보기 허용·수정/삭제 불허를 별도 표시해 인증과 구분한다. 원고의 근거는 각 작품 sources에 기록한 GitHub 공식 문서 및 OWASP 인증·인가 Cheat Sheet다.

그림은 built-in image_gen으로 제작하고 기존 고정 지면 v1/Apple SD Gothic Neo로 조판했다. 세 인물의 얼굴·복장·기술 역할을 유지하면서 배역 조합·장면·자세·인물 노출을 달리했다. 원본·실제 생성 프롬프트·대본·장면 설명·shot·offscreen·버전·승인을 보존한다. 상세 모델명·seed는 도구가 공개하지 않아 추정하지 않았다. 엔진·클라우드의 그림·합본·개별 컷 PNG 12개는 완료 검토 커밋 dd62d1d와 바이트 동일하며, 재생성·재조판하지 않았다.
