# VSCode

## 한 줄 설명

코드 편집·디버깅·확장을 제공하는 Microsoft의 개발자 도구.

## 쉽게 설명하면

파일을 고치고 terminal·debugger·확장을 한 화면에서 쓰는 편집기다.

## 정확한 설명

workspace 설정, language server, extension, integrated terminal을 조합해 개발 흐름을 지원한다.

## 언제 쓰나

프로젝트를 열고 formatter와 test 실행 명령을 구성한다.

## 기억할 경계

에디터 설정은 프로젝트의 runtime 의존성과는 별개다.

## 이 미션에서는 왜 필요한가

예비 M01의 4.10 항목에서 GitHub 로그인과 저장소 연동을 보여 주는 증거로 씁니다. 편집기를 쓰는 것 자체가 채점 대상이 아니라, 계정이 연결되고 저장소가 열려 있다는 상태가 증거입니다.

## 코드 예

```text
증거로 남길 것
  좌하단 계정 표시에 GitHub 계정이 연결돼 있는지
  소스 제어 패널에 저장소가 인식돼 있는지
  캡처 전에 토큰이나 메일 주소가 화면에 남아 있지 않은지
```
