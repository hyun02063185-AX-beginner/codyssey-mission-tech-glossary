# VSCode

## 한 줄 설명

코드 편집·디버깅·확장을 제공하는 Microsoft의 개발자 도구.

## 쉽게 설명하면

파일을 고치고 terminal·debugger·확장을 한 화면에서 쓰는 편집기다.

## 정확한 설명

workspace 설정, language server, extension, integrated terminal을 조합해 개발 흐름을 지원한다.

## 언제 쓰나

프로젝트를 열고 formatter와 test 실행 명령을 구성한다.

## 기억할 경계

에디터 설정은 프로젝트의 runtime 의존성과는 별개다.

## 이 미션에서는 왜 필요한가

AI·데이터 도구와 개발·운영 환경을 선택하고, 결과·비용·장애를 정확한 기준으로 설명하는 데 필요합니다.
