# Bootstrap

## 한 줄 설명

미리 만든 CSS component와 utility를 제공하는 UI framework.

## 쉽게 설명하면

`Bootstrap`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

class 기반 스타일과 component를 제공하지만 접근성과 디자인 요구를 자동으로 충족하지는 않는다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
Bootstrap
```

## 관련 용어

- `css`
- `tailwind-css`
