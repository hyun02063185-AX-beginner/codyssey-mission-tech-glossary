# line diff

## 한 줄 설명

추가·삭제 line으로 표현한 text 차이.

## 쉽게 설명하면

무엇이 지워지고 무엇이 더해졌는지 줄 단위로 보여 주는 표현입니다. 앞의 기호가 그것을 나타냅니다.

## 정확한 설명

두 상태를 비교해 줄 단위 추가와 삭제로 나타낸다. 줄 안에서 글자 몇 개만 바뀌어도 그 줄 전체가 지워지고 더해진 것으로 표시되며, 줄바꿈 문자나 줄 끝 공백이 달라도 다른 줄로 본다.

## 이 미션에서는 왜 필요한가

본과정 M10의 보너스 항목인 텍스트 비교에서 씁니다. 두 버전을 줄 단위로 맞춰 보고 어느 줄이 빠지고 어느 줄이 들어왔는지 표시하는 방식이라, 한 줄을 고치면 뺀 줄과 넣은 줄 두 줄로 보이는 이유도 여기서 나옵니다.

## 코드 예

```bash
git diff
# --- a/src/app.py
# +++ b/src/app.py
# @@ -10,3 +10,4 @@        ← 원본 10번째 줄부터 3줄 → 새로 4줄
#  def login():             ← 공백으로 시작하면 안 바뀐 줄
# -    timeout = 30         ← - 는 지워진 줄
# +    timeout = 60         ← + 는 더해진 줄
# +    retries = 3

# 줄 안의 차이를 보려면
git diff --word-diff
git diff --color-words
```

## 주의할 점 / 경계 조건

한 줄에 긴 문장을 쓰면 단어 하나만 고쳐도 그 줄 전체가 바뀐 것으로 보입니다. 문서를 문장 단위로 줄을 나눠 쓰면 차이가 읽기 쉬워집니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

바뀐 글자만 표시된다고 생각하기 쉽지만, 줄 단위입니다. 줄 안의 차이를 보려면 별도 옵션이 필요합니다.
