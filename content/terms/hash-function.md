# Hash Function

## 한 줄 설명

임의 길이의 키를 일정 범위의 해시 값으로 바꾸는 함수.

## 쉽게 설명하면

긴 이름표를 서랍 번호로 바꾸는 계산 규칙이다.

## 정확한 설명

좋은 해시 함수는 입력을 버킷에 고르게 퍼뜨리고 계산 비용이 낮다. 자료구조용 해시는 암호학적 해시와 목적이 다르다.

## 대표 사용

문자열 키를 해시맵의 인덱스로 바꾼다.

## 주의할 점

해시 값이 같아도 원래 키가 같다는 뜻은 아니다.

## 이 미션에서는 왜 필요한가

키를 어느 칸에 넣을지 정하는 계산이 여기서 나옵니다. 이 함수가 값을 한쪽으로 몰면 버킷 하나에만 항목이 쌓여, 해시맵을 만들어 놓고도 목록을 처음부터 훑는 것과 같아집니다. 빠르기를 결정하는 것은 자료구조의 이름이 아니라 이 분포입니다.

## 코드 예

```python
# 파이썬 내장 hash 는 실행할 때마다 문자열 시드가 달라진다(보안 목적).
# 저장한 값을 다음 실행에서 다시 읽어야 한다면 고정된 해시를 써야 한다.
import hashlib

def stable_hash(key: str) -> int:
    return int.from_bytes(hashlib.blake2b(key.encode(), digest_size=8).digest(), 'big')

print(stable_hash('user:1') % 8)   # 몇 번을 실행해도 같은 버킷
```
