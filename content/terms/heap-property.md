# Heap Property

## 한 줄 설명

부모와 자식 사이의 우선순위를 보장하는 힙의 불변 조건.

## 쉽게 설명하면

나무의 각 부모가 자식보다 먼저 처리될 조건을 지키는 규칙이다.

## 정확한 설명

최소 힙에서는 부모 키가 자식 키 이하이고, 최대 힙에서는 반대다. 삽입·삭제 뒤에는 sift-up 또는 sift-down으로 복구한다.

## 판단 기준

우선순위 큐가 항상 가장 작은 작업을 꺼내게 한다.

## 주의할 점

형제 노드끼리의 순서는 힙 속성이 보장하지 않는다.

## 이 미션에서는 왜 필요한가

힙이 매번 정렬된 상태를 유지하는 것이 아니라 "부모가 자식보다 작다"만 지킨다는 점이 핵심입니다. 이 약한 조건 덕분에 삽입·삭제가 O(log n)에 끝나며, 반대로 전체가 정렬돼 있을 것이라 기대하면 잘못된 결과를 읽게 됩니다.

## 코드 예

```python
import heapq

h = [5, 3, 8, 1]
heapq.heapify(h)
print(h)        # [1, 3, 8, 5] — 정렬된 목록이 아니다
print(h[0])     # 1 — 보장되는 것은 맨 앞이 최솟값이라는 것뿐

# 정렬된 결과가 필요하면 하나씩 꺼내야 한다
print([heapq.heappop(h) for _ in range(len(h))])   # [1, 3, 5, 8]
```
