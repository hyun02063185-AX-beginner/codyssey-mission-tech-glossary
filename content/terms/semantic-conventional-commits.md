# Semantic / Conventional Commits

## 한 줄 설명

변경 의미를 type과 scope로 표현하는 commit message 관례.

## 쉽게 설명하면

`Semantic / Conventional Commits`은(는) 변경을 기록하고 동료와 안전하게 공유하는 Git 작업 흐름의 한 부분입니다.

## 정확한 설명

변경 의미를 type과 scope로 표현하는 commit message 관례. local history, remote state, review 규칙의 역할을 구분해 사용해야 합니다.

## 이 미션에서는 왜 필요한가

M04와 M06에서 변경을 안전하게 기록하고 review 가능한 단위로 공유하며 충돌을 복구하는 기준입니다.
