# npm

## 한 줄 설명

npm은 JavaScript 프로젝트의 패키지를 설치하고 `package.json`에 정의한 스크립트를 실행하는 도구와 공개 패키지 저장소 생태계입니다.

## 쉽게 설명하면

`npm install`로 필요한 라이브러리를 받고, `npm run build`로 프로젝트에 적어 둔 빌드 명령을 실행합니다.

## 정확한 설명

npm CLI는 패키지 설치·업데이트·스크립트 실행을 담당하고, npm registry는 패키지를 배포하고 받는 저장소입니다. `package.json`은 프로젝트 이름, 의존성, 실행 스크립트를 기록합니다. Node.js는 JavaScript 런타임이고 npm은 그 위에서 패키지 작업을 돕는 도구이므로 같은 것이 아닙니다.

## 이 미션에서는 왜 필요한가

본과정 M02에서 React와 의존성을 설치하고 개발·빌드 명령을 실행합니다.

## 관련 용어

- node-js
- javascript
- cli

## 흔한 오해

`npm install`은 프로그램을 실행하는 명령이 아닙니다. 보통 의존성을 내려받아 프로젝트에 준비하는 명령입니다.
