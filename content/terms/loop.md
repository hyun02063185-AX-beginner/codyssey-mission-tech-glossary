# 반복문

## 한 줄 설명

조건이 유지되거나 컬렉션에 항목이 있는 동안 같은 처리 구조를 반복 실행하는 제어 구조입니다.

## 쉽게 설명하면

목록의 물건을 하나씩 확인할 때까지 같은 동작을 되풀이하는 것과 같습니다.

## 정확한 설명

Loop는 `for`처럼 순회 가능한 값의 각 항목을 처리하거나 `while`처럼 조건이 참인 동안 실행합니다. 종료 조건과 상태 갱신이 정확해야 무한 반복을 피할 수 있습니다.

## 이 미션에서는 왜 필요한가

예비 M02 메뉴를 사용자가 종료할 때까지 다시 보여 주는 흐름을 구현합니다.

## 코드 예

```python
while True:
    command = input('> ')
    if command == 'quit':
        break
```

## 주의할 점 / 경계 조건

반복 안에서 컬렉션을 동시에 변경하면 항목 누락이나 예외가 날 수 있어 순회 방식에 맞는 처리가 필요합니다.

## 관련 용어

- `if-elif-else`
- `generator`
- `iterator`

## 흔한 오해

Loop는 재귀와 같지 않으며, 각각 상태·호출 스택·종료 방식을 다르게 관리합니다.
