# Ubuntu

## 한 줄 설명

Debian 계열의 널리 쓰이는 Linux distribution.

## 쉽게 설명하면

리눅스 배포판 중 하나로, 설치와 패키지 관리가 쉬워 처음 쓰기에 알맞습니다. 자료가 많아 막혔을 때 검색이 잘 됩니다.

## 정확한 설명

데비안 계열이라 패키지 관리에 apt를 쓴다. 장기 지원 판은 몇 년간 보안 갱신을 제공하므로 서버에는 그쪽을 고르는 것이 보통이고, 배포판마다 기본 방화벽 도구와 서비스 관리 방식이 달라 다른 계열의 명령이 그대로 듣지 않는다.

## 이 미션에서는 왜 필요한가

이 회차의 주요 기술로 명시된 환경입니다. 실습 문서의 명령이 이 배포판 기준으로 적혀 있으므로, 다른 배포판에서 실습한다면 패키지 관리와 방화벽 도구가 달라진다는 점을 감안해야 합니다.

## 코드 예

```bash
cat /etc/os-release | head -3
# PRETTY_NAME="Ubuntu 24.04 LTS"   ← LTS 인지 확인한다

sudo apt-get update && sudo apt-get install -y htop

# 다른 계열에서는 명령이 다르다
#   Debian/Ubuntu   apt-get
#   RHEL/CentOS     dnf 또는 yum
#   Alpine          apk
```

## 주의할 점 / 경계 조건

장기 지원 판이 아닌 것을 쓰면 몇 달 만에 보안 갱신이 끊깁니다. 서버로 쓸 것이면 판 번호를 확인해야 합니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

리눅스면 명령이 다 같다고 생각하기 쉽지만, 패키지 설치와 서비스 관리는 계열마다 다릅니다. `apt`는 이 계열에서만 듭니다.
