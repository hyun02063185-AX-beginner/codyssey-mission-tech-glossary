# logrotate

## 한 줄 설명

log file을 교체·압축·보관·삭제하는 운영 도구.

## 쉽게 설명하면

로그 파일이 무한히 커지지 않도록 일정 주기로 새 파일로 갈아 주고 오래된 것을 지우는 도구입니다.

## 정확한 설명

크기나 기간 조건에 따라 현재 파일의 이름을 바꾸고 새 파일을 만든다. 이때 기존 파일을 쓰고 있던 프로세스는 이름이 바뀐 파일에 계속 쓰므로, 새 파일로 옮겨 쓰게 하려면 해당 프로세스에 신호를 보내거나 내용을 비우는 방식을 써야 한다.

## 이 미션에서는 왜 필요한가

이 회차의 점검이 매분 돌면 로그가 계속 쌓입니다. 방치하면 디스크가 차서 서버 전체가 멈추므로, 점검을 만드는 것과 그 점검이 남기는 것을 관리하는 것이 한 쌍입니다.

## 코드 예

```text
# /etc/logrotate.d/monitor
/var/log/monitor.log {
    daily
    rotate 7            # 7개까지만 보관
    compress
    missingok           # 파일이 없어도 오류로 보지 않는다
    notifempty
    copytruncate        # 내용을 비우는 방식 — 열린 파일을 그대로 쓴다
}

# 설정을 시험한다 (실제로 돌리지 않고)
sudo logrotate -d /etc/logrotate.d/monitor

# 강제로 한 번 실행
sudo logrotate -f /etc/logrotate.d/monitor
```

## 주의할 점 / 경계 조건

교체한 뒤 프로세스가 여전히 옛 파일에 쓰면 새 파일은 비어 있고 디스크는 그대로 찹니다. 열려 있는 파일이 바뀌지 않기 때문입니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

설정만 적으면 즉시 도는 줄 알기 쉽지만, 정해진 주기에 한 번 확인합니다. 시험하려면 강제로 실행해 봐야 합니다.
