# SSH 키

## 한 줄 설명

SSH에서 password 대신 공개키 암호로 사용자를 증명하는 key pair.

## 쉽게 설명하면

비밀번호 대신 쓰는 한 쌍의 열쇠입니다. 공개키를 서버에 올려 두고 개인키로 자신을 증명합니다.

## 정확한 설명

공개키와 개인키가 한 쌍으로 만들어진다. 공개키는 어디에 올려도 되고, 개인키는 절대 나가면 안 된다. 서버가 보낸 값을 개인키로 서명해 돌려주면 서버가 공개키로 검증하므로, 개인키 자체는 네트워크를 지나가지 않는다.

## 이 미션에서는 왜 필요한가

이 회차의 저장소 인증 보너스입니다. 토큰과 달리 만료를 신경 쓰지 않아도 되고 매번 입력할 필요도 없으며, 추측으로 뚫을 수 없다는 점이 비밀번호와 가장 다릅니다.

## 코드 예

```bash
ssh-keygen -t ed25519 -C "codyssey"
# ~/.ssh/id_ed25519       개인키 — 절대 나가면 안 된다
# ~/.ssh/id_ed25519.pub   공개키 — 서버에 올린다

cat ~/.ssh/id_ed25519.pub     # 이것을 등록한다
chmod 600 ~/.ssh/id_ed25519   # 느슨하면 사용이 거부된다

ssh -T git@github.com         # 연결 확인
# Hi username! You've successfully authenticated

# 개인키는 네트워크를 지나가지 않는다.
# 서버가 보낸 값에 서명해 돌려줄 뿐이다
```

## 주의할 점 / 경계 조건

개인키 파일의 권한이 느슨하면 사용이 거부됩니다. 다른 컴퓨터로 옮길 때 권한도 함께 맞춰야 합니다.

## 관련 용어

- `authentication`

## 흔한 오해

두 파일 중 어느 것을 올려도 된다고 생각하기 쉽지만, `.pub`이 붙은 쪽만 올립니다. 개인키를 올리면 누구나 나인 척할 수 있습니다.
