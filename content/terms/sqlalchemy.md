# SQLAlchemy

## 한 줄 설명

SQLAlchemy는 Python 프로그램이 관계형 데이터베이스에 SQL을 보내고, 객체 형태로 데이터를 다룰 수 있게 돕는 라이브러리입니다.

## 쉽게 설명하면

Python class로 테이블 구조를 표현하고, 필요한 경우 SQL을 직접 쓰거나 라이브러리의 조회 문법으로 데이터를 다룰 수 있습니다.

## 정확한 설명

SQLAlchemy는 Core와 ORM 기능을 제공합니다. ORM은 class와 테이블을 연결하지만, 데이터베이스가 사라지거나 SQL 개념이 필요 없어지는 것은 아닙니다. 세션은 변경을 모아 트랜잭션으로 처리하는 작업 단위이므로, 요청이 끝난 뒤 적절히 닫고 오류 시 롤백해야 합니다.

## 이 미션에서는 왜 필요한가

본과정 M12에서 FastAPI 백엔드가 데이터베이스 모델을 읽고 저장하는 데 사용합니다.

## 관련 용어

- sql
- relational-database
- database-session
- fastapi

## 흔한 오해

ORM을 쓰면 SQL 인젝션이 자동으로 완전히 사라지는 것은 아닙니다. 매개변수 바인딩을 지키고, 임의의 SQL 문자열은 여전히 주의해야 합니다.
