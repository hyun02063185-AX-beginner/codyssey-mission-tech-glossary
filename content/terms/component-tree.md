# Component Tree

## 한 줄 설명

UI framework에서 component가 부모·자식 관계로 구성된 구조.

## 쉽게 설명하면

`Component Tree`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

props가 아래로 흐르고 context가 provider 아래로 전달되는 경계를 보여 준다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.
