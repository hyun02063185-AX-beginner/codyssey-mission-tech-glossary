# 내적

## 한 줄 설명

두 벡터의 같은 위치 원소를 곱해 모두 더한 값인 내적.

## 쉽게 설명하면

두 방향이 얼마나 같은 쪽을 향하는지 수치로 재는 연산이다.

## 정확한 설명

벡터 a와 b의 내적은 Σaᵢbᵢ이며 차원이 같아야 한다. 유사도, projection, 신경망 선형 연산의 기본이 된다.

## 언제 쓰나

attention에서 query와 key의 친밀도 점수를 계산한다.

## 기억할 경계

내적이 크다고 길이가 다른 두 벡터의 cosine 유사도가 반드시 큰 것은 아니다.

## 이 미션에서는 왜 필요한가

필터 한 칸의 계산이 바로 이것입니다. 겹쳐 놓은 두 묶음의 같은 자리끼리 곱해 모두 더하는 한 번의 연산이며, 시뮬레이터가 세는 곱셈-덧셈 횟수의 단위이기도 합니다.

## 코드 예

```python
def dot(a, b):
    assert len(a) == len(b)        # 길이가 다르면 정의되지 않는다
    return sum(x * y for x, y in zip(a, b))

# 합성곱의 한 칸은 두 3x3 을 펴서 내적한 것과 같다
patch  = [1, 0, 2, 0, 1, 0, 2, 0, 1]
kernel = [0, 1, 0, 1, -4, 1, 0, 1, 0]
print(dot(patch, kernel))      # 곱셈 9번 + 덧셈 8번
```

- `tensor`
