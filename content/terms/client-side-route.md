# 클라이언트 측 라우트

## 한 줄 설명

클라이언트 측 라우트는 SPA에서 현재 URL에 따라 브라우저 안에서 어떤 화면을 보여 줄지 정하는 규칙입니다.

## 쉽게 설명하면

`/todos`에서 `/settings`로 이동해도 새 HTML 문서를 다시 받지 않고, React가 URL을 보고 다른 컴포넌트를 보여 주는 방식입니다.

## 정확한 설명

클라이언트 라우터는 링크 클릭과 브라우저 뒤로 가기를 처리하고, History API로 URL을 바꾼 뒤 알맞은 화면을 렌더링합니다. 새로고침이나 주소 직접 입력도 동작하려면 서버가 SPA의 진입 HTML을 돌려주도록 배포 설정을 맞춰야 할 수 있습니다.

## 이 미션에서는 왜 필요한가

본과정 M02에서 여러 화면을 URL별로 나누고 최소 다섯 개의 라우트를 구현합니다.

## 관련 용어

- single-page-application
- react
- server-side-rendering

## 흔한 오해

클라이언트 측 라우트가 있다고 서버 라우트가 없어지는 것은 아닙니다. API 요청이나 새로고침 처리에는 서버의 역할이 남습니다.
