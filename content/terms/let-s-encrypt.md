# Let’s Encrypt

## 한 줄 설명

무료 TLS certificate를 발급·갱신하는 certificate authority.

## 쉽게 설명하면

무료로 인증서를 발급해 주는 기관입니다. 사람이 신청하는 대신 프로그램이 자동으로 발급받고 갱신합니다.

## 정확한 설명

도메인 소유를 자동으로 증명하는 프로토콜을 쓴다. 발급 도구가 지정한 파일을 웹 경로에 두거나 DNS 레코드를 추가하면 기관이 그것을 확인해 발급하며, 인증서 수명이 짧은 대신 갱신이 자동화되어 있다.

## 이 미션에서는 왜 필요한가

이 회차에서 HTTPS를 붙이는 현실적인 방법입니다. 수명이 짧아 수동으로 관리하면 반드시 만료되므로, 발급보다 갱신이 자동으로 돌고 있는지 확인하는 쪽이 실제 작업입니다.

## 코드 예

```bash
sudo certbot --nginx -d example.com

# 갱신이 실제로 되는지 미리 확인한다 (실제 발급 없이)
sudo certbot renew --dry-run

# 자동 갱신 타이머가 돌고 있는지
systemctl list-timers | grep certbot

# 만료일 확인
sudo certbot certificates

# 설정을 시험할 때는 --test-cert 를 쓴다. 발급 횟수 제한에 걸리지 않는다
```

## 주의할 점 / 경계 조건

같은 도메인에 대한 발급 횟수에 제한이 있습니다. 설정을 고치며 반복 시도하면 제한에 걸리므로, 연습은 테스트 환경에서 합니다.

## 관련 용어

- `authentication`

## 흔한 오해

한 번 발급받으면 끝이라고 생각하기 쉽지만, 수명이 몇 달입니다. 갱신이 자동으로 도는지 확인하지 않으면 어느 날 사이트가 경고 화면이 됩니다.
