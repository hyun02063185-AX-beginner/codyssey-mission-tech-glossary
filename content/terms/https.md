# HTTPS

## 한 줄 설명

HTTPS는 HTTP 통신에 TLS 암호화와 서버 신원 검증을 적용하는 웹 통신 방식입니다.

## 쉽게 설명하면

웹사이트와 대화하는 내용을 잠그고, 상대 서버가 맞는지 확인하는 보호된 HTTP입니다.

## 정확한 설명

HTTPS는 HTTP의 request/response 의미를 바꾸기보다 TLS로 전송 구간의 기밀성·무결성·서버 인증을 제공합니다. 브라우저는 인증서 체인을 검증해 신뢰할 수 있는 도메인인지 확인합니다. HTTPS가 적용돼도 서버의 권한 검사, XSS 방지, 안전한 비밀번호 저장이 자동으로 해결되지는 않습니다.

## 이 미션에서는 왜 필요한가

M05에서 배포한 서비스의 통신 보호와 인증서 설정을 확인하고, API key·사용자 정보를 안전하게 다루는 기본 전제입니다.

## 관련 용어

- `http`
- `authentication`
- `api-key`
- `cors`

## 흔한 오해

주소창의 자물쇠가 웹사이트의 모든 콘텐츠와 운영 방식을 안전하다고 보증하는 것은 아닙니다. HTTPS는 통신 경로 보호의 한 층입니다.
