# 재사용 컴포넌트

## 한 줄 설명

재사용 컴포넌트는 같은 역할의 UI와 동작을 한 번 구현해 여러 화면에서 다시 쓰도록 나눈 단위입니다.

## 쉽게 설명하면

여러 화면에 같은 모양의 버튼이 필요하다면, 버튼 코드를 복사하기보다 `Button` 컴포넌트 하나를 만들어 필요한 글자와 동작만 전달합니다.

## 코드 예

```jsx
function Button({ children, onClick }) {
  return <button onClick={onClick}>{children}</button>;
}
```

## 정확한 설명

재사용은 단순히 코드를 짧게 만드는 일이 아니라, 같은 UI 규칙을 한곳에서 유지하게 합니다. 다만 서로 다른 요구를 억지로 하나의 컴포넌트에 넣으면 props가 지나치게 복잡해질 수 있으므로, 함께 바뀌는 역할 단위인지 먼저 판단합니다.

## 이 미션에서는 왜 필요한가

본과정 M02에서 여러 화면에 반복되는 UI를 컴포넌트로 분리해 일관성 있게 구현합니다.

## 관련 용어

- react
- react-state
- css

## 흔한 오해

두 번 쓰인다고 무조건 컴포넌트로 뽑아야 하는 것은 아닙니다. 반복되는 역할과 변경 이유가 같은지를 먼저 봅니다.
