# max_tokens

## 한 줄 설명

한 요청 또는 생성에서 사용할 수 있는 토큰 수의 상한.

## 쉽게 설명하면

답변이 너무 길어지지 않게 잡는 글자 예산에 가깝다.

## 정확한 설명

입력 토큰과 출력 토큰의 한도는 모델 API마다 분리되거나 함께 계산된다. 상한은 비용·지연 시간·잘림 가능성에 영향을 준다.

## 대표 사용

긴 문서 요약에서 출력 길이를 제한한다.

## 주의할 점

token은 문자 수나 단어 수와 정확히 같지 않다.

## 이 미션에서는 왜 필요한가

이 회차는 출력 길이에 상한을 둡니다. 상한에 걸리면 오류가 나는 것이 아니라 문장이 중간에서 잘린 채 돌아오므로, 잘렸는지 확인하지 않으면 반쪽짜리 커밋 메시지가 그대로 쓰입니다.

## 코드 예

```python
response = ask(prompt, max_tokens=300)

# 상한에 걸리면 오류가 아니라 '잘린 정상 응답' 으로 온다
if response.get('finish_reason') == 'length':
    raise RuntimeError('출력이 잘렸습니다. max_tokens 를 늘리거나 입력을 줄이세요.')

# 토큰은 글자 수가 아니다. 한글은 영어보다 토큰을 더 쓴다
```
