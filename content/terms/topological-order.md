# topological order

## 한 줄 설명

DAG의 모든 간선이 앞에서 뒤로 향하도록 나열한 정점 순서.

## 쉽게 설명하면

선행 작업을 먼저 두고 후속 작업을 뒤에 세운 실행 목록이다.

## 정확한 설명

u→v가 있으면 u는 반드시 v보다 앞선다. 하나의 DAG에도 여러 위상 순서가 존재할 수 있다.

## 작은 사례

패키지 설치나 빌드 작업의 안전한 실행 순서를 만든다.

## 주의할 점

순환 의존성이 있으면 가능한 위상 순서는 없다.

## 이 미션에서는 왜 필요한가

로그를 출력할 때 자식 커밋이 부모보다 먼저 나오면 기록을 읽는 사람이 순서를 거꾸로 이해합니다. 모든 부모가 자기 자식보다 앞에 오도록 줄 세운 결과가 이 순서이며, 답이 하나가 아니라는 점이 중요합니다. 같은 기록에서도 유효한 순서가 여러 개 나옵니다.

## 코드 예

```text
C1 → C2 → C4
  ↘ C3 ↗

유효한 순서   C1, C2, C3, C4
              C1, C3, C2, C4      ← 둘 다 맞다
무효한 순서   C1, C4, C2, C3      ← C4 가 부모 C2 보다 앞에 있다

순서가 하나로 정해지지 않으므로, 출력 순서를 고정하려면
날짜나 커밋 ID 같은 추가 기준을 함께 써야 한다.
```
