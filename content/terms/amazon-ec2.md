# EC2

## 한 줄 설명

AWS에서 virtual server instance를 실행하는 compute service.

## 쉽게 설명하면

클라우드에서 빌려 쓰는 가상 서버입니다. 운영체제부터 위쪽은 전부 내가 관리합니다.

## 정확한 설명

가상 머신 하나를 빌려 운영체제 위의 모든 것을 직접 다룬다. 인스턴스 종류가 CPU·메모리 크기를, 이미지가 초기 운영체제를 정하며, 키 쌍·보안 그룹·서브넷을 만들 때 함께 지정해야 접속과 통신이 가능해진다.

## 이 미션에서는 왜 필요한가

이 회차에서 웹 서버를 실제로 띄우는 자리입니다. 만든 직후에는 아무것도 열려 있지 않아 접속조차 안 되는데, 그때 무엇이 빠졌는지 짚어 가는 과정이 네트워크 구성을 이해하는 실습이 됩니다.

## 코드 예

```text
만든 뒤 접속이 안 될 때 확인 순서

  1. 공인 IP 가 붙어 있는가          없으면 밖에서 주소가 없다
  2. 보안 그룹에 22 번이 열렸는가     내 IP 에서 들어올 수 있는가
  3. 서브넷에 인터넷 경로가 있는가    0.0.0.0/0 → IGW
  4. 인스턴스가 실행 중인가          상태 검사 2/2 통과
  5. 키 파일 권한이 600 인가         느슨하면 클라이언트가 거부한다

하나라도 빠지면 "응답 없음" 으로 똑같이 보인다.
증상이 같으므로 순서대로 지워 나가야 한다.
```

## 주의할 점 / 경계 조건

만들 때 받은 키 파일은 다시 받을 수 없습니다. 잃어버리면 그 인스턴스에 접속할 방법이 사라집니다.

## 관련 용어

- `http`
- `tcp`

## 흔한 오해

만들면 바로 접속된다고 생각하기 쉽지만, 방화벽 규칙과 공인 주소, 경로가 모두 갖춰져야 합니다. 하나만 빠져도 응답이 없습니다.

## 동료평가 질문
