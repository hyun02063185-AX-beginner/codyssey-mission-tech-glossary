# 상태 변경

## 한 줄 설명

프로그램이 기억하는 값이 이전 값에서 새 값으로 바뀌는 사건입니다.

## 쉽게 설명하면

장바구니 수량이 1에서 2가 되는 것처럼, 화면이나 프로그램이 기억하던 사실이 달라지는 일입니다.

## 정확한 설명

State change는 UI·도메인·서버 상태의 값이 이벤트나 처리 결과로 바뀌는 것을 말합니다. 변경 자체와 화면 렌더링, 영속 저장, 네트워크 전송은 서로 다른 단계일 수 있습니다.

## 동작 원리

1. 이벤트가 의도를 전달합니다.
2. 상태 업데이트가 이전 값을 기준으로 새 값을 계산합니다.
3. UI 계층이 새 상태를 사용해 다음 화면을 결정합니다.

## 이 미션에서는 왜 필요한가

M01의 사용자 클릭 처리에서 이벤트가 상태를 바꾸고 화면에 반영되는 흐름을 설명합니다.

## 코드 예

```js
setCount(previous => previous + 1);
```

## 주의할 점 / 경계 조건

객체를 제자리에서 바꾸면 프레임워크가 변경을 감지하지 못할 수 있으므로 해당 상태 관리 방식의 불변성 규칙을 확인해야 합니다.

## 관련 용어

- `state-transition`
- `ui-state`
- `react-state`
- `user-event`

## 흔한 오해

상태가 바뀌었다고 즉시 DOM이 같은 방식으로 갱신된다고 단정할 수는 없습니다.

## 동료평가 질문
