# Accessibility / a11y

## 한 줄 설명

다른 장애·입력 방식·환경의 사람도 웹을 사용할 수 있게 하는 설계.

## 쉽게 설명하면

`Accessibility / a11y`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

semantic HTML, keyboard, focus, label, contrast, accessible name을 함께 다룬다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
Accessibility / a11y
```

## 관련 용어

- `html-form`
- `interaction`
