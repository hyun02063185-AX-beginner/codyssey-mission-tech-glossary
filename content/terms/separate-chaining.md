# chaining

## 한 줄 설명

같은 해시 버킷의 여러 항목을 연결 구조에 저장하는 충돌 해결법.

## 쉽게 설명하면

한 서랍에 물건이 겹치면 서랍 안에 작은 목록을 이어 두는 방식이다.

## 정확한 설명

각 버킷에 연결 리스트나 동적 배열을 두고, 같은 해시 값의 키를 그 안에서 비교한다.

## 대표 사용

충돌을 허용하면서 해시맵에 키-값 쌍을 저장한다.

## 주의할 점

버킷 하나가 길어지면 탐색 성능이 선형으로 나빠진다.

## 이 미션에서는 왜 필요한가

충돌한 키들을 같은 칸 안에 목록으로 이어 두는 방식이며, 이 회차의 저장소가 택하는 해결책입니다. 구현이 간단한 대신 한 칸이 길어지면 그 칸만 선형 탐색이 되므로, 뒤에 나오는 적재율과 리사이징이 함께 필요해집니다.

## 코드 예

```python
def get(buckets, key):
    bucket = buckets[hash(key) % len(buckets)]
    for k, v in bucket:        # 같은 칸에 있어도 키는 다를 수 있다
        if k == key:
            return v
    raise KeyError(key)

# 이 for 문이 도는 횟수가 곧 성능이다. 평균 1~2 를 넘기지 않게 유지한다
```

## 관련 용어

- `collision`
- `hash-bucket`
