# 768px / 1024px 브레이크포인트

## 한 줄 설명

Breakpoint는 화면 조건에 따라 레이아웃 규칙을 전환하는 반응형 설계 기준점입니다.

## 쉽게 설명하면

화면이 좁아져 메뉴나 카드가 더 이상 편하게 보이지 않는 순간에 배치를 바꾸는 경계선입니다.

## 정확한 설명

CSS media query는 viewport 폭 같은 조건을 검사해 다른 규칙을 적용합니다. 브레이크포인트는 특정 기기 이름을 외워 정하기보다 실제 콘텐츠가 겹치거나 읽기 어려워지는 지점에서 정해야 합니다.

M01은 768px와 1024px를 예시 기준으로 사용합니다. 경계 바로 앞뒤 폭에서도 메뉴·카드·여백이 자연스럽게 이어지는지 확인해야 하며, 그 사이 폭을 무시하면 반응형이 깨질 수 있습니다.

## 이 미션에서는 왜 필요한가

내비게이션과 프로젝트 카드가 모바일·태블릿·데스크톱에서 각각 알맞게 전환되도록 합니다.

## 코드 예

```css
@media (min-width: 768px) { .projects { grid-template-columns: repeat(2, 1fr); } }
```

## 관련 용어

- mobile-first
- responsive-web-design
- css-grid

## 흔한 오해

768px와 1024px는 모든 사이트의 정답이 아니라 M01에서 검증할 기준입니다.
