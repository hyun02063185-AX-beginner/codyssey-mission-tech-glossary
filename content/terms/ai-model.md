# model

## 한 줄 설명

입력을 받아 학습한 규칙으로 예측·생성·분류를 수행하는 계산 모델.

## 쉽게 설명하면

데이터에서 패턴을 배운 뒤 새 입력에 답을 내는 엔진이다.

## 정확한 설명

모델은 구조·파라미터·추론 절차의 조합이다. 학습과 추론은 입력·비용·실패 양상이 다르다.

## 작동 흐름

입력의 형태, 기대 결과, 비용과 실패 조건을 분리해 이 개념이 맡는 역할을 판단합니다.

## 실제 사용

서비스에서 사용자의 문장을 분류하거나 답변을 생성한다.

## 경계와 오해

모델 이름만으로 정확성·안전성·최신성이 보장되지는 않는다.

## 동료평가 질문

모델을 바꿨을 때 같은 입력에서 무엇이 달라졌는지를, 결과·시간·토큰 사용량을 함께 놓고 설명할 수 있나요?

## 이 미션에서는 왜 필요한가

이 회차는 명령줄 옵션으로 모델을 바꿀 수 있게 만듭니다. 모델을 바꾸면 결과의 품질뿐 아니라 응답 시간과 비용, 그리고 지원하는 기능까지 달라지므로, 바꿔서 어떻게 달라졌는지 비교할 수 있게 기록을 남기는 편이 좋습니다.

## 코드 예

```bash
mytool commit --model fast      # 빠르고 싸다, 형식이 흔들릴 수 있다
mytool commit --model strong    # 느리고 비싸다, 형식이 안정적이다

# 비교할 때는 같은 입력으로, 결과와 함께 시간·토큰도 기록한다
# model | 소요(s) | 입력토큰 | 출력토큰 | 형식 통과
```
