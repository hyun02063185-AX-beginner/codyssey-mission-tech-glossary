# 포트 매핑

## 한 줄 설명

포트 매핑은 호스트의 포트로 들어온 요청을 컨테이너 안 서비스의 포트로 전달하는 설정입니다.

## 쉽게 설명하면

컨테이너 안 웹 서버가 80번 포트에서 기다릴 때, 내 PC의 8080번 포트로 들어온 요청을 그 서버에 연결하는 방법입니다.

## 코드 예

```sh
docker run -p 8080:80 my-web
```

## 정확한 설명

`-p 8080:80`에서 앞의 8080은 호스트 포트, 뒤의 80은 컨테이너 포트입니다. 컨테이너 안에서 서비스가 실제로 해당 포트에 바인딩되어 있어야 하며, 이미 호스트에서 사용 중인 포트는 다시 연결할 수 없습니다.

## 이 미션에서는 왜 필요한가

예비 M01에서 컨테이너로 실행한 서비스를 브라우저나 `curl`로 접속해 확인합니다.

## 관련 용어

- docker-container
- port-80-http
- localhost

## 흔한 오해

포트를 공개했다고 서비스가 인터넷 전체에 자동으로 열리는 것은 아닙니다. 호스트 방화벽과 클라우드 보안 규칙도 따로 확인해야 합니다.
