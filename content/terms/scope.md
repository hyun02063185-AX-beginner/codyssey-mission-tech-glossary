# Scope

## 한 줄 설명
Scope는 이름을 선언한 위치에 따라 그 이름을 읽고 쓸 수 있는 코드 범위를 정하는 규칙입니다.

## 쉽게 설명하면
변수 이름표가 통하는 구역입니다. 건물 전체에서 보이는 이름도 있고, 한 함수 방이나 `{}` 블록 안에서만 보이는 이름도 있습니다.

## 정확한 설명
대표적인 scope에는 global scope, function scope, block scope가 있습니다. JavaScript에서 `var`는 주로 함수 범위를 따르고 `let`과 `const`는 블록 범위를 따르므로, 같은 이름이라도 선언 위치와 키워드에 따라 접근 가능 범위가 달라집니다.

## 동작 원리
안쪽 scope에서 이름을 찾고 없으면 바깥 scope로 올라갑니다. 안쪽에서 같은 이름을 선언하면 바깥 이름을 가릴 수 있습니다.

## 이 미션에서는 왜 필요한가
M01의 이벤트 처리 코드와 예비 M02의 함수·클래스 코드에서 값이 의도한 곳에서만 바뀌도록 변수 범위를 설계하는 데 필요합니다.

## 코드 예
```js
const site = 'Codyssey';
if (true) {
  let message = 'visible here';
  var legacy = 'function scoped';
}
// message는 여기서 접근할 수 없지만 legacy는 함수 안에서는 접근 가능
```

## 주의할 점 / 경계 조건
`const`는 값을 절대 바꾸지 못한다는 뜻이 아니라 binding을 다시 할당하지 못한다는 뜻입니다. 객체 내부 변경 가능성은 별도 문제입니다.

## 관련 용어
- `variable`
- `var`
- `let`
- `const`
- `function`
- `javascript`
- `python`

## 흔한 오해
블록 안에서 선언한 모든 변수는 자동으로 블록 밖에서도 보인다는 생각은 `let`·`const`에는 맞지 않습니다.
