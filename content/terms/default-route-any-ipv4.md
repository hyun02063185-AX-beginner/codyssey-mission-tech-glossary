# 0.0.0.0/0

## 한 줄 설명

어떤 IPv4 destination과도 일치하지 않을 때 쓰는 0.0.0.0/0 route.

## 쉽게 설명하면

"다른 규칙에 안 맞으면 전부 여기로"라는 뜻의 표기입니다. 경로에서는 기본 통로, 방화벽에서는 전체 허용이 됩니다.

## 정확한 설명

접두사 길이가 0이라 모든 주소와 일치한다. 경로 표에서는 다른 경로에 맞지 않는 목적지의 기본 경로가 되고, 방화벽 규칙에서는 출처를 가리지 않는다는 뜻이 된다. 같은 표기가 두 곳에서 다른 의미를 갖는다.

## 이 미션에서는 왜 필요한가

이 회차에서 인터넷 연결을 만들 때와 방화벽을 열 때 모두 나옵니다. 경로 표에 적는 것은 필요한 일이지만 방화벽 규칙에 적는 것은 신중해야 하는데, 같은 표기라 구분 없이 쓰기 쉽습니다.

## 코드 예

```text
경로 표에서
  대상 0.0.0.0/0 → IGW
  "여기 적힌 다른 곳이 아니면 인터넷으로 보내라"   ← 필요한 설정

방화벽 규칙에서
  포트 22, 출처 0.0.0.0/0
  "누구든 접속을 시도할 수 있다"                  ← 위험한 설정

  포트 80, 출처 0.0.0.0/0
  "누구든 웹에 접속할 수 있다"                    ← 의도한 설정

같은 표기지만 어디에 적느냐에 따라 뜻이 다르다.
```

## 주의할 점 / 경계 조건

방화벽에서 접속 포트를 이 범위로 열면 전 세계에서 접속 시도가 들어옵니다. 관리 포트는 반드시 좁혀야 합니다.

## 관련 용어

- `http`
- `tcp`

## 흔한 오해

경로 표에 적어도 되니 방화벽에도 괜찮다고 생각하기 쉽지만, 두 곳의 의미가 다릅니다. 경로는 "어디로 보낼까"이고 방화벽은 "누구를 받을까"입니다.
