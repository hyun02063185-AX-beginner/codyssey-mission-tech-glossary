# NAT Gateway

## 한 줄 설명

private subnet resource가 public IPv4로 outbound 연결할 때 source address를 변환하는 gateway.

## 쉽게 설명하면

밖에서는 안 보이는 서버가 밖으로 나가기만 할 수 있게 해 주는 통로입니다. 나갈 때 주소를 바꿔 줍니다.

## 정확한 설명

사설 주소만 가진 자원이 외부로 연결할 때 출발지 주소를 공인 주소로 바꾼다. 연결은 안에서 밖으로만 시작할 수 있어 밖에서 먼저 접속하는 것은 불가능하다. 시간당 요금과 처리량 요금이 함께 붙는다.

## 이 미션에서는 왜 필요한가

이 회차의 확장 학습입니다. 데이터베이스처럼 밖에서 접근할 필요가 없는 서버도 보안 갱신은 받아야 하는데, 그 한쪽 방향만 열어 주는 것이 이 통로입니다. 실습에서는 요금 때문에 보통 만들지 않습니다.

## 코드 예

```text
IGW (인터넷 게이트웨이)      NAT 게이트웨이
  양방향                       안 → 밖 만
  공인 IP 가 필요하다          사설 IP 로도 된다
  무료                         시간당 + 전송량 과금

쓰는 자리
  public  서브넷의 웹 서버   → IGW
  private 서브넷의 DB        → NAT (보안 갱신을 받기 위해)

실습에서는 요금 때문에 보통 만들지 않는다.
만들었다면 정리 목록에 반드시 넣는다.
```

## 주의할 점 / 경계 조건

시간당 요금이 붙고 무료 범위에 들어가지 않습니다. 실습에서 만들어 두고 잊으면 요금이 계속 나갑니다.

## 관련 용어

- `http`
- `tcp`

## 흔한 오해

인터넷 게이트웨이와 비슷하다고 생각하기 쉽지만, 방향이 다릅니다. 이쪽은 안에서 밖으로만 되고 밖에서 안으로는 안 됩니다.

## 동료평가 질문
