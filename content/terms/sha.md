# SHA

## 한 줄 설명

입력에서 고정 길이 digest를 만드는 secure hash algorithm 계열.

## 쉽게 설명하면

입력이 무엇이든 정해진 길이의 값으로 바꾸는 계산 방식의 묶음입니다. 같은 입력은 항상 같은 값이 나옵니다.

## 정확한 설명

임의 길이의 입력에서 고정 길이의 값을 만든다. 되돌릴 수 없고 입력이 조금만 달라도 값이 크게 바뀌므로 내용이 바뀌었는지 확인하는 데 쓴다. 버전에 따라 안전성이 다르고, 계산이 빠르기 때문에 비밀번호 저장에는 맞지 않는다.

## 이 미션에서는 왜 필요한가

이 회차에서 만든 기록의 식별자가 이 계열의 값입니다. 내용에서 계산되므로 같은 내용은 같은 값이 되고, 그래서 값이 달라졌다는 것이 곧 내용이 달라졌다는 뜻이 됩니다.

## 코드 예

```bash
echo -n "hello" | sha256sum
# 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824

echo -n "hellO" | sha256sum      # 글자 하나만 달라도
# 완전히 다른 값이 나온다

# 파일이 바뀌지 않았는지 확인
sha256sum -c checksums.txt

# 비밀번호에는 쓰지 않는다.
# 초당 수십억 번 계산되므로 흔한 비밀번호는 금방 뚫린다
```

## 주의할 점 / 경계 조건

빠르게 계산되도록 만들어진 함수입니다. 그 성질 때문에 비밀번호 저장에는 오히려 부적합합니다.

## 관련 용어

- `authentication`

## 흔한 오해

해시니까 비밀번호 저장에도 쓰면 된다고 생각하기 쉽지만, 빠른 것이 단점이 됩니다. 비밀번호에는 일부러 느린 함수를 씁니다.
