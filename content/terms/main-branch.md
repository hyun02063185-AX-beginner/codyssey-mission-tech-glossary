# main branch

## 한 줄 설명

배포 가능한 통합 상태를 유지하는 중심 branch.

## 쉽게 설명하면

팀이 기준으로 삼는 중심 줄기입니다. 언제든 동작하는 상태를 유지하는 것이 약속입니다.

## 정확한 설명

배포 가능한 상태를 유지하는 기준 브랜치다. 여기에 직접 밀어 넣지 않고 다른 브랜치에서 작업한 뒤 검토를 거쳐 합치는 것이 협업의 기본 규칙이며, 보호 규칙으로 그 약속을 강제할 수 있다.

## 이 미션에서는 왜 필요한가

이 회차는 여기에 직접 밀어 넣는 것을 금지합니다. 여러 명이 동시에 작업할 때 이 줄기가 깨지면 모두가 막히기 때문인데, 규칙으로 막아 두지 않으면 급할 때 누군가는 직접 올리게 됩니다.

## 코드 예

```bash
git branch -a
# * main
#   feature/login
#   remotes/origin/main

# 기술적으로는 그냥 이름이다
cat .git/refs/heads/main        # 커밋 해시 하나가 들어 있다

# 특별하게 만드는 것은 설정이다
#   직접 push 금지
#   PR 과 승인 1명 이상 필요
#   검사 통과 필요
```

## 주의할 점 / 경계 조건

이름이 `master`인 저장소도 있습니다. 기본 이름이 바뀐 시기가 있어 예전 저장소에서는 다르게 나옵니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

특별한 성질을 가진 브랜치라고 생각하기 쉽지만, 기술적으로는 다른 브랜치와 똑같습니다. 특별한 것은 팀이 그렇게 쓰기로 한 약속과 그것을 강제하는 설정뿐입니다.
