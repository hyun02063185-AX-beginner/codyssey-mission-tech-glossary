# 숨김 파일

## 한 줄 설명

이름이 점으로 시작해 일반 listing에서 숨겨지는 Unix file.

## 쉽게 설명하면

이름이 점으로 시작해 기본 목록에서 보이지 않는 파일입니다. 설정 파일이 주로 이렇게 되어 있습니다.

## 정확한 설명

별도의 속성이 있는 것이 아니라 이름이 점으로 시작한다는 관례뿐이다. 목록을 보여 주는 도구가 기본적으로 걸러 낼 뿐이므로, 옵션을 주면 그대로 보이고 이름을 바꾸면 숨김 상태도 바뀐다.

## 이 미션에서는 왜 필요한가

예비 M01의 4.2 항목은 목록을 볼 때 숨김 파일까지 포함하라고 요구합니다. 이름이 점으로 시작하면 기본 목록에서 빠지는데, 정작 설정 파일 대부분이 그 형태라 숨김을 포함하지 않으면 확인해야 할 것을 못 보게 됩니다.

## 코드 예

```bash
ls                 # .env 가 안 보인다
ls -a              # 보인다
ls -A              # . 과 .. 만 빼고 보인다

# 별표는 점으로 시작하는 이름과 맞지 않는다
cp project/* backup/       # .env 가 빠진다
cp -r project/. backup/    # 전부 복사된다

# 숨김은 관례일 뿐이다
mv .env env.txt            # 이름만 바꿔도 보인다
```

## 주의할 점 / 경계 조건

복사할 때 별표만 쓰면 이 파일들이 빠집니다. 설정 파일을 통째로 옮길 때 자주 겪는 문제입니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

숨겨진 것이라 보호된다고 생각하기 쉽지만, 보여 주지 않을 뿐 권한은 그대로입니다. 안 보이는 것과 못 읽는 것은 다릅니다.
