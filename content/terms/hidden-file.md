# 숨김 파일

## 한 줄 설명

이름이 점으로 시작해 일반 listing에서 숨겨지는 Unix file.

## 쉽게 설명하면

`숨김 파일`은(는) 실행 중인 program과 operating system의 상태를 관찰할 때 구분해야 하는 개념입니다.

## 정확한 설명

이름이 점으로 시작해 일반 listing에서 숨겨지는 Unix file. 실제 장애 판단에서는 값의 순간 변화와 지속 상태, process 범위와 system 범위를 나누어 봐야 합니다.

## 이 미션에서는 왜 필요한가

예비 M01의 4.2 항목은 목록을 볼 때 숨김 파일까지 포함하라고 요구합니다. 이름이 점으로 시작하면 기본 목록에서 빠지는데, 정작 설정 파일 대부분이 그 형태라 숨김을 포함하지 않으면 확인해야 할 것을 못 보게 됩니다.

## 코드 예

```bash
ls           # .bashrc .gitignore 가 보이지 않는다
ls -a        # 숨김 포함
ls -la       # 숨김 포함 + 권한까지
```

## 관련 용어

- `process`
- `linux`
