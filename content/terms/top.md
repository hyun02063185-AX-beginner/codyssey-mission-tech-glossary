# top

## 한 줄 설명

CPU·memory를 많이 쓰는 process를 실시간으로 보는 command.

## 쉽게 설명하면

무엇이 CPU와 메모리를 많이 쓰는지 실시간으로 보여 주는 화면입니다. 계속 갱신됩니다.

## 정확한 설명

일정 간격으로 프로세스 정보를 다시 읽어 정렬해 보여 준다. 첫 화면의 CPU 값은 부팅 이후 평균이라 의미가 적고 두 번째 갱신부터가 실제 구간 값이며, 화면에 나오는 값은 다음 갱신까지의 평균이 아니라 직전 구간의 값이다.

## 이 미션에서는 왜 필요한가

이 회차의 실시간 관제에 씁니다. 지금 이 순간 무엇이 자원을 쓰고 있는지 바로 보이므로 원인 후보를 좁히기에 가장 빠르지만, 화면에 있는 값이라 기록으로 남기려면 별도 방식이 필요합니다.

## 코드 예

```bash
top                       # 대화형
#  키 조작: P CPU 정렬 / M 메모리 정렬 / 1 코어별 / q 종료

# 기록으로 남기려면 한 번만 찍는 방식을 쓴다
top -bn2 -d1 | tail -20 >> /var/log/monitor.log
#     │  │   └ 1초 간격
#     │  └ 두 번 찍는다 — 두 번째가 실제 구간 값
#     └ 화면 제어 문자 없이 (파일에 넣기 좋다)

# 특정 프로세스만
top -bn1 -p "$PID"
```

## 주의할 점 / 경계 조건

첫 화면의 값은 부팅 이후 평균이라 현재 상태를 반영하지 않습니다. 몇 초 두고 봐야 합니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

보이는 값이 현재 순간의 값이라 생각하기 쉽지만, 직전 갱신 구간의 평균입니다. 아주 짧게 치솟는 것은 안 잡힐 수 있습니다.
