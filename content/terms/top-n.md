# TOP N

## 한 줄 설명

정렬 또는 선택 결과에서 상위 N개만 취하는 작업.

## 쉽게 설명하면

전체 순위 중 앞의 몇 개만 뽑는 일이다.

## 정확한 설명

전체 정렬 뒤 앞 N개를 자르거나, 크기 N의 힙으로 후보를 유지해 처리할 수 있다.

## 언제 쓰나

점수 상위 10명이나 최근 오류 상위 5개를 보여 준다.

## 기억할 경계

N의 기준과 동점 처리 규칙을 정하지 않으면 결과가 흔들린다.

## 이 미션에서는 왜 필요한가

가계부에서 "이번 달 지출이 큰 항목 3개"를 뽑는 기능이 이것입니다. 전체를 정렬한 뒤 앞을 자르는 방법과 상위 N개만 유지하는 방법이 있는데, 어느 쪽이든 금액이 같을 때 무엇을 먼저 둘지 정해 두지 않으면 실행할 때마다 결과가 달라집니다.

## 코드 예

```python
spending = [('식비', 32000), ('교통', 12000), ('도서', 32000), ('간식', 5000)]

# 금액 내림차순, 같으면 이름 오름차순 — 동점 규칙을 명시한다
top3 = sorted(spending, key=lambda x: (-x[1], x[0]))[:3]
print(top3)   # [('도서', 32000), ('식비', 32000), ('교통', 12000)]

# 항목이 아주 많으면 전체 정렬 대신
import heapq
print(heapq.nlargest(3, spending, key=lambda x: x[1]))
```

## 관련 용어

- `sorting-algorithm`
- `min-heap`
