# MEM

## 한 줄 설명

process 또는 system이 현재 사용 중인 memory 양.

## 쉽게 설명하면

지금 쓰고 있는 메모리 양입니다. 무엇을 포함해 세느냐에 따라 숫자가 크게 달라집니다.

## 정확한 설명

운영체제는 남는 메모리를 파일 캐시로 쓰므로, 캐시를 사용 중으로 세면 거의 항상 가득 차 보인다. 판단 기준이 되는 것은 캐시를 제외하고 실제로 회수하기 어려운 양이며, 도구마다 어느 쪽을 보여 주는지가 다르다.

## 이 미션에서는 왜 필요한가

이 회차의 점검 스크립트가 수집하는 값입니다. 캐시를 포함한 숫자를 그대로 기록하면 평소에도 90%가 넘게 나와 경보가 의미를 잃으므로, 무엇을 세는지 정하는 것이 수집보다 먼저입니다.

## 코드 예

```bash
free -m
#               total   used   free   shared  buff/cache   available
# Mem:           7940   2100    300      120        5540        5500
#                              ↑ 작아 보이지만            ↑ 이쪽을 본다
#                              캐시로 쓰고 있을 뿐, 필요하면 회수된다

# 컨테이너 안에서는 호스트 값이 보일 수 있다
cat /sys/fs/cgroup/memory.max 2>/dev/null
```

## 주의할 점 / 경계 조건

컨테이너 안에서는 호스트 전체의 값이 보일 수 있습니다. 컨테이너에 걸린 한도와 비교하려면 다른 경로를 봐야 합니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

남는 메모리가 적으면 부족한 것이라 생각하기 쉽지만, 캐시로 쓰고 있을 뿐 필요하면 즉시 회수됩니다. `available` 쪽을 봐야 합니다.
