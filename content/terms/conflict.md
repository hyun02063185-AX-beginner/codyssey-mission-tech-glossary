# 충돌

## 한 줄 설명

서로 양립할 수 없는 변경이나 상태가 충돌하는 일반적 상황.

## 쉽게 설명하면

`충돌`은(는) 변경을 기록하고 동료와 안전하게 공유하는 Git 작업 흐름의 한 부분입니다.

## 정확한 설명

서로 양립할 수 없는 변경이나 상태가 충돌하는 일반적 상황. local history, remote state, review 규칙의 역할을 구분해 사용해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M02의 병합 실습에서 반드시 마주치게 되는 상황입니다. 충돌은 고장이 아니라 "두 쪽이 같은 줄을 다르게 고쳤으니 사람이 정하라"는 Git의 요청이며, 그 요청을 읽고 답하는 것이 실습의 내용입니다.

## 코드 예

```text
<<<<<<< HEAD
점수 = 맞은_개수 * 10
=======
점수 = 맞은_개수 * 5
>>>>>>> feature/scoring
# 표시를 지우고 남길 쪽을 직접 정한 뒤 add · commit
```

## 관련 용어

- `git`
- `commit`
