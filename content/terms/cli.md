# 명령줄 인터페이스

## 한 줄 설명

CLI는 그래픽 버튼 대신 텍스트 명령으로 프로그램을 실행하고 조작하는 인터페이스입니다.

## 쉽게 설명하면

터미널에서 `python main.py`나 `git status`를 입력하고 결과를 읽는 방식이 CLI입니다.

## 정확한 설명

CLI 프로그램은 보통 명령어, 옵션, 인자를 받아 표준 입력·출력·오류 스트림으로 결과를 주고받습니다. 같은 작업을 반복하기 쉽고 자동화에 잘 맞지만, 명령의 형식과 오류 메시지를 읽을 줄 알아야 합니다.

## 이 미션에서는 왜 필요한가

예비 M01의 환경 설정부터 본과정 M03·M09·M10의 프로그램 실행까지 명령줄에서 결과를 확인합니다.

## 관련 용어

- terminal
- shell
- python

## 흔한 오해

터미널과 CLI는 같은 말이 아닙니다. 터미널은 입출력을 보여 주는 창이고, CLI는 그 안에서 쓰는 조작 방식 또는 프로그램입니다.
