# localhost

## 한 줄 설명

현재 실행 중인 host 자신을 가리키는 loopback 이름.

## 쉽게 설명하면

지금 명령을 실행하고 있는 그 컴퓨터 자신을 가리키는 이름입니다. 통신이 바깥으로 나가지 않습니다.

## 정확한 설명

자기 자신을 가리키는 되돌림 주소를 뜻하며, 그 주소로 보낸 통신은 네트워크 장치를 거치지 않는다. 서비스가 이 주소에만 묶여 있으면 같은 기계에서만 닿고 밖에서는 닿지 않으므로, 방화벽과 무관하게 접속이 막힌다.

## 이 미션에서는 왜 필요한가

이 회차에서 서버 안에서 서비스가 도는지 먼저 확인할 때 씁니다. 여기서는 되는데 밖에서 안 된다면 원인이 서비스가 아니라 네트워크 쪽이라는 것이 이 한 번의 확인으로 갈립니다.

## 코드 예

```bash
# 서버에 접속한 상태에서
curl -I http://localhost/        # 여기서 200 이면 서비스는 정상이다

# 그런데 밖에서 안 된다면 원인은 네트워크 쪽이다
#   보안 그룹 / 경로표 / 공인 IP / 묶인 주소

ss -tlnp | grep :8000
# LISTEN 127.0.0.1:8000    ← 이 기계에서만 닿는다
# LISTEN 0.0.0.0:8000      ← 밖에서도 닿는다

# 개발 서버를 밖에 열려면
uvicorn main:app --host 0.0.0.0 --port 8000
```

## 주의할 점 / 경계 조건

개발 서버가 기본으로 이 주소에만 묶이는 경우가 많습니다. 밖에서 접속하려면 모든 주소에 묶도록 지정해야 합니다.

## 관련 용어

- `http`
- `tcp`

## 흔한 오해

내 컴퓨터의 브라우저에서 이 주소를 치면 서버에 접속된다고 생각하기 쉽지만, 내 컴퓨터 자신을 가리킵니다. 서버에 접속하려면 서버의 주소를 써야 합니다.
