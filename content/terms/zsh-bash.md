# zsh / bash

## 한 줄 설명

Unix shell인 zsh와 bash의 문법·startup 설정 차이.

## 쉽게 설명하면

명령을 받아 주는 프로그램이 여러 개 있고 그중 많이 쓰이는 두 가지입니다. 문법이 조금씩 다릅니다.

## 정확한 설명

기본 명령 문법은 대부분 같지만 시작할 때 읽는 설정 파일이 다르고, 배열 인덱스 시작 번호나 일부 확장 문법에서 차이가 있다. 스크립트 맨 위에 어느 것으로 실행할지 적어 두지 않으면 환경에 따라 다르게 동작할 수 있다.

## 이 미션에서는 왜 필요한가

예비 M01에서 실행 환경을 적을 때 어떤 셸을 썼는지 구분해야 합니다. 명령은 같아 보여도 시작 설정 파일과 문법이 달라, 같은 한 줄이 한쪽에서만 동작하는 일이 생깁니다.

## 코드 예

```bash
echo $SHELL              # 로그인 셸
ps -p $$ -o comm=        # 지금 실행 중인 셸

# 읽는 설정 파일이 다르다
#   bash   ~/.bashrc  ~/.bash_profile
#   zsh    ~/.zshrc   ~/.zprofile

# 스크립트에는 어느 것으로 실행할지 적는다
#!/usr/bin/env bash

# 차이 하나 — 배열 인덱스
# bash  arr[0] 부터
# zsh   arr[1] 부터 (기본 설정에서)
```

## 주의할 점 / 경계 조건

시작할 때 읽는 설정 파일이 다릅니다. 한쪽에 환경 변수를 적어 두고 다른 쪽에서 실행하면 그 값이 없습니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

둘이 같다고 생각하기 쉽지만, 설정 파일과 일부 문법이 다릅니다. 실행 환경을 기록할 때 어느 것인지 적어야 하는 이유입니다.
