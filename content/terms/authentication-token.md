# 인증 토큰

## 한 줄 설명

인증이 끝난 뒤 클라이언트가 자신을 증명할 때 제시하는 자격 증명 값.

## 쉽게 설명하면

`인증 토큰`을(를) 누가 접근할 수 있고 어떤 정보가 노출되는지의 관점에서 확인하면 됩니다.

## 정확한 설명

인증이 끝난 뒤 클라이언트가 자신을 증명할 때 제시하는 자격 증명 값. 실제 적용에서는 신원, 권한, network 경계, 비밀값 보관 중 관련된 조건을 구분해야 합니다.

## 동작 원리

요청 또는 접속이 들어오면 자격 증명과 정책을 확인하고, 허용된 범위에서만 작업을 수행한 뒤 기록·만료·회수 조건을 적용합니다.

## 이 미션에서는 왜 필요한가

M05·M07·M13의 배포, 원격 접속, 인증 기능에서 안전한 기본값과 실패 처리를 설명하는 기준입니다.

## 코드 예

```text
# 인증 토큰 설정은 비밀값과 권한 범위를 검토한다
```

## 주의할 점 / 경계 조건

정상 응답이나 한 번의 로그인 성공만으로 전체 보안이 보장되지는 않습니다. 만료, 철회, 최소 권한, 감사 기록을 함께 확인합니다.

## 관련 용어

- `authentication`
- `authorization`
- `security-group`

## 흔한 오해

보안 기능 하나를 추가했다고 모든 위협이 사라지는 것은 아닙니다. 공격 표면과 권한 경계는 별도로 점검해야 합니다.
