# lexicographical order

## 한 줄 설명

문자열을 앞 글자부터 비교해 정하는 사전식 순서.

## 쉽게 설명하면

사전에서 단어를 첫 글자부터 비교해 놓는 순서다.

## 정확한 설명

공통 접두사는 건너뛰고 처음 다른 문자에서 비교한다. 문자 인코딩과 locale 규칙에 따라 사람이 기대하는 순서와 달라질 수 있다.

## 대표 사용

파일명과 사용자 이름을 일관되게 정렬할 때 쓰인다.

## 주의할 점

숫자 문자열은 숫자 크기 순서가 아니라 문자 순서로 비교된다.

## 이 미션에서는 왜 필요한가

작성자 이름이나 커밋 ID처럼 문자열을 기준으로 정렬할 때의 순서 규칙입니다. 날짜가 같을 때 무엇을 먼저 둘지 정하는 보조 기준으로 쓰이는데, 숫자가 섞인 문자열에서는 사람이 기대하는 크기 순서와 다르게 나옵니다.

## 코드 예

```python
print(sorted(['item10', 'item2', 'item1']))
# ['item1', 'item10', 'item2']  ← '1' < '2' 라서 item10 이 먼저다

# 숫자로 비교하려면 키를 바꿔 준다
import re
print(sorted(['item10', 'item2', 'item1'],
             key=lambda s: int(re.sub(r'\D', '', s))))
```

## 관련 용어

- `stable-custom-comparator`
