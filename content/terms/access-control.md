# Access Control

## 한 줄 설명

누가 어떤 resource에 어떤 작업을 할 수 있는지 결정·집행하는 보안 통제.

## 쉽게 설명하면

`Access Control`을(를) 누가 접근할 수 있고 어떤 정보가 노출되는지의 관점에서 확인하면 됩니다.

## 정확한 설명

누가 어떤 resource에 어떤 작업을 할 수 있는지 결정·집행하는 보안 통제. 실제 적용에서는 신원, 권한, network 경계, 비밀값 보관 중 관련된 조건을 구분해야 합니다.

## 이 미션에서는 왜 필요한가

M05·M07·M13의 배포, 원격 접속, 인증 기능에서 안전한 기본값과 실패 처리를 설명하는 기준입니다.
