# Backend as a Service

## 한 줄 설명

인증·database·storage 같은 backend 기능을 managed service로 쓰는 방식.

## 쉽게 설명하면

서버를 직접 만들지 않고 인증·데이터베이스·저장소를 서비스로 빌려 쓰는 방식입니다.

## 정확한 설명

서버 코드를 작성하는 대신 제공되는 기능을 화면 쪽에서 직접 호출한다. 서버를 만들고 운영하는 일이 없어지는 대신 접근 권한을 제공자의 규칙으로 설정해야 하고, 그 규칙을 열어 두면 화면 쪽 코드만으로 데이터가 그대로 노출된다.

## 이 미션에서는 왜 필요한가

이 회차에서 원격 데이터를 다룰 때 고를 수 있는 방식입니다. 서버 없이 시작할 수 있어 빠르지만, 권한 규칙을 설정하지 않으면 누구나 데이터를 읽고 쓸 수 있는 상태로 공개됩니다.

## 코드 예

```text
서버를 만들 때              BaaS 를 쓸 때
  브라우저 → 내 서버 → DB     브라우저 → 제공자 → DB
  서버에서 권한을 확인한다     제공자 쪽 규칙이 확인한다
  키는 서버에만 있다           키는 브라우저에 있다 (숨길 수 없다)

그래서 규칙을 반드시 설정한다
  기본값이 "전체 허용" 인 경우가 있다
  로그인한 사용자만 / 자기 데이터만 읽고 쓰게 좁힌다

설정하지 않으면 브라우저 개발자 도구만으로 전체가 열린다.
```

## 주의할 점 / 경계 조건

화면 쪽 코드에 들어가는 키는 사용자가 볼 수 있습니다. 그 키로 무엇을 할 수 있는지는 제공자 쪽 권한 규칙이 정합니다.

## 관련 용어

- `http`
- `tcp`

## 흔한 오해

키를 숨기면 안전하다고 생각하기 쉽지만, 화면 쪽 코드의 값은 숨길 수 없습니다. 방어선은 제공자 쪽 권한 규칙뿐입니다.
