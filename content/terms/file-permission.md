# 파일 권한

## 한 줄 설명

파일 권한은 누가 파일이나 디렉터리를 읽고, 쓰고, 실행할 수 있는지 정하는 운영체제 규칙입니다.

## 쉽게 설명하면

`rwx`는 읽기(read), 쓰기(write), 실행(execute)을 뜻합니다. 소유자·그룹·그 밖의 사용자에게 각각 다른 권한을 줄 수 있습니다.

## 코드 예

```sh
chmod 640 secrets.txt
```

## 정확한 설명

Unix 계열 권한은 보통 소유자(user), 그룹(group), 기타 사용자(other)로 나뉩니다. 파일의 실행 권한과 디렉터리의 실행 권한은 다르게 작동합니다. 디렉터리에서 실행 권한은 그 안으로 들어가 항목을 찾을 수 있는 권한에 가깝습니다.

## 이 미션에서는 왜 필요한가

예비 M01과 본과정 M07에서 파일 소유자와 읽기·쓰기 권한을 확인하고 변경 전후를 설명합니다.

## 관련 용어

- 755-644
- filesystem
- linux-user

## 흔한 오해

`chmod 777`은 문제를 해결하는 기본 답이 아닙니다. 필요 이상으로 넓은 권한은 민감한 파일을 노출할 수 있습니다.
