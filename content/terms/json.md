# JSON

## 한 줄 설명

JSON은 객체와 배열 같은 데이터를 텍스트로 주고받기 위한 형식입니다.

## 쉽게 설명하면

프로그램 안의 값을 다른 프로그램이나 파일로 옮겨 적을 때 쓰는 공통 언어입니다. API 응답에서 `{ "name": "Mina" }`처럼 보이는 내용이 JSON입니다.

## 정확한 설명

JSON은 문자열, 숫자, 불리언, null, 배열, 객체만으로 데이터를 표현하는 가벼운 텍스트 형식입니다. JavaScript 객체와 모양은 비슷하지만 JSON의 키와 문자열은 큰따옴표를 써야 하고, 함수나 주석은 담을 수 없습니다.

## 이 미션에서는 왜 필요한가

- main M01: API 응답을 읽어 화면에 표시합니다.
- preliminary M02: 상태 데이터를 파일로 저장하고 다시 읽습니다.

## 관련 용어

- `fetch-api`
- `serialization`

## 흔한 오해

JSON은 JavaScript 전용 형식이 아닙니다. Python, Java, 서버와 브라우저도 같은 JSON을 주고받을 수 있습니다.
