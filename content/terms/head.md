# HEAD

## 한 줄 설명

현재 checkout된 commit 또는 branch tip을 가리키는 Git reference.

## 쉽게 설명하면

지금 내가 어디에 있는지를 가리키는 표시입니다. 보통 브랜치 이름을 가리킵니다.

## 정확한 설명

현재 위치를 나타내는 참조로, 보통은 브랜치 이름을 가리키고 그 브랜치가 커밋을 가리킨다. 커밋을 직접 가리키게 되면 분리된 상태가 되며, 이때 만든 커밋은 어떤 브랜치에도 속하지 않아 다른 곳으로 옮기면 참조를 잃는다.

## 이 미션에서는 왜 필요한가

예비 M02에서 브랜치를 옮겨 다닐 때 기준이 되는 지점입니다. "지금 어느 커밋 위에 서 있는가"를 가리키므로, 브랜치를 바꾸면 작업 폴더의 내용이 왜 통째로 달라지는지가 이것으로 설명됩니다.

## 코드 예

```bash
cat .git/HEAD
# ref: refs/heads/main       ← 브랜치를 가리킨다

git switch --detach a1b2c3d
cat .git/HEAD
# a1b2c3d4e5f6...            ← 커밋을 직접 가리킨다 (분리된 상태)

# 이 상태에서 커밋하면
# "you are in 'detached HEAD' state" 경고가 나온다
# 브랜치를 만들어 두지 않으면 옮길 때 참조를 잃는다
git switch -c rescue        # 이렇게 붙잡아 둔다
```

## 주의할 점 / 경계 조건

분리된 상태에서 커밋하고 브랜치를 옮기면 그 커밋을 가리키는 것이 없어집니다. 경고 메시지가 나오므로 읽어야 합니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

커밋 하나를 가리킨다고 생각하기 쉽지만, 보통은 브랜치 이름을 가리킵니다. 한 단계 건너 커밋에 닿습니다.

## 동료평가 질문

분리된 상태가 무엇이고 그 상태에서 커밋하면 무슨 일이 생기는지 설명할 수 있나요?
