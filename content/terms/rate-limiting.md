# 시간당 60회 제한

## 한 줄 설명

Rate Limiting은 서비스가 일정 시간 동안 허용하는 요청 수를 제한해 자원을 보호하는 정책입니다.

## 쉽게 설명하면

짧은 시간에 API를 너무 많이 부르지 못하게 정해 둔 사용량 한도입니다.

## 정확한 설명

API 제공자는 공정한 사용과 서비스 안정성을 위해 요청 횟수를 시간 창, 사용자, IP, 인증 상태 같은 기준으로 제한할 수 있습니다. GitHub의 비인증 요청 한도는 M01에서 시간당 60회라는 조건으로 다뤄집니다.

제한은 HTTP 상태 코드와 함께 나타날 수 있지만 Rate Limit 자체가 상태 코드와 같은 개념은 아닙니다. 반복 요청을 피하고 실패 시 재시도·안내 전략을 UI 상태에 반영해야 합니다.

## 이 미션에서는 왜 필요한가

GitHub API 요청이 제한됐을 때 사용자에게 상황을 설명하는 오류 UI를 만듭니다.

## 관련 용어

- github-api
- http-status-code-403
- ui-state

## 흔한 오해

모든 403이 권한 오류인 것은 아니며, 요청 한도도 함께 확인해야 합니다.
