# 사용자 이벤트

## 한 줄 설명

사용자 이벤트는 사람이 클릭·입력·스크롤·제출처럼 인터페이스와 상호작용할 때 브라우저가 발생시키는 이벤트입니다.

## 쉽게 설명하면

사용자가 화면에서 한 행동을 프로그램에 알려 주는 신호입니다.

## 정확한 설명

브라우저는 pointer, keyboard, input, submit 같은 이벤트를 DOM 요소에 전달합니다. 코드가 직접 만든 이벤트와 달리 사용자 이벤트는 실제 상호작용에서 비롯되지만, 보안과 접근성 때문에 모든 이벤트가 같은 사용자 권한을 주는 것은 아닙니다. 이벤트를 받으려면 대상에 핸들러를 등록하고, 키보드·터치 입력도 함께 고려해야 합니다.

## 이 미션에서는 왜 필요한가

M01에서 버튼 클릭만이 아니라 폼 제출과 키보드 사용까지 고려해 상호작용을 구현합니다.

## 코드 예

```js
form.addEventListener('submit', (event) => {
  event.preventDefault();
  submitProfile();
});
```

## 관련 용어

- `event-handler`
- `add-event-listener`
- `form-validation`
- `prevent-default`

## 흔한 오해

클릭 이벤트만 처리하면 모든 사용자가 같은 기능을 쓸 수 있다고 생각하면 안 됩니다. 버튼에는 키보드 조작과 적절한 HTML 의미도 필요합니다.
