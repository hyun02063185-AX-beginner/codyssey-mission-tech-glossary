# 라벨 정규화

## 한 줄 설명

동일 의미의 label 표기를 규칙에 따라 통일하는 처리.

## 쉽게 설명하면

같은 뜻인데 사람마다 다르게 적은 이름을 한 가지 표기로 맞추는 처리입니다.

## 정확한 설명

비교나 집계를 하기 전에 먼저 적용해야 합니다. 대소문자만 맞추는 것으로 끝나지 않고, 같은 것을 가리키는 서로 다른 이름을 하나로 모으는 대응표가 필요한 경우가 많습니다.

## 이 미션에서는 왜 필요한가

예비 M03은 답을 `Cross`와 `X`, `x`와 `+` 처럼 여러 표기로 받을 수 있게 하고 이를 한 가지로 통일해 판정하라고 요구합니다. 통일하지 않으면 맞는 답을 틀렸다고 판정하게 됩니다.

## 코드 예

```python
ALIASES = {"cross": "Cross", "x": "Cross", "+": "Plus", "plus": "Plus"}

def normalize(label):
    return ALIASES.get(label.strip().lower(), label.strip())

normalize(" X ")   # "Cross"
```

## 주의할 점 / 경계 조건

대응표에 없는 값이 들어왔을 때 조용히 원본을 그대로 두면 판정이 틀어집니다. 모르는 표기는 그냥 넘기지 말고 눈에 띄게 처리하는 편이 안전합니다.

## 관련 용어

- `filter`
- `tie-handling`

## 흔한 오해

소문자로 바꾸면 끝난다고 생각하기 쉽지만, `X` 와 `Cross` 처럼 글자가 아예 다른 경우는 대응표가 있어야 합니다. 대소문자 통일은 정규화의 한 부분일 뿐입니다.
