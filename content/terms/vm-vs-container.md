# 가상머신 대비

## 한 줄 설명

가상머신과 컨테이너가 격리·운영체제·자원 사용을 나누는 방식의 차이.

## 쉽게 설명하면

VM은 운영체제까지 따로 가진 컴퓨터이고, 컨테이너는 host kernel을 공유하는 격리된 프로세스다.

## 정확한 설명

VM은 hypervisor 위 guest OS를 실행하고, container는 namespace·cgroup으로 host kernel 위 프로세스를 분리한다.

## 언제 쓰나

격리 강도와 시작 속도, 운영체제 요구를 기준으로 배포 방식을 고른다.

## 기억할 경계

컨테이너가 VM보다 항상 더 안전하거나 더 가볍다는 단정은 환경에 따라 틀릴 수 있다.

## 이 미션에서는 왜 필요한가

예비 M01에서 컨테이너를 쓰는 이유 자체가 여기서 나옵니다. 가상머신은 운영체제를 통째로 하나 더 띄우지만 컨테이너는 호스트 커널을 함께 쓰므로, 뜨는 속도와 차지하는 용량이 크게 달라집니다.

## 코드 예

```text
가상머신                      컨테이너
  게스트 OS 를 통째로 실행       호스트 커널을 함께 사용
  부팅에 수십 초                시작에 1초 안팎
  이미지가 GB 단위              이미지가 MB~수백 MB
  커널까지 격리                 커널은 공유, 보이는 범위만 격리
```

## 관련 용어

- `containerd-runc`
- `orbstack`
