# 예외 처리

## 한 줄 설명

예외 처리는 실행 중 예상하지 못한 문제가 생겼을 때 프로그램이 어떻게 대응할지 정하는 코드입니다.

## 쉽게 설명하면

숫자를 받아야 하는 칸에 글자가 들어왔을 때 프로그램을 바로 종료하는 대신, 이유를 알리고 다시 입력하게 하는 방식입니다.

## 코드 예

```python
try:
    age = int(text)
except ValueError:
    print('숫자를 입력해 주세요.')
```

## 정확한 설명

예외는 파일이 없거나, 숫자 변환에 실패하거나, 네트워크 요청이 실패하는 등 정상 흐름을 계속하기 어려운 상황을 나타냅니다. 예외 처리는 발생 가능한 예외를 좁게 잡고, 사용자에게 필요한 정보를 주며, 복구할 수 없는 오류는 숨기지 않는 것이 좋습니다.

## 이 미션에서는 왜 필요한가

예비 M02와 본과정 M03에서 잘못된 입력·파일 오류가 있어도 프로그램이 이유 없이 멈추지 않게 합니다.

## 관련 용어

- python
- input-validation
- error-message

## 흔한 오해

모든 예외를 무시하면 안정적인 프로그램이 되는 것이 아닙니다. 원인을 감추면 데이터 손상이나 버그를 놓칠 수 있습니다.
