# 객체와 인스턴스

## 한 줄 설명

인스턴스는 class를 바탕으로 만들어진 실제 객체로, 자신만의 데이터와 동작을 가집니다.

## 쉽게 설명하면

`User`가 사용자 설계도라면 `User('민아')`는 이름이 민아인 실제 사용자 한 명입니다.

## 코드 예

```python
user = User('민아')
print(user.name)
```

## 정확한 설명

객체는 값과 기능을 함께 가진 대상을 가리키는 넓은 말이고, 인스턴스는 특정 class에서 생성된 객체를 말합니다. 인스턴스 속성은 객체마다 달라질 수 있지만, 메서드 정의는 같은 class를 공유합니다.

## 이 미션에서는 왜 필요한가

예비 M02에서 Quiz·QuizGame 같은 class를 만들고, 실제 퀴즈 데이터를 담을 객체를 생성합니다.

## 관련 용어

- class
- method
- attribute

## 흔한 오해

모든 객체가 특정 class의 인스턴스라는 뜻은 아닙니다. 언어에 따라 숫자·문자열 같은 값도 객체처럼 다뤄질 수 있습니다.
