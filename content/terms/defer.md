# defer

## 한 줄 설명

`defer`는 HTML 해석을 막지 않고 문서 파싱 뒤 외부 스크립트를 실행하게 하는 `script` 속성입니다.

## 쉽게 설명하면

페이지 뼈대를 먼저 읽고 난 뒤 JavaScript가 필요한 요소를 찾게 만드는 약속입니다.

## 정확한 설명

일반적인 외부 스크립트는 HTML 파싱을 멈출 수 있지만, `defer` 스크립트는 병렬로 내려받고 문서 파싱이 끝난 뒤 실행됩니다. 여러 defer 스크립트는 문서에 적은 순서를 유지합니다.

따라서 JavaScript가 `querySelector`로 M01의 메뉴나 폼 요소를 찾을 때, 해당 요소가 아직 만들어지지 않은 문제를 줄입니다. 모듈 스크립트도 기본적으로 defer와 유사한 실행 특성이 있지만 같은 개념으로 섞어 설명하지는 않습니다.

## 이 미션에서는 왜 필요한가

파일을 역할별로 분리하면서 메뉴·폼·테마 코드가 초기 DOM을 안정적으로 읽게 합니다.

## 코드 예

```html
<script src="js/main.js" defer></script>
```

## 관련 용어

- html
- javascript
- dom

## 흔한 오해

`defer`는 스크립트를 전혀 실행하지 않는 옵션이 아니라 실행 시점만 조절합니다.
