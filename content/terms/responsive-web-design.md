# 반응형

## 한 줄 설명

반응형 웹 디자인은 하나의 페이지가 여러 화면 크기에서 읽고 조작하기 좋게 적응하도록 만드는 설계입니다.

## 쉽게 설명하면

휴대폰에서 보던 포트폴리오가 태블릿과 데스크톱에서도 내용이 잘리지 않고 편하게 보이게 하는 것입니다. 같은 소개·작업·연락 카드를 좁은 화면에서는 세로로, 넓은 화면에서는 나란히 놓습니다. 화면 전체를 작게 복사하는 것이 아니라 자리에 맞게 다시 배치합니다.

## 정확한 설명

반응형 설계는 유연한 폭, media query, 적절한 레이아웃 규칙을 조합해 viewport 변화에 대응합니다. 단순히 요소를 축소하는 것이 아니라 콘텐츠 우선순위, 줄바꿈, 터치 영역과 가독성까지 조정합니다.

HTML은 내용과 구조를, CSS는 배치와 표현을 정합니다. 미디어 쿼리(Media Query)는 화면 폭 같은 조건에 맞을 때 CSS 규칙을 적용합니다. 브레이크포인트(Breakpoint)는 배치 규칙을 바꾸는 기준 폭입니다. 모바일 퍼스트(Mobile First)는 작은 화면의 규칙을 먼저 쓰고, 폭이 넓어질 때 필요한 규칙을 덧붙이는 방식입니다.

B1-1 학습 자료에서는 Mobile First를 기본으로 하고 768px·1024px에서 Flexbox·Grid 규칙을 확장합니다. 각 경계뿐 아니라 그 사이 폭에서도 overflow와 겹침이 없는지 확인해야 합니다.

768px·1024px는 B1-1 학습 자료의 예시 기준이며 모든 사이트가 따라야 하는 공통 값은 아닙니다. 배열·메뉴 표현·여백·글자 크기·터치 공간도 화면에 맞게 조정할 수 있습니다. 그림의 메뉴를 접어 표시하는 규칙은 CSS로, 버튼을 눌러 여닫는 동작은 JavaScript로 구현할 수 있습니다.

다음은 그림의 카드 1·2·3열을 연결하는 교육용 일반 예시입니다. 세 화면에 별도 HTML 파일을 만드는 코드는 아닙니다.

```css
.cards { display: grid; grid-template-columns: 1fr; }
@media (min-width: 768px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1024px) {
  .cards { grid-template-columns: repeat(3, 1fr); }
}
```

## 이 미션에서는 왜 필요한가

배포된 B1-1 페이지가 모바일·태블릿·데스크톱 모두에서 사용 가능해야 합니다.

## 관련 용어

- mobile-first
- breakpoint
- css-flexbox
- css-grid

## 흔한 오해

반응형은 글자와 카드만 작게 만드는 작업이 아닙니다.
