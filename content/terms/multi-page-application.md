# MPA

## 한 줄 설명

MPA는 페이지를 이동할 때 서버에서 새 HTML 문서를 받아 표시하는 웹 애플리케이션 방식입니다.

## 쉽게 설명하면

상품 목록에서 상품 상세로 갈 때 브라우저가 새 문서를 요청하고 그 문서 전체를 화면에 보여 주는 구성입니다.

## 정확한 설명

MPA는 URL마다 서버가 별도 문서를 응답하는 경우가 많습니다. 화면 전환의 일부를 JavaScript가 맡을 수도 있으므로 MPA가 곧 SSR이고 SPA가 곧 CSR이라는 등식은 성립하지 않습니다. 어떤 방식을 쓸지는 문서 구조, 배포 방식, 팀의 구현 범위를 함께 보고 정합니다.

## 이 미션에서는 왜 필요한가

본과정 M01에서 브라우저 내 화면 갱신 방식인 SPA와 문서 단위 전환 방식을 비교합니다.

## 관련 용어

- single-page-application
- server-side-rendering
- client-side-route

## 흔한 오해

MPA가 오래된 방식이고 SPA가 항상 더 낫다는 뜻은 아닙니다. 해결하려는 문제와 운영 조건이 다릅니다.

## 동료평가 질문

MPA에서 링크를 클릭할 때 브라우저가 새 문서를 요청하는 흐름을 설명해 보세요.
