# Docker 컨테이너

## 한 줄 설명

Docker 컨테이너는 이미지에서 만들어 실행되는, 서로 격리된 프로세스 실행 단위입니다.

## 쉽게 설명하면

이미지가 요리법이라면 컨테이너는 그 요리법으로 실제 실행 중인 한 그릇입니다. 같은 이미지에서 컨테이너를 여러 개 만들 수 있습니다.

## 정확한 설명

컨테이너는 이미지 레이어 위에 쓰기 가능한 레이어를 더해 프로세스를 실행합니다. 컨테이너를 삭제하면 그 쓰기 레이어의 데이터는 사라질 수 있으므로, 남겨야 할 데이터는 볼륨이나 바인드 마운트에 둡니다.

## 이 미션에서는 왜 필요한가

예비 M01에서 컨테이너 안에 진입하고, 삭제 뒤에도 데이터가 남는지 저장 방식을 검증합니다.

## 관련 용어

- docker
- docker-image
- volume
- bind-mount

## 흔한 오해

컨테이너는 가상 머신과 같지 않습니다. 보통 호스트 커널을 공유하는 격리된 프로세스입니다.

## 동료평가 질문

컨테이너를 지운 뒤에도 데이터를 남기려면 왜 볼륨이 필요한가요?
