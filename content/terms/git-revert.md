# git revert

## 한 줄 설명

기존 commit의 반대 변경을 새 commit으로 만드는 명령.

## 쉽게 설명하면

이전 커밋의 변경을 되돌리는 새 커밋을 만드는 명령입니다. 기록을 지우지 않고 되돌립니다.

## 정확한 설명

대상 커밋과 반대되는 변경을 담은 새 커밋을 만든다. 기존 이력을 건드리지 않으므로 이미 공유된 브랜치에서도 안전하며, 되돌렸다는 사실 자체가 기록으로 남는다. 합치기 커밋을 되돌릴 때는 어느 쪽을 기준으로 할지 지정해야 한다.

## 이 미션에서는 왜 필요한가

이 회차의 트러블슈팅 항목 중 하나입니다. 이미 공유한 변경을 되돌려야 할 때 이력을 다시 쓰는 방법은 팀 전체에 영향을 주는데, 이 명령은 앞으로 커밋을 하나 더하는 방식이라 아무도 영향받지 않습니다.

## 코드 예

```bash
git revert a1b2c3d
# 반대 변경을 담은 새 커밋이 만들어진다

git log --oneline -3
# f9e8d7c Revert "결제 로직 변경"
# a1b2c3d 결제 로직 변경          ← 그대로 남아 있다

# 합치기 커밋을 되돌릴 때는 기준을 지정한다
git revert -m 1 <머지커밋>
#          └ 1 은 합쳐진 쪽이 아니라 받은 쪽(main)

# 여러 개를 되돌리려면
git revert --no-commit a1b2c3d b2c3d4e && git commit
```

## 주의할 점 / 경계 조건

합치기 커밋을 되돌릴 때는 어느 부모를 기준으로 할지 지정해야 합니다. 지정하지 않으면 실패합니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

되돌리면 그 커밋이 없어진다고 생각하기 쉽지만, 원래 커밋은 그대로 남고 반대 변경이 하나 더 쌓입니다. 그래서 안전합니다.
