# 인터프리터

## 한 줄 설명

소스 코드를 실행 가능한 동작으로 해석하는 프로그램.

## 쉽게 설명하면

작성한 문장을 읽어 한 단계씩 실행 의미를 정하는 실행기다.

## 정확한 설명

인터프리터는 파싱·바이트코드 실행·런타임 관리를 수행할 수 있다. 구현에 따라 JIT 컴파일을 함께 쓰기도 한다.

## 언제 쓰나

Python 파일을 실행할 때 Python 인터프리터가 코드를 처리한다.

## 기억할 경계

인터프리터 언어라도 매번 한 줄씩만 읽는다는 뜻은 아니다.

## 이 미션에서는 왜 필요한가

작성한 파이썬 파일이 어떻게 실행되는지에 대한 답입니다. 실행 전에 전체를 검사하지 않기 때문에 오타가 있는 줄도 그 줄에 도달하기 전에는 오류가 나지 않습니다. 퀴즈가 중간까지 잘 돌다가 갑자기 멈추는 일이 이래서 생깁니다.

## 코드 예

```python
def never_called():
    print(undefined_name)    # 실행되지 않으면 오류도 나지 않는다

print('여기까지는 잘 돈다')
never_called()               # 이 줄에 와서야 NameError

# 문법 오류는 다르다 — 파일을 읽는 단계에서 바로 걸린다
```
