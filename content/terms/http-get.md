# GET

## 한 줄 설명

GET은 서버의 리소스를 조회하기 위해 사용하는 HTTP method입니다.

## 쉽게 설명하면

서버에 정보를 보여 달라고 요청하는 동사입니다.

## 정확한 설명

GET은 안전(safe)하고 멱등(idempotent)한 조회 의미로 설계하는 것이 원칙입니다. 같은 GET을 여러 번 보내도 서버 상태를 바꾸지 않아야 하며, 조회 조건은 보통 URL query에 표현합니다. 실제 네트워크 재시도나 cache 동작은 별도 조건에 따라 달라지므로, 민감한 정보를 URL에 넣지 않아야 합니다.

## 이 미션에서는 왜 필요한가

M12에서 목록·상세 조회 API를 설계하고, M01에서 fetch의 기본 GET 요청을 이해합니다.

## 코드 예

```http
GET /api/users?role=member HTTP/1.1
```

## 관련 용어

- `http`
- `http-post`
- `http-request-response`
- `rest-api`

## 흔한 오해

GET은 body를 절대 보낼 수 없다는 문법 규칙으로만 이해하면 부족합니다. 핵심은 조회 의미를 표현하고 서버 상태 변경에 쓰지 않는 것입니다.
