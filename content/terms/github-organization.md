# Organization

## 한 줄 설명

여러 repository와 member를 관리하는 GitHub 계정 단위.

## 쉽게 설명하면

여러 저장소와 사람을 묶어 관리하는 단위입니다. 개인 계정과 달리 팀 단위로 권한을 줍니다.

## 정확한 설명

저장소와 구성원을 한 단위로 관리하고, 사람을 팀으로 묶어 팀 단위로 권한을 부여한다. 사람마다 따로 초대하는 방식과 달리 인원이 늘어도 관리 대상이 팀 수만큼으로 유지되며, 저장소가 개인이 아닌 조직에 속하므로 개인이 떠나도 남는다.

## 이 미션에서는 왜 필요한가

이 회차의 팀 저장소 운영 방식 중 하나입니다. 개인 저장소에 초대하는 방식보다 준비할 것이 많지만, 저장소가 특정 개인의 계정에 묶이지 않는다는 점이 팀 작업에서는 더 중요합니다.

## 코드 예

```text
개인 저장소 + 초대
  저장소가 만든 사람 계정에 속한다
  그 사람이 계정을 지우면 저장소도 사라진다
  사람마다 따로 초대한다

조직
  저장소가 조직에 속한다
  사람이 나가도 저장소는 남는다
  팀 단위로 권한을 준다

    조직 codyssey-team
      팀 frontend  →  repo web 에 Write
      팀 backend   →  repo api 에 Write

  새 팀원은 팀에 넣으면 끝난다.
```

## 주의할 점 / 경계 조건

개인 계정의 저장소를 옮기면 기존 주소가 새 주소로 넘어가지만, 원격 주소를 고쳐 두는 편이 안전합니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

팀을 만들면 권한이 자동으로 생긴다고 생각하기 쉽지만, 팀에 저장소 권한을 따로 부여해야 합니다. 팀은 사람 묶음일 뿐입니다.

## 동료평가 질문

개인 저장소에 초대하는 방식과 조직을 쓰는 방식의 차이를, 팀원이 나갈 때를 예로 설명할 수 있나요?
