# Elastic IP

## 한 줄 설명

AWS account에 할당해 instance와 연결할 수 있는 고정 public IPv4 주소.

## 쉽게 설명하면

계정에 할당받아 두고 원하는 서버에 붙였다 뗄 수 있는 고정 주소입니다. 서버를 바꿔도 주소는 그대로입니다.

## 정확한 설명

계정 단위로 할당되는 고정 공인 주소다. 인스턴스를 교체해도 같은 주소를 유지할 수 있지만, 어디에도 붙어 있지 않으면 과금된다. 즉 쓰지 않을 때 요금이 나오는 구조라, 실습 뒤 정리 대상에 반드시 포함된다.

## 이 미션에서는 왜 필요한가

이 회차에서 접속 주소를 고정하고 싶을 때 씁니다. 다만 실습 뒤 정리할 때 인스턴스만 지우면 이것이 떠 있는 상태로 남아 계속 과금되므로, 과금 정리 목록에 반드시 들어가야 하는 항목입니다.

## 코드 예

```text
과금 규칙이 거꾸로다

  실행 중인 인스턴스에 붙어 있다   무료
  아무 데도 안 붙어 있다           시간당 과금
  정지된 인스턴스에 붙어 있다      시간당 과금

정리 순서
  1. 인스턴스 종료
  2. Elastic IP 연결 해제
  3. Elastic IP 릴리스(반납)      ← 이것을 빠뜨리면 계속 나간다

인스턴스를 지워도 주소는 자동으로 반납되지 않는다.
```

## 주의할 점 / 경계 조건

붙어 있지 않을 때 요금이 나옵니다. 인스턴스를 지우면 자동으로 그 상태가 되므로, 주소도 함께 반납해야 합니다.

## 관련 용어

- `http`
- `tcp`

## 흔한 오해

안 쓰면 요금이 안 나온다고 생각하기 쉽지만 반대입니다. 쓰고 있으면 무료이고 놀고 있으면 과금됩니다.
