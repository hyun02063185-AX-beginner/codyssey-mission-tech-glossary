# 환경 변수

## 한 줄 설명

환경 변수는 코드를 고치지 않고 실행 환경에 따라 설정값을 전달하는 이름과 값의 쌍입니다.

## 쉽게 설명하면

개발용 API 주소와 운영용 API 주소를 소스 파일에 적어 두는 대신, `API_URL`이라는 환경 변수에 각각 다른 값을 넣어 실행할 수 있습니다.

## 정확한 설명

환경 변수는 운영체제 프로세스에 전달되며, 프로그램은 실행 중 이를 읽습니다. 비밀값을 코드와 Git 저장소에서 분리하는 데 도움이 되지만, 환경 변수 자체가 암호화되지는 않습니다. 로그·오류 화면·클라이언트 번들에 값을 노출하지 않도록 별도 관리가 필요합니다.

## 코드 예

```python
api_key = os.environ["API_KEY"]
```

## 이 미션에서는 왜 필요한가

본과정 M02·M06에서 API 키를, M07에서 서비스 경로와 포트를 환경별로 전달합니다.

## 관련 용어

- api-key
- secret-management
- dockerfile

## 흔한 오해

`.env` 파일과 환경 변수는 같은 말이 아닙니다. `.env`는 환경 변수를 편하게 불러오기 위해 쓰는 파일 형식 중 하나입니다.
