# 다크모드

## 한 줄 설명

다크모드는 밝은 테마와 어두운 테마 사이에서 페이지의 색상 표현을 전환하는 UI 기능입니다.

## 쉽게 설명하면

배경과 글자색을 함께 바꿔 어두운 환경에서도 편하게 읽을 수 있게 하는 테마 선택입니다.

## 정확한 설명

다크모드는 보통 document 또는 상위 요소에 class·data attribute를 적용하고 CSS 변수나 선택자 규칙을 바꿔 구현합니다. 배경만 바꾸지 말고 텍스트, 경계선, 링크, 포커스 표시의 대비를 함께 설계해야 합니다.

테마 전환은 UI 기능이고, 사용자가 고른 테마를 새로고침 뒤에도 유지하는 것은 localStorage의 책임입니다. 두 책임을 분리하면 코드와 검증 기준이 선명해집니다.

## 이 미션에서는 왜 필요한가

M01에서 사용자의 테마 선택을 화면에 반영하고 다음 방문에도 유지합니다.

## 관련 용어

- css
- local-storage
- dom

## 흔한 오해

다크모드는 배경색만 검게 바꾸는 기능이 아닙니다.
