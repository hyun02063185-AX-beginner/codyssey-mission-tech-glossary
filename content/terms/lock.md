# Lock

## 한 줄 설명

공유 자원을 한 번에 한 실행 흐름만 변경하도록 만드는 동기화 장치입니다.

## 쉽게 설명하면

한 사람이 쓰는 화장실 열쇠처럼, 열쇠를 가진 작업만 안의 자원을 바꿀 수 있게 합니다.

## 정확한 설명

Lock은 임계 구역에 들어가기 전 획득하고 작업 뒤 해제하는 배타 제어입니다. 올바른 범위·해제·획득 순서가 없으면 race condition이나 deadlock을 만들 수 있습니다.

## 동작 원리

1. lock을 획득한 흐름만 임계 구역에 들어갑니다.
2. 공유 값을 읽고 변경합니다.
3. 예외가 나도 해제되도록 finally 또는 context manager로 lock을 놓습니다.

## 이 미션에서는 왜 필요한가

M08에서 동시에 실행되는 작업이 공유 상태를 안전하게 다루는 방법을 설명합니다.

## 코드 예

```python
with lock:
    balance += 1  # 읽기·수정·쓰기를 한 임계 구역으로 묶는다
```

## 주의할 점 / 경계 조건

모든 코드를 lock으로 감싸면 안전해 보일 수 있지만 병렬성을 낮추고 오래 잡은 lock은 병목이 됩니다.

## 관련 용어

- `mutex`
- `race-condition`
- `deadlock`
- `thread`

## 흔한 오해

Lock은 데이터를 자동으로 올바르게 만드는 기능이 아니라 접근 순서를 제어하는 기능입니다.
