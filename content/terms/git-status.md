# git status

## 한 줄 설명

working tree, index, branch의 변경 상태를 요약하는 명령.

## 쉽게 설명하면

지금 무엇이 바뀌었고 그중 무엇이 커밋에 담길 예정인지 보여 주는 명령입니다.

## 정확한 설명

작업 디렉터리·스테이지·현재 브랜치의 상태를 한 번에 요약한다. 변경됐지만 스테이지에 올리지 않은 것, 올린 것, 아직 추적하지 않는 파일을 구분해 보여 주므로 커밋 직전에 무엇이 담길지 확인하는 자리다. 원격과의 차이는 마지막으로 가져온 시점 기준이다.

## 이 미션에서는 왜 필요한가

이 회차의 AI 도우미가 변경 상태를 수집할 때 씁니다. 사람이 읽는 형식은 버전에 따라 문구가 달라질 수 있으므로, 프로그램이 읽을 때는 고정된 형식으로 출력하는 옵션을 써야 합니다.

## 코드 예

```bash
git status
# Changes to be committed:     ← 이것만 커밋된다
# Changes not staged:          ← 안 담긴다
# Untracked files:             ← 추적조차 안 한다

# 프로그램이 읽을 때는 고정된 형식을 쓴다
git status --porcelain=v1
#  M src/app.py       두 번째 칸 M = 스테이지에 안 올림
# M  src/main.py      첫 번째 칸 M = 올림
# ?? notes.txt        추적 안 함

# 문구는 버전과 언어 설정에 따라 바뀌지만 이 형식은 고정이다
```

## 주의할 점 / 경계 조건

원격과 몇 개 차이 난다는 안내는 마지막으로 가져온 시점 기준입니다. 실시간이 아닙니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

변경한 파일이 다 커밋된다고 생각하기 쉽지만, 스테이지에 올린 것만 담깁니다. 이 명령이 그 둘을 나눠 보여 주는 이유입니다.
