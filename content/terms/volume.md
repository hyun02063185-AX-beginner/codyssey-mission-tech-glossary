# 볼륨

## 한 줄 설명

Docker 볼륨은 컨테이너의 수명과 분리해 데이터를 남길 수 있도록 Docker가 관리하는 저장 공간입니다.

## 쉽게 설명하면

컨테이너를 지워도 남겨 둘 데이터 전용 서랍을 Docker에 만드는 방식입니다.

## 코드 예

```sh
docker run -v app-data:/var/lib/app my-image
```

## 정확한 설명

볼륨은 Docker가 호스트에 보관하고 컨테이너 경로에 마운트합니다. 같은 볼륨을 새 컨테이너에 연결해 데이터를 이어 쓸 수 있습니다. 볼륨을 지우는 일은 컨테이너 삭제와 별개이므로, 어떤 데이터가 들어 있는지 확인한 뒤 관리해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M01에서 컨테이너를 삭제한 뒤에도 데이터가 남는지 확인해 영속 저장을 증명합니다.

## 관련 용어

- docker-container
- bind-mount
- persistence

## 흔한 오해

컨테이너를 삭제한다고 볼륨까지 자동으로 항상 지워지는 것은 아닙니다. 삭제 옵션과 관리 명령을 따로 확인해야 합니다.

## 동료평가 질문

새 컨테이너에 같은 볼륨을 연결하면 이전 데이터가 보일 수 있는 이유는 무엇인가요?
