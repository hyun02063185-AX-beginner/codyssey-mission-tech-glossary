# Navigation State Styling

## 한 줄 설명

현재 route나 scroll 위치에 따라 navigation 모양을 바꾸는 UI 처리.

## 쉽게 설명하면

`Navigation State Styling`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

active state는 URL 또는 app state에서 계산하고 aria-current 같은 의미도 제공한다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
Navigation State Styling
```

## 관련 용어

- `client-side-routing`
- `accessibility-a11y`
