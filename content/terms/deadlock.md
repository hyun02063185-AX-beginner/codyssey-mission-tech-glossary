# Deadlock

## 한 줄 설명

서로가 가진 자원을 기다리느라 어떤 작업도 더 진행하지 못하는 상태입니다.

## 쉽게 설명하면

두 사람이 서로의 열쇠를 기다리며 문을 열지 못하는 상황과 비슷합니다.

## 정확한 설명

Deadlock은 둘 이상의 실행 흐름이 lock을 획득한 뒤 다른 lock의 해제를 무한히 기다리는 동시성 장애입니다. 대기 순환이 생기면 CPU가 충분해도 작업은 끝나지 않습니다.

## 동작 원리

1. 실행 흐름이 첫 lock을 각각 획득합니다.
2. 각 흐름이 상대가 가진 두 번째 lock을 기다립니다.
3. 아무도 첫 lock을 놓지 못해 대기 순환이 유지됩니다.

## 이 미션에서는 왜 필요한가

M08에서 lock 대기 장애의 원인을 구분하고, 멈춘 프로세스의 조치를 설명하는 기준입니다.

## 코드 예

```python
# T1: A를 잡고 B 대기 / T2: B를 잡고 A 대기
# lock 획득 순서를 A → B로 통일하면 순환을 막을 수 있다.
```

## 주의할 점 / 경계 조건

timeout은 관찰과 복구에 도움을 주지만 설계상 순환 대기를 자동으로 없애지는 않습니다.

## 관련 용어

- `lock`
- `mutex`
- `race-condition`
- `process`

## 흔한 오해

Deadlock은 단순히 프로그램이 느린 상태가 아닙니다. 진행 조건 자체가 막힌 상태입니다.
