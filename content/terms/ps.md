# ps

## 한 줄 설명

현재 process snapshot을 보여 주는 Unix command.

## 쉽게 설명하면

지금 어떤 프로그램이 돌고 있는지 한 번 찍어서 보여 주는 명령입니다. 그 순간의 사진이라 다음 순간은 다를 수 있습니다.

## 정확한 설명

호출 시점의 프로세스 목록을 한 번만 출력한다. 표시할 항목을 지정할 수 있고 정렬도 가능하며, CPU 사용률은 프로세스가 시작된 이후의 평균이라 방금 치솟은 값과는 다르다.

## 이 미션에서는 왜 필요한가

이 회차의 프로세스 확인에 씁니다. 실시간으로 보는 도구와 달리 출력을 파일에 남기거나 다른 명령으로 넘길 수 있어, 점검 스크립트에서 쓰기에 알맞습니다.

## 코드 예

```bash
# 필요한 항목만 골라 정렬한다
ps -eo pid,ppid,pcpu,pmem,rss,etime,comm --sort=-pcpu | head -10
#        │    │    │    │    │    └ 얼마나 오래 떠 있었나
#        │    │    │    │    └ 실제 물리 메모리 (KB)
#        │    │    │    └ 메모리 비율
#        │    │    └ CPU 비율 — 시작 이후의 평균이다
#        │    └ 부모 프로세스
#        └ 프로세스 번호

# 기록으로 남기기 좋다
ps -eo pid,pcpu,rss,comm --sort=-rss | head -5 >> /var/log/monitor.log
```

## 주의할 점 / 경계 조건

여기서 보이는 CPU 사용률은 시작 이후의 평균입니다. 지금 치솟고 있는지 알려면 실시간 도구를 봐야 합니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

계속 갱신되며 보여 준다고 생각하기 쉽지만, 한 번 찍고 끝납니다. 변화를 보려면 반복해서 부르거나 다른 도구를 써야 합니다.
