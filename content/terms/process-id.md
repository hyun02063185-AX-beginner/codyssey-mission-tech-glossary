# PID

## 한 줄 설명

운영체제가 실행 중인 process에 부여하는 식별 번호.

## 쉽게 설명하면

실행 중인 프로그램마다 붙는 번호입니다. 같은 프로그램을 두 번 띄우면 번호는 서로 다릅니다.

## 정확한 설명

운영체제가 프로세스를 만들 때 부여하며, 그 프로세스가 끝나면 번호는 재사용될 수 있다. 따라서 어딘가에 적어 둔 번호가 지금도 같은 프로세스를 가리킨다는 보장은 없고, 시작 시각이나 명령줄을 함께 봐야 확실하다.

## 이 미션에서는 왜 필요한가

이 회차에서 어떤 프로세스를 조사할지 지목하는 수단입니다. 이름으로 찾으면 같은 이름이 여럿일 때 구분되지 않으므로, 번호로 좁힌 뒤 그 번호에 대해 자원 사용량과 스레드를 들여다보는 순서가 됩니다.

## 코드 예

```bash
pgrep -x nginx                    # 이름이 정확히 맞는 것의 번호

PID=$(pgrep -o -x nginx)          # -o 는 가장 오래된 것
ps -p "$PID" -o pid,lstart,cmd    # 시작 시각과 명령줄로 확인

# 번호만 믿지 않는다
ls -l /proc/$PID/exe              # 실제로 어떤 실행 파일인지
cat /proc/$PID/cmdline | tr "\0" " "
```

## 주의할 점 / 경계 조건

적어 둔 번호를 나중에 쓸 때는 같은 프로세스인지 확인해야 합니다. 끝난 뒤 재사용된 번호일 수 있습니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

번호가 작으면 먼저 뜬 것이라 생각하기 쉽지만, 번호는 한 바퀴 돌면 처음부터 다시 부여됩니다. 시작 시각을 봐야 정확합니다.
