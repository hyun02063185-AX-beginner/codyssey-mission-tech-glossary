# 필수값 검증

## 한 줄 설명

폼 검증은 사용자의 입력이 제출 조건을 만족하는지 확인하고 이해 가능한 피드백을 주는 과정입니다.

## 쉽게 설명하면

사용자가 빈 이름이나 잘못된 이메일을 보냈을 때 무엇을 고쳐야 하는지 바로 알려 주는 기능입니다.

## 정확한 설명

클라이언트 검증은 submit 이벤트에서 값을 읽고 필수 여부·형식 같은 규칙을 검사한 뒤 오류 상태를 표시합니다. 오류는 관련 입력칸 가까이에 두고 정상 입력이 되면 이전 오류를 해제해야 사용자가 다음 행동을 알 수 있습니다.

브라우저 쪽 검증은 사용자 경험을 돕지만 서버 검증을 대체하지는 않습니다. M01은 화면에서 필드별 안내와 정상·오류 상태 전환을 명확히 보여 주는 데 초점을 둡니다.

## 이 미션에서는 왜 필요한가

Contact Form에서 필수값과 이메일 형식을 안내합니다.

## 코드 예

```js
form.addEventListener('submit', event => { if (!email.validity.valid) event.preventDefault(); });
```

## 관련 용어

- add-event-listener
- javascript
- ui-state

## 흔한 오해

alert만 띄우는 것은 입력칸별로 수정할 정보를 충분히 전달하지 못합니다.
