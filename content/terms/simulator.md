# 시뮬레이터

## 한 줄 설명

현실 또는 대상 시스템의 동작을 모델로 흉내 내는 프로그램.

## 쉽게 설명하면

실제 장비를 건드리기 전에 가상 환경에서 결과를 시험하는 도구다.

## 정확한 설명

입력·상태 전이·시간·확률 규칙을 정의해 결과를 계산한다. 모델의 가정이 simulator 결과의 신뢰 범위를 결정한다.

## 언제 쓰나

트래픽 증가가 큐 대기 시간에 미치는 영향을 모의한다.

## 기억할 경계

시뮬레이션 결과는 실제 운영 측정값과 같은 증거가 아니다.

## 이 미션에서는 왜 필요한가

하드웨어를 사서 쓰는 대신 그 동작 규칙을 프로그램으로 옮겨 놓은 것이 이 회차의 결과물입니다. 흉내 낸 것이므로 계산 결과는 같아도 걸린 시간은 실제 장치와 무관하다는 점을 결과 보고에서 분명히 해야 합니다.

## 코드 예

```text
시뮬레이터가 재현하는 것 / 재현하지 못하는 것

  재현한다      연산의 순서와 결과값, 연산 횟수
  재현 못 한다  실제 소요 시간, 전력, 병렬 처리

따라서 "시뮬레이터에서 2배 빨랐다" 는 말은 성립하지 않는다.
"곱셈-덧셈 횟수가 절반이었다" 라고 말해야 한다.
```
