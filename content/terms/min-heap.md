# 최소 힙

## 한 줄 설명

가장 작은 값이 루트에 있는 완전 이진 트리 기반 우선순위 큐.

## 쉽게 설명하면

늘 가장 급한, 즉 가장 작은 우선순위의 일을 맨 위에 올려둔다.

## 정확한 설명

부모 값은 자식 값보다 작거나 같다는 힙 속성을 유지한다. 최솟값 조회는 O(1), 삽입과 삭제는 O(log n)이다.

## 구조와 선택

문제의 관계·순서·비용을 먼저 정의하고, 그 조건에 맞는 자료구조와 알고리즘을 선택한다.

## 사용 장면

최단 경로 탐색에서 다음 후보 중 비용이 가장 작은 정점을 꺼낸다.

## 경계와 오해

전체가 정렬된 배열은 아니므로 임의 위치의 값을 빠르게 찾는 용도에는 맞지 않는다.

## 동료평가 질문

만료 처리를 힙으로 할 때와 전체를 훑을 때의 차이를, 저장된 키 개수를 바꿔 가며 설명할 수 있나요?

## 이 미션에서는 왜 필요한가

만료 시각이 가장 이른 항목을 반복해서 꺼내야 할 때, 전체를 다시 정렬하지 않고 맨 위 하나만 보면 되게 해 줍니다. 이 회차의 만료 처리가 이 구조를 쓰는 이유이며, 전체를 매번 훑는 방식과의 차이는 항목이 많아질수록 커집니다.

## 코드 예

```python
import heapq, time

expiry = []
heapq.heappush(expiry, (time.time() + 60, 'session:1'))
heapq.heappush(expiry, (time.time() + 5, 'session:2'))

now = time.time()
while expiry and expiry[0][0] <= now:     # 맨 위만 보면 된다
    _, key = heapq.heappop(expiry)
    print('만료', key)
```

## 관련 용어

- `heap-property`
- `shortest-path`
