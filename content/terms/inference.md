# 추론

## 한 줄 설명

학습된 모델에 새 입력을 넣어 결과를 계산하는 단계.

## 쉽게 설명하면

공부를 마친 모델이 실제 질문에 답하는 시간이다.

## 정확한 설명

파라미터는 보통 고정한 채 forward pass를 수행하고, 생성 모델은 다음 token 선택을 반복한다.

## 대표 사용

배포한 분류기가 새 이미지의 라벨 확률을 낸다.

## 주의할 점

추론 결과는 훈련 데이터 밖의 입력에서 틀리거나 편향될 수 있다.

## 이 미션에서는 왜 필요한가

학습이 끝난 모델에 새 입력을 넣어 답을 얻는 단계이며, 이 회차의 NPU가 맡는 일이 바로 이쪽입니다. 학습과 추론은 필요한 계산도 비용도 다르므로, 무엇을 흉내 내고 있는지 구분해 두어야 합니다.

## 코드 예

```text
학습 (training)              추론 (inference) ← 이번 회차
  가중치를 바꾼다               가중치는 고정
  정답이 필요하다               입력만 있으면 된다
  느리고 비싸다, 한 번          빠르고 싸다, 계속 반복
  GPU 가 유리하다               NPU 가 자리를 얻는 지점

NPU 가 따로 존재하는 이유가 이 오른쪽 열에 있다.
```
