# 속성

## 한 줄 설명

객체나 클래스에 붙어 그 상태 또는 메타데이터를 나타내는 이름 붙은 값입니다.

## 쉽게 설명하면

학생 카드에 이름·학번 칸이 붙어 있는 것처럼 객체가 가진 정보 칸입니다.

## 정확한 설명

Python에서 attribute는 `object.name` 형태로 접근하며 인스턴스 attribute, class attribute, property처럼 저장·조회 규칙이 다를 수 있습니다.

## 이 미션에서는 왜 필요한가

예비 M02에서 클래스가 보유하는 데이터를 메서드와 구분해 모델링합니다.

## 코드 예

```python
user.name = 'Mina'
```

## 관련 용어

- `class`
- `method`
- `python-dataclass`
