# NumPy와 pandas

## 한 줄 설명

수치 배열 처리와 표 형태 데이터 분석에 널리 쓰이는 Python 외부 라이브러리입니다.

## 쉽게 설명하면

큰 숫자 표와 계산을 손으로 처리하지 않게 돕는 전문 도구 상자입니다.

## 정확한 설명

NumPy는 다차원 배열과 벡터화 연산을, pandas는 Series·DataFrame 기반의 표 데이터 조작을 제공합니다. 둘 다 Python 표준 라이브러리에는 포함되지 않습니다.

## 이 미션에서는 왜 필요한가

예비 M03에서 외부 라이브러리 사용 금지 조건을 이해하고 허용된 도구 범위를 지키는 데 필요합니다.
