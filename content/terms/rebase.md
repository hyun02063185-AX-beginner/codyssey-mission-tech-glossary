# 리베이스

## 한 줄 설명

commit을 다른 base 위에 다시 적용해 history를 재구성하는 작업.

## 쉽게 설명하면

`리베이스`은(는) 변경을 기록하고 동료와 안전하게 공유하는 Git 작업 흐름의 한 부분입니다.

## 정확한 설명

commit을 다른 base 위에 다시 적용해 history를 재구성하는 작업. local history, remote state, review 규칙의 역할을 구분해 사용해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M02는 두 대의 PC에서 작업하는 상황을 다룹니다. 양쪽에서 각각 커밋이 쌓이면 이력이 갈라지는데, 리베이스는 그것을 한 줄로 다시 세워 읽기 쉽게 만듭니다. 다만 이미 공유한 커밋에는 쓰지 않는 것이 원칙입니다.

## 코드 예

```bash
git pull --rebase origin main
# 내 커밋을 원격 커밋 뒤로 옮겨 붙여 이력을 한 줄로 만든다
```

## 관련 용어

- `git`
- `commit`
