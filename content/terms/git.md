# Git

## 한 줄 설명

Git은 파일 변경 이력을 커밋으로 기록하고, 여러 사람이 그 이력을 합칠 수 있게 하는 분산 버전 관리 시스템입니다.

## 쉽게 설명하면

문서를 저장할 때마다 이전 상태를 남기고, 필요하면 어느 저장 시점으로 돌아가거나 동료의 변경과 비교할 수 있게 하는 도구입니다.

## 정확한 설명

Git은 각 개발자의 컴퓨터에 저장소와 이력 전체를 둘 수 있습니다. 커밋은 특정 시점의 스냅샷과 부모 커밋을 가리키고, 브랜치는 커밋을 가리키는 참조입니다. GitHub 같은 원격 호스팅 서비스와 Git 자체는 구분해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M02와 본과정 M04에서 작업 이력을 남기고 브랜치·PR 기반 협업을 수행합니다.

## 관련 용어

- commit
- branch
- merge
- github

## 흔한 오해

Git과 GitHub는 같은 제품이 아닙니다. Git은 버전 관리 도구이고 GitHub는 Git 저장소를 호스팅하고 협업 기능을 제공하는 서비스입니다.
