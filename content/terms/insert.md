# INSERT

## 한 줄 설명

새 row를 table에 추가하는 SQL 명령.

## 쉽게 설명하면

표에 새 줄을 하나 넣는 명령입니다. 표가 요구하는 필수 칸을 채우지 않으면 거부됩니다.

## 정확한 설명

열 이름과 값을 짝지어 새 행을 만든다. 열 이름을 생략하면 표에 정의된 순서를 그대로 따르게 되어 나중에 열이 추가되면 깨지므로, 이름을 명시하는 편이 안전하다. 제약을 위반하면 행이 만들어지지 않고 오류가 난다.

## 이 미션에서는 왜 필요한가

이 회차에서 표를 만든 뒤 샘플 데이터를 넣는 데 씁니다. 여기서 제약 위반 오류를 만나는 것이 오히려 좋은 신호인데, 설계한 제약이 실제로 동작한다는 뜻이기 때문입니다.

## 코드 예

```sql
-- 열 이름을 명시한다. 생략하면 나중에 열이 추가될 때 깨진다
INSERT INTO post (title, body, author_id)
VALUES ('첫 글', '내용입니다', 3);

-- 여러 줄을 한 번에
INSERT INTO tag (name) VALUES ('공지'), ('질문'), ('후기');
```

## 주의할 점 / 경계 조건

값을 문자열로 이어 붙여 만들면 입력에 따옴표가 섞였을 때 쿼리 구조가 바뀝니다. 반드시 자리 표시자를 써서 값으로 전달해야 합니다.

## 관련 용어

- `sql`
- `table`

## 흔한 오해

오류 없이 실행됐으니 들어갔다고 생각하기 쉽지만, 트랜잭션 안이라면 확정하기 전까지는 밖에서 보이지 않습니다.
