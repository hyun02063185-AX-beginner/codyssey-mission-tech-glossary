# 패킷

## 한 줄 설명

패킷은 네트워크로 데이터를 나눠 옮기는 단위로, 앞부분(헤더)에 출발지·목적지 IP 주소 같은 전달 정보가 적혀 있습니다.

## 쉽게 설명하면

주소가 적힌 봉투에 비유할 수 있습니다. 봉투 겉면에는 보내는 곳과 받는 곳이 있고, 안에는 실제 내용이 들어 있습니다. 큰 짐을 여러 상자로 나눠 보내듯 큰 데이터는 여러 패킷으로 나뉘어 갑니다. 비유는 여기까지입니다. 실제 패킷은 봉투 안에 다른 프로토콜의 정보가 겹겹이 들어 있습니다.

## 정확한 설명

여기서 패킷은 IP 패킷을 말합니다. IP 헤더에는 출발지 IP 주소와 목적지 IP 주소가 있고, 라우터는 목적지 주소를 보고 다음 경로를 고릅니다.

이 그림처럼 IPv4·TCP·HTTP 80으로 보내는 웹 요청에서는 IP 패킷 안에 TCP 세그먼트가 들어 있고, TCP 헤더에 출발지·목적지 포트 번호가 있습니다. 그 안에 HTTP 요청 같은 내용이 들어갑니다. 그래서 주소는 IP 정보, 포트는 TCP 정보입니다.

HTTP 요청 하나가 항상 패킷 하나에 담기는 것은 아닙니다. 데이터는 여러 TCP 세그먼트·IP 패킷으로 나뉠 수 있고, 연결을 맺거나 받았음을 알리는 TCP 패킷에는 HTTP 내용이 없을 수도 있습니다. 장비 사이 전달에 쓰는 MAC 주소 같은 링크 계층 정보는 이 설명에서 생략합니다.

IP는 주소와 전달, TCP는 포트 구분과 신뢰성 있는 바이트 전송, HTTP는 웹 요청의 의미를 맡습니다. TCP는 암호화나 HTTP 요청의 성공을 보장하지 않습니다. 모든 HTTP가 TCP를 쓰는 것은 아니며 HTTP/3는 QUIC을 사용합니다.

그림의 두 IP는 문서용 주소로 실제 접속 주소가 아닙니다. 아래 역할 목록은 정보를 활용하는 방식의 비교이며 통과 장비의 순서가 아닙니다. Route Table은 경로 설정이고 Security Group은 허용 규칙입니다. NAT는 필요에 따라 IP 주소·포트를 바꾸며, B3-1 IPv4 사례의 IGW는 공인·사설 주소를 1:1 변환합니다.

## 이 미션에서는 왜 필요한가

B3-1(M05)의 AWS 설정은 패킷의 서로 다른 정보를 다룹니다. 인터넷 게이트웨이는 IP 주소를 공인↔사설로 바꾸고, Route Table은 목적지 IP 주소로 다음 대상을 정하며, Security Group은 출발지 IP·프로토콜·목적지 포트로 허용 여부를 판단하고, Nginx는 HTTP 내용을 읽고 응답합니다. 패킷 안에 무엇이 있는지 알면 각 설정이 무엇을 보는지 구분할 수 있습니다.

## 코드 예

```text
요청 패킷 하나를 겹으로 읽기 (IPv4 · HTTP 80 예시 · 문서용 주소)

  IP 헤더      출발지 IP 198.51.100.25    목적지 IP 203.0.113.10
   └ TCP 헤더   출발지 포트 51514          목적지 포트 80
      └ HTTP    GET /   (홈페이지를 주세요)

누가 무엇을 보나
  라우터 · Route Table        목적지 IP                → 다음 경로
  방화벽 · Security Group     출발지 IP · 프로토콜 · 포트 → 허용 / 차단
  NAT · 인터넷 게이트웨이      IP 주소를 바꾼다
  웹 서버 (Nginx)             HTTP 내용을 읽고 응답한다
```

## 주의할 점 / 경계 조건

패킷이 목적지에 도착하는 것과 요청이 성공하는 것은 다릅니다. 패킷이 잘 도착해도 서버가 HTTP 오류로 응답할 수 있고, 허용 규칙이 없으면 중간에 버려질 수 있습니다.

## 흔한 오해

"포트 번호도 IP 주소의 일부"라고 생각하기 쉽지만, 포트는 IP 헤더가 아니라 TCP·UDP 헤더에 있습니다. `203.0.113.10:80`처럼 붙여 쓰는 것은 주소와 포트를 함께 적는 표기일 뿐입니다.

## 비슷한 개념과의 차이

IP 패킷은 주소를 보고 목적지까지 옮기는 단위이고, TCP 세그먼트는 그 안에 담겨 포트와 순서 정보를 가지는 TCP의 단위입니다. HTTP 요청은 무엇을 원하는지 담은 내용의 단위이고, 패킷은 그 내용을 나눠 옮기는 단위입니다.
