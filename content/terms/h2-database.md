# H2

## 한 줄 설명

Java 기반 application에서 자주 쓰는 경량 relational database.

## 쉽게 설명하면

자바 프로그램 안에서 도는 가벼운 데이터베이스입니다. 시험용으로 메모리에만 띄워 쓰는 일이 많습니다.

## 정확한 설명

자바로 작성되어 애플리케이션과 같은 프로세스에서 동작할 수 있다. 메모리 모드로 띄우면 프로세스가 끝날 때 데이터가 사라지므로 자동 시험에 알맞고, 다른 데이터베이스의 문법을 흉내 내는 호환 모드를 제공한다.

## 이 미션에서는 왜 필요한가

이 회차의 선택지 중 하나입니다. 파이썬으로 실습한다면 직접 쓸 일은 없지만, 자바 쪽 자료를 읽을 때 자주 나오므로 파일 기반과 같은 자리를 차지하는 도구라는 점을 알아 두면 됩니다.

## 코드 예

```text
자리로 보면

  파이썬 실습      SQLite        파일 하나, 설치 없음
  자바 실습        H2            프로세스 안, 설치 없음
  실제 서비스      PostgreSQL / MySQL

H2 를 메모리 모드로 쓰면 시험이 끝날 때 데이터가 사라진다.
시험마다 깨끗한 상태로 시작할 수 있다는 것이 이점이다.

대신 실제 데이터베이스와 동작이 다를 수 있으므로,
중요한 쿼리는 실제 환경에서도 한 번 확인한다.
```

## 주의할 점 / 경계 조건

호환 모드를 켜도 실제 데이터베이스와 동작이 완전히 같지는 않습니다. 시험은 통과하는데 실제 환경에서 실패하는 일이 생깁니다.

## 관련 용어

- `sql`
- `table`

## 흔한 오해

시험에서 통과했으니 실제 데이터베이스에서도 된다고 생각하기 쉽지만, 흉내 내는 범위가 제한적입니다. 중요한 쿼리는 실제 환경에서도 확인해야 합니다.
