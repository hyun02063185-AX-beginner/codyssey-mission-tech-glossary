# Docker 이미지

## 한 줄 설명

Docker 이미지는 컨테이너를 만들 때 사용할 파일과 실행 설정을 담은 읽기 전용 템플릿입니다.

## 쉽게 설명하면

이미지는 실행 환경의 설계본이고, 컨테이너는 그 설계본으로 실제 실행한 결과입니다.

## 정확한 설명

이미지는 여러 레이어로 구성되며, Dockerfile의 명령이 보통 레이어를 만듭니다. 같은 이미지는 여러 컨테이너가 공유할 수 있습니다. 실행 중에 컨테이너 안에서 바꾼 내용은 이미지 자체를 바꾸지 않으며, 새 이미지를 만들려면 다시 빌드해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M01에서 기본 이미지를 확인하고 Dockerfile로 만든 이미지를 실행합니다.

## 관련 용어

- docker
- docker-container
- dockerfile

## 흔한 오해

이미지는 실행 중인 프로그램이 아닙니다. 실행하면 그때 컨테이너가 만들어집니다.
