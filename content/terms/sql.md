# SQL

## 한 줄 설명

SQL은 관계형 데이터베이스의 표와 데이터를 정의하고 조회·변경하기 위해 쓰는 언어입니다.

## 쉽게 설명하면

"사용자 표에서 이름이 민아인 사람을 찾아 줘"처럼 데이터베이스에 원하는 결과를 선언하는 언어입니다.

## 코드 예

```sql
SELECT name FROM users WHERE id = 1;
```

## 정확한 설명

SQL은 데이터 정의(테이블 만들기), 데이터 조작(조회·삽입·수정·삭제), 권한 제어 등을 포함합니다. SQL 문법은 데이터베이스 제품마다 조금씩 다를 수 있습니다. 사용자 입력을 문자열로 이어 붙이지 말고 매개변수 바인딩을 사용해야 SQL 인젝션 위험을 줄일 수 있습니다.

## 이 미션에서는 왜 필요한가

본과정 M11에서 데이터 모델을 만들고 조회하며, M12에서는 백엔드가 데이터베이스와 대화하는 기반이 됩니다.

## 관련 용어

- relational-database
- join
- primary-key
- sqlalchemy

## 흔한 오해

SQL은 특정 데이터베이스 제품명이 아닙니다. PostgreSQL, MySQL, SQLite 등이 SQL을 서로 조금씩 다르게 구현합니다.
