# Threshold

## 한 줄 설명

값이 정상·경고·실패 같은 다음 행동으로 바뀌는 기준점입니다.

## 쉽게 설명하면

온도가 일정 수치를 넘으면 경보가 울리게 하는 선입니다.

## 정확한 설명

Threshold는 관찰한 값을 비교해 분기나 알림을 결정하는 도메인·운영 기준입니다. 값 자체가 아니라 측정 단위, 지속 시간, 오탐 비용과 함께 정의해야 합니다.

## 이 미션에서는 왜 필요한가

M07에서 CPU나 메모리 사용량이 WARNING 기준을 넘었는지 판단합니다.

## 코드 예

```python
if cpu_percent >= 80:
    logger.warning('CPU threshold exceeded')
```

## 주의할 점 / 경계 조건

순간 spike 하나에 즉시 종료할지, 일정 시간 지속을 요구할지는 서비스의 위험도와 측정 간격에 따라 다릅니다.

## 관련 용어

- `cpu-usage`
- `logging`
- `verification`

## 흔한 오해

80% 같은 숫자는 보편적으로 옳은 기준이 아니라 시스템 목적에 맞춰 정해야 합니다.
