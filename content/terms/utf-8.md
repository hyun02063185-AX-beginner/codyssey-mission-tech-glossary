# UTF-8

## 한 줄 설명

UTF-8은 글자에 번호를 붙인 Unicode를 바이트로 저장하는 대표적인 인코딩 방식입니다.

## 쉽게 설명하면

`가`, `A`, 😀처럼 서로 다른 글자를 파일에 저장할 때, 컴퓨터가 어떤 바이트 순서로 기록하고 읽을지 정하는 약속입니다.

## 정확한 설명

UTF-8은 문자를 1~4바이트로 표현하며 ASCII와 호환됩니다. 파일을 UTF-8로 저장하고 다른 인코딩으로 읽으면 글자가 깨질 수 있습니다. Unicode는 문자 집합이고 UTF-8은 그 문자를 저장하는 방법이라는 점을 구분해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M02에서 `state.json`을 저장하고 읽을 때 한글 데이터가 깨지지 않게 인코딩을 명시합니다.

## 코드 예

```python
open('state.json', encoding='utf-8')
```

## 관련 용어

- json
- file-io
- encoding

## 흔한 오해

UTF-8이 글자 자체의 언어는 아닙니다. 한글·영문 등 문자 데이터를 바이트로 바꾸는 방식입니다.
