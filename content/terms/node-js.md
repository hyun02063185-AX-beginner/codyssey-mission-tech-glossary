# Node.js

## 한 줄 설명

Node.js는 브라우저 밖에서 JavaScript를 실행할 수 있게 하는 런타임입니다.

## 쉽게 설명하면

웹페이지의 버튼을 움직이는 JavaScript뿐 아니라, 터미널 도구나 서버 프로그램도 JavaScript로 실행할 수 있게 해 주는 환경입니다.

## 정확한 설명

Node.js는 V8 JavaScript 엔진과 파일·네트워크 같은 시스템 기능을 제공하는 런타임입니다. React 앱을 개발할 때는 빌드 도구와 개발 서버를 실행하는 데 자주 쓰고, 서버 API를 만들 수도 있습니다. Node.js는 npm이나 JavaScript 언어 자체와는 다른 역할입니다.

## 이 미션에서는 왜 필요한가

본과정 M02에서 React 프로젝트의 의존성을 설치하고 개발 서버·빌드 스크립트를 실행합니다.

## 관련 용어

- javascript
- npm
- cli

## 흔한 오해

Node.js를 설치했다고 브라우저가 필요 없어지는 것은 아닙니다. 브라우저와 Node.js는 JavaScript를 실행하는 서로 다른 환경입니다.
