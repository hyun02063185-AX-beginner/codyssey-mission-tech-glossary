# Python 3.10+

## 한 줄 설명

Python은 읽기 쉬운 문법으로 자동화, 데이터 처리, 웹 서버 등 다양한 프로그램을 만들 수 있는 범용 프로그래밍 언어입니다.

## 쉽게 설명하면

`print('안녕하세요')`처럼 비교적 간단한 문장으로 프로그램의 동작을 적고 실행하는 언어입니다.

## 정확한 설명

Python 프로그램은 보통 인터프리터가 소스 코드를 읽어 실행합니다. 들여쓰기는 코드 블록을 구분하는 문법의 일부이며, 패키지는 가상환경으로 프로젝트마다 분리해 관리할 수 있습니다. 버전이 달라지면 문법·표준 라이브러리 동작도 달라질 수 있으므로 실행 버전을 명시합니다.

## 이 미션에서는 왜 필요한가

예비 M02에서 CLI 프로그램을 만들고, 본과정 M03·M12·M13에서 데이터 처리와 백엔드 구현에 사용합니다.

## 관련 용어

- python-virtual-environment

## 흔한 오해

Python은 느리기만 한 언어라는 말은 지나친 단순화입니다. 작업 성격과 사용하는 라이브러리에 따라 병목과 실행 방식이 달라집니다.
