# Closes #

## 한 줄 설명

issue 번호와 함께 써 병합 시 issue를 자동 종료하는 keyword.

## 쉽게 설명하면

검토 요청 본문에 `Closes #12`처럼 적어 두면 합쳐질 때 그 이슈가 자동으로 닫히게 하는 표현입니다.

## 정확한 설명

정해진 낱말과 이슈 번호를 함께 적으면 합쳐질 때 그 이슈가 닫히고 양쪽이 서로 연결된다. 기본 브랜치에 합쳐질 때만 동작하며, 본문이 아니라 댓글에 적으면 연결은 되어도 자동으로 닫히지는 않는다.

## 이 미션에서는 왜 필요한가

이 회차에서 검토 요청과 이슈를 잇는 수단입니다. 손으로 닫으면 잊기 쉬워 끝난 일이 목록에 남는데, 그러면 이슈 목록이 현재 상황을 보여 주지 못하게 됩니다.

## 코드 예

```text
Pull Request 본문에

  로그인 실패 메시지를 통일합니다.

  Closes #12

쓸 수 있는 낱말
  close / closes / closed
  fix / fixes / fixed
  resolve / resolves / resolved

여러 개를 닫으려면 각각 적는다
  Closes #12
  Closes #13
  (Closes #12, #13 은 앞의 것만 닫힌다)

기본 브랜치에 합쳐질 때만 닫힌다.
```

## 주의할 점 / 경계 조건

기본 브랜치로 합쳐질 때만 닫힙니다. 다른 브랜치로 합치면 연결만 되고 닫히지는 않습니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

어디에 적어도 동작한다고 생각하기 쉽지만, 검토 요청의 본문이나 커밋 메시지에 있어야 합니다. 댓글에 적으면 자동으로 닫히지 않습니다.
