# 사용자

## 한 줄 설명

Linux system에서 identity와 권한을 가진 user account.

## 쉽게 설명하면

시스템에서 누구인지를 나타내는 계정입니다. 사람마다 하나씩 두기도 하고, 서비스 전용으로 만들기도 합니다.

## 정확한 설명

계정마다 숫자 ID와 기본 그룹, 홈 디렉터리, 로그인 셸이 지정된다. 권한 판정에 쓰이는 것은 이름이 아니라 숫자 ID이며, 서비스용 계정에는 로그인 셸을 주지 않아 사람이 접속하는 통로로 쓰이지 않게 한다.

## 이 미션에서는 왜 필요한가

이 회차는 실습용 계정을 만들도록 요구합니다. 계정을 나누면 어떤 파일이 누구 것인지가 정해지고 로그에도 누가 무엇을 했는지 남으므로, 권한 실습의 출발점이 됩니다.

## 코드 예

```bash
sudo useradd -m -s /bin/bash agent-admin      # 사람이 쓸 계정
sudo useradd -r -s /usr/sbin/nologin agent    # 서비스 전용 — 로그인 불가

id agent-admin
# uid=1001(agent-admin) gid=1001(agent-admin) groups=1001(agent-admin)
#     ↑ 권한 판정에 쓰이는 것은 이 숫자다

# 지울 때 홈 디렉터리 처리를 함께 정한다
sudo userdel -r agent-admin        # -r 이 없으면 홈이 남는다
```

## 주의할 점 / 경계 조건

계정을 지울 때 홈 디렉터리와 그 계정이 만든 파일을 어떻게 할지 함께 정해야 합니다. 그냥 지우면 주인 없는 파일이 남습니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

계정 이름이 권한을 정한다고 생각하기 쉽지만, 실제 판정은 숫자 ID로 이뤄집니다. 이름을 바꿔도 권한은 그대로이고, 같은 번호를 쓰는 다른 이름은 같은 권한을 갖습니다.
