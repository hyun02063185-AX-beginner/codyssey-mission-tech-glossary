# Health Check Endpoint

## 한 줄 설명

서비스 상태를 확인하도록 만든 HTTP endpoint.

## 쉽게 설명하면

`Health Check Endpoint`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

liveness와 readiness 목적, 상태 코드, timeout, 의존성 검사 범위를 분명히 정한다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
Health Check Endpoint
```

## 관련 용어

- `health-check`
- `http-status-code`
