# 출력 검증

## 한 줄 설명

모델 또는 프로그램 출력이 요구한 형식·범위·안전 조건을 만족하는지 확인하는 절차.

## 쉽게 설명하면

답을 바로 믿지 않고 사용할 수 있는 모양인지 마지막으로 검사하는 단계다.

## 정확한 설명

schema 검사, 허용값 검증, 길이 제한, 정책 검사처럼 소비자 계약에 맞춘 검증을 적용한다.

## 선택 기준

입력의 형태, 기대 결과, 비용과 실패 조건을 분리해 이 개념이 맡는 역할을 판단합니다.

## 실제 사용

JSON 응답을 저장하기 전에 필수 필드와 타입을 확인한다.

## 경계와 오해

형식이 맞아도 내용의 사실성까지 증명하지는 않는다.

## 동료평가 질문

검사를 통과했는데도 결과가 쓸모없을 수 있는 경우를 하나 들고, 그때 무엇으로 걸러 낼지 설명할 수 있나요?

## 이 미션에서는 왜 필요한가

이 회차는 제목 길이와 섹션 형식을 검사하도록 요구합니다. 모델은 지시를 대체로 따르지만 항상은 아니므로, 검사 없이 그대로 쓰면 가끔 형식이 어긋난 결과가 그대로 커밋 메시지가 됩니다. 검사는 형식까지만 보증한다는 점도 함께 알아야 합니다.

## 코드 예

```python
def validate(result):
    problems = []
    title = result.get('title', '')
    if not title:
        problems.append('제목이 없습니다')
    elif len(title) > 50:
        problems.append(f'제목이 {len(title)}자입니다 (최대 50)')
    if not result.get('body'):
        problems.append('본문이 없습니다')
    return problems

# 형식만 본다. 내용이 diff 와 맞는지는 사람이 봐야 한다
```
