# 인코딩

## 한 줄 설명

문자를 byte열로 바꾸고 다시 해석하는 규칙.

## 쉽게 설명하면

`인코딩`은(는) 데이터를 읽고 바꾸는 과정에서 어떤 구조와 규칙이 필요한지 보여 주는 개념입니다.

## 정확한 설명

문자를 byte열로 바꾸고 다시 해석하는 규칙. 설계와 실행에서는 값의 형태, 관계, 제약, transaction 경계를 구분해 판단해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M02에서 상태 파일을 저장하고 읽을 때 UTF-8을 지정해야 하는 이유입니다. 지정하지 않으면 운영체제 기본값을 따라가는데, 그 값이 컴퓨터마다 달라 한글이 깨져 보이는 일이 생깁니다.

## 코드 예

```python
open("state.json", "w", encoding="utf-8")   # 반드시 지정한다

# 지정하지 않으면 Windows 기본값으로 저장돼
# 다른 컴퓨터에서 열 때 한글이 깨진다
```

## 주의할 점 / 경계 조건

한 query가 성공했다고 data model 전체가 안전한 것은 아닙니다. NULL, 중복, foreign key, 동시 변경, transaction 범위를 함께 확인해야 합니다.

## 관련 용어

- `utf-8`
- `file-io`

## 흔한 오해

글자가 깨지면 파일이 손상된 것으로 생각하기 쉽지만, 대부분은 저장할 때와 읽을 때 규칙이 달랐을 뿐입니다. 같은 바이트를 맞는 규칙으로 다시 읽으면 그대로 살아납니다.
