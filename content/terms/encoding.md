# 인코딩

## 한 줄 설명

문자를 byte열로 바꾸고 다시 해석하는 규칙.

## 쉽게 설명하면

글자를 컴퓨터가 저장하는 숫자로 바꾸는 규칙입니다. 저장할 때와 읽을 때 규칙이 다르면 깨집니다.

## 정확한 설명

문자와 바이트 사이의 대응 규칙이다. 파일에는 어떤 규칙으로 저장했는지가 기록되지 않으므로 읽는 쪽이 정해야 하고, 지정하지 않으면 실행 환경의 기본값이 쓰인다. 글자가 깨진 것은 파일이 손상된 것이 아니라 규칙이 어긋난 것이다.

## 이 미션에서는 왜 필요한가

예비 M02에서 상태 파일을 저장하고 읽을 때 UTF-8을 지정해야 하는 이유입니다. 지정하지 않으면 운영체제 기본값을 따라가는데, 그 값이 컴퓨터마다 달라 한글이 깨져 보이는 일이 생깁니다.

## 코드 예

```python
open("state.json", "w", encoding="utf-8")   # 반드시 지정한다

# 지정하지 않으면 Windows 기본값으로 저장돼
# 다른 컴퓨터에서 열 때 한글이 깨진다
```

## 주의할 점 / 경계 조건

파일에는 어떤 규칙으로 저장했는지가 적혀 있지 않습니다. 읽는 쪽이 맞게 지정하는 수밖에 없습니다.

## 관련 용어

- `utf-8`
- `file-io`

## 흔한 오해

글자가 깨지면 파일이 손상된 것으로 생각하기 쉽지만, 대부분은 저장할 때와 읽을 때 규칙이 달랐을 뿐입니다. 같은 바이트를 맞는 규칙으로 다시 읽으면 그대로 살아납니다.

## 동료평가 질문

다른 컴퓨터에서 열었을 때도 한글이 깨지지 않는다는 것을 어떻게 보이겠습니까?
