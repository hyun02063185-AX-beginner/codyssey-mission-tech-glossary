# 부동소수점

## 한 줄 설명

부동소수점은 실수를 유한한 비트로 근사해 표현하는 방식이라, 모든 소수를 정확히 담을 수는 없습니다.

## 쉽게 설명하면

컴퓨터는 `0.1` 같은 값을 2진수로 완벽하게 적지 못할 때가 있어 `0.1 + 0.2`가 정확히 `0.3`처럼 보이지 않을 수 있습니다.

## 코드 예

```python
0.1 + 0.2 == 0.3  # False가 될 수 있음
```

## 정확한 설명

일반적인 IEEE 754 부동소수점은 부호, 지수, 가수로 값을 저장합니다. 표현할 수 없는 값은 가장 가까운 값으로 반올림되고, 계산을 반복하면 오차가 누적될 수 있습니다. 그래서 실수 비교에는 허용 오차를 쓰거나, 돈처럼 정확한 10진 계산이 필요한 값에는 별도 자료형을 고려합니다.

## 이 미션에서는 왜 필요한가

예비 M03에서 벡터 계산 결과를 비교할 때 `epsilon`을 쓰는 이유를 이해합니다.

## 관련 용어

- epsilon
- ieee-754
- matrix-2d-array

## 흔한 오해

부동소수점 오차는 언어 버그가 아닙니다. 유한한 2진수 표현에서 생기는 계산상의 한계입니다.
