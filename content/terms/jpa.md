# JPA

## 한 줄 설명

Java object와 relational database를 mapping하는 persistence 표준 API.

## 쉽게 설명하면

자바에서 객체와 표를 잇는 방식을 정해 둔 표준입니다. 구현은 여러 가지가 있고 그중 하나를 골라 씁니다.

## 정확한 설명

어노테이션으로 클래스와 표를 대응시키고, 영속성 컨텍스트가 객체의 변경을 추적해 확정 시점에 SQL로 내보낸다. 표준이 정하는 것은 인터페이스이며 실제 동작은 구현체가 정하므로, 성능 특성은 구현체에 따라 달라진다.

## 이 미션에서는 왜 필요한가

이 회차 이후의 ORM 학습으로 이어지는 개념입니다. 파이썬 쪽 도구와 이름은 다르지만 해결하려는 문제는 같으므로, 한쪽을 이해하면 다른 쪽도 같은 구조로 읽힙니다.

## 코드 예

```text
이름만 다르고 구조는 같다

  자바                       파이썬
  JPA (표준)                 (표준 없음)
  Hibernate (구현체)         SQLAlchemy
  EntityManager              Session
  영속성 컨텍스트            Identity Map
  @Entity @Id @Column        declarative_base, Column

둘 다 같은 문제를 푼다
  객체의 변경을 추적해 SQL 로 바꾼다
  같은 행을 두 번 읽으면 같은 객체를 돌려준다
  목록을 돌며 연결을 읽으면 조회가 항목 수만큼 나간다
```

## 주의할 점 / 경계 조건

표준이 정한 범위 밖의 기능은 구현체마다 다릅니다. 표준만 보고 쓰면 구현체를 바꿀 때 동작이 달라질 수 있습니다.

## 관련 용어

- `sql`
- `table`

## 흔한 오해

표준이니 어느 구현체나 같다고 생각하기 쉽지만, 같은 것은 인터페이스뿐입니다. 어떤 SQL이 나가는지와 성능은 구현체가 정합니다.
