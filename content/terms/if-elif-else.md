# 조건문

## 한 줄 설명

조건의 참·거짓에 따라 서로 다른 코드를 하나 선택해 실행하는 제어 구조입니다.

## 쉽게 설명하면

갈림길 표지판을 보고 현재 조건에 맞는 길 하나를 고르는 것과 같습니다.

## 정확한 설명

Python의 `if`/`elif`/`else`는 위에서 아래로 조건을 평가하고 처음 참인 분기만 실행합니다. 조건 순서가 겹치면 먼저 쓴 조건이 우선합니다.

## 이 미션에서는 왜 필요한가

예비 M02 메뉴 입력과 상태별 처리를 명확한 분기로 구현하는 기초입니다.

## 코드 예

```python
if score >= 90:
    grade = 'A'
elif score >= 80:
    grade = 'B'
else:
    grade = 'C'
```

## 주의할 점 / 경계 조건

독립된 `if`를 여러 개 쓰면 여러 분기가 실행될 수 있어, 하나만 선택할 규칙에는 `elif`가 맞는지 확인해야 합니다.

## 관련 용어

- `loop`
- `input-validation`
- `state-transition`

## 흔한 오해

else는 오류 처리 전용이 아니라 앞선 모든 조건이 거짓일 때의 경로입니다.

## 동료평가 질문

90점 조건을 80점 조건 뒤에 두면 왜 A 등급이 나오지 않나요?
