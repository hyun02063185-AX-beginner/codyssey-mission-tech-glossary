# git amend

## 한 줄 설명

가장 최근 commit의 message 또는 staged snapshot을 바꾸는 명령.

## 쉽게 설명하면

방금 만든 커밋을 다시 만드는 명령입니다. 메시지를 고치거나 빠뜨린 파일을 더할 때 씁니다.

## 정확한 설명

마지막 커밋을 대체하는 새 커밋을 만든다. 고치는 것이 아니라 새로 만드는 것이라 해시가 달라지며, 이미 공유한 커밋에 쓰면 원격과 이력이 어긋나 강제로 밀어 넣어야 하는 상황이 된다.

## 이 미션에서는 왜 필요한가

이 회차의 트러블슈팅 항목 중 하나입니다. 커밋 직후 오타를 발견했을 때 가장 간단한 해결이지만, 이미 올린 뒤라면 쓰지 말아야 할 명령이 됩니다. 그 경계를 아는 것이 이 명령을 아는 것입니다.

## 코드 예

```bash
git commit -m "로그인 수정"
# 아차, 파일 하나를 빠뜨렸다

git add src/auth.py
git commit --amend --no-edit      # 메시지는 그대로, 파일만 추가

# 메시지만 고치기
git commit --amend -m "로그인 실패 메시지 통일"

# 이미 push 했다면 하지 않는다
git log origin/main..HEAD --oneline   # 여기에 있으면 아직 안 올렸다
```

## 주의할 점 / 경계 조건

이미 원격에 올린 커밋에 쓰면 강제로 밀어 넣어야 합니다. 팀이 쓰는 브랜치에서는 하지 않습니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

커밋을 수정하는 명령이라고 생각하기 쉽지만, 새 커밋으로 갈아 끼우는 것입니다. 해시가 달라지므로 원격과 어긋납니다.
