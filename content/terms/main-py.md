# main.py

## 한 줄 설명

Python 프로그램의 진입점으로 자주 쓰이는 파일 이름이며, 프로젝트가 정한 실행 시작 위치입니다.

## 쉽게 설명하면

책의 첫 장처럼 프로그램을 어디서 시작할지 알려 주는 약속된 표지입니다.

## 정확한 설명

`main.py`는 Python 언어가 강제하는 특별 파일명은 아니지만 과제·프로젝트에서 `python main.py` 실행 계약으로 사용될 수 있습니다.

## 이 미션에서는 왜 필요한가

예비 M03에서 제출 산출물의 파일명과 실행 경로를 요구사항대로 맞춥니다.

## 코드 예

```bash
python main.py
```
