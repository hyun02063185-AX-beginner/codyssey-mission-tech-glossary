# 인가

## 한 줄 설명

인가는 인증된 사용자가 특정 데이터나 기능에 접근해도 되는지 판단하는 과정입니다.

## 쉽게 설명하면

로그인한 사람 모두에게 같은 메뉴와 데이터를 보여 주지 않기 위해 쓰는 규칙입니다. 예를 들어 일반 사용자는 자기 글만 수정하고, 관리자는 모든 글을 관리할 수 있습니다.

## 정확한 설명

서버는 요청한 사용자의 역할, 소유권, 정책을 확인한 뒤 허용하거나 거절합니다. 화면에서 버튼을 숨기는 것만으로는 충분하지 않으며, 실제 데이터를 주는 서버도 같은 규칙을 검사해야 합니다.

## 이 미션에서는 왜 필요한가

- main M13: 역할에 따라 보호된 기능과 데이터를 구분합니다.

## 관련 용어

- `authentication`
- `access-control`
- `rbac`

## 흔한 오해

클라이언트 화면의 숨김 처리는 보안 경계가 아닙니다. 권한 검사는 서버에서도 해야 합니다.

## 동료평가 질문

다른 사용자의 글 ID를 주소에 넣었을 때도 서버가 권한을 확인해야 하는 이유는 무엇인가요?
