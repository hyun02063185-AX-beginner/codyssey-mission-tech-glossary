# useMemo

## 한 줄 설명

dependency가 같을 때 이전 계산 결과를 재사용하는 React Hook.

## 쉽게 설명하면

`useMemo`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

correctness 저장소가 아니라 비용을 측정한 뒤 선택하는 render 최적화다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
useMemo
```

## 관련 용어

- `memoization`
- `usecallback`
