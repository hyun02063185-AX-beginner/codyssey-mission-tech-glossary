# useMemo

## 한 줄 설명

dependency가 같을 때 이전 계산 결과를 재사용하는 React Hook.

## 쉽게 설명하면

계산 결과를 기억해 두었다가 재료가 그대로면 다시 계산하지 않는 Hook입니다. 계산이 비쌀 때만 의미가 있습니다.

## 정확한 설명

correctness 저장소가 아니라 비용을 측정한 뒤 선택하는 render 최적화다.

## 이 미션에서는 왜 필요한가

이 회차의 성능 보너스에서, 큰 목록을 거르거나 정렬하는 계산이 입력할 때마다 반복되는 경우에 씁니다. 재 보지 않고 먼저 붙이면 기억하는 비용만 늘고 얻는 것이 없습니다.

## 코드 예

```jsx
// 입력할 때마다 1만 건을 다시 거른다
const visible = items.filter(i => i.title.includes(query));

// 재료가 그대로면 다시 계산하지 않는다
const visible = useMemo(
  () => items.filter(i => i.title.includes(query)),
  [items, query],
);

// 이 정도 계산에는 붙일 이유가 없다 — 기억하는 비용이 더 크다
const total = useMemo(() => a + b, [a, b]);
```

## 주의할 점 / 경계 조건

React는 필요하면 기억한 값을 버릴 수 있습니다. 반드시 유지되어야 하는 값을 여기에 두면 안 됩니다.

## 관련 용어

- `memoization`
- `usecallback`

## 흔한 오해

값이 절대 다시 계산되지 않는다고 생각하기 쉽지만 보장이 아닙니다. 결과가 항상 같아야 하는 것은 계산을 되풀이해도 같은 값이 나오도록 만들어야지, 기억에 의존하면 안 됩니다.
