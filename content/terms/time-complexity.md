# 시간복잡도

## 한 줄 설명

시간복잡도는 입력이 커질 때 알고리즘의 작업량이 어떤 비율로 늘어나는지 나타내는 방법입니다.

## 쉽게 설명하면

데이터가 두 배가 되었을 때 일이 두 배쯤 늘어나는지, 네 배쯤 늘어나는지를 비교하는 표기입니다. 한 번의 실행 시간이 아니라 성장하는 모습을 봅니다.

## 정확한 설명

Big-O 표기는 충분히 큰 입력에서 지배적인 증가율을 나타냅니다. 예를 들어 배열을 한 번 훑는 작업은 보통 O(n), 두 항목을 모두 비교하는 이중 반복은 O(n²)로 설명합니다. 상수 시간이나 실제 기기 속도까지 완전히 무시한다는 뜻은 아닙니다.

## 이 미션에서는 왜 필요한가

- main M09: 자료구조와 탐색 방법의 성능 차이를 설명합니다.

## 관련 용어

- `big-o-notation`
- `hash-map`
- `binary-search-tree`

## 흔한 오해

O(n)이 항상 빠르고 O(log n)이 항상 빠르다는 뜻은 아닙니다. 입력 크기, 상수 비용, 메모리 사용도 함께 봐야 합니다.
