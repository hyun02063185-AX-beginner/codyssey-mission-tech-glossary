# GitHub

## 한 줄 설명

GitHub는 Git 저장소를 온라인에 보관하고 코드 검토·이슈·Pull Request 같은 협업 기능을 제공하는 서비스입니다.

## 쉽게 설명하면

내 컴퓨터의 Git 이력을 동료와 공유하고, 변경 내용을 화면에서 검토하고 토론하는 장소입니다.

## 정확한 설명

GitHub는 원격 저장소 호스팅 외에도 Pull Request, Issue, 리뷰, 권한 관리, Pages 같은 기능을 제공합니다. Git 명령은 GitHub 없이도 로컬에서 쓸 수 있지만, GitHub에 push하면 다른 사람이 같은 원격 이력을 받아 협업할 수 있습니다.

## 이 미션에서는 왜 필요한가

본과정 M04에서 Pull Request와 코드 리뷰를 하고, M01에서는 GitHub API로 공개 프로필 데이터를 읽습니다.

## 관련 용어

- git
- pull-request
- github-api
- github-pages

## 흔한 오해

GitHub에 올렸다고 자동으로 배포되는 것은 아닙니다. Pages나 별도의 배포 설정이 필요한 경우가 많습니다.
