# temperature

## 한 줄 설명

생성 모델의 다음 토큰 선택 무작위성을 조절하는 파라미터.

## 쉽게 설명하면

낮추면 보수적으로, 높이면 더 다양한 후보를 고르는 다이얼이다.

## 정확한 설명

logit 분포를 재조정해 샘플링 다양성에 영향을 준다. 정확한 효과와 허용 범위는 모델 제공자마다 다르다.

## 판단할 점

사실 추출은 낮게, 아이디어 초안은 상대적으로 높게 설정해 비교한다.

## 주의할 점

temperature 0도 시스템 전체가 결정적이라는 보장은 아니다.

## 이 미션에서는 왜 필요한가

이 회차에서 같은 입력에 매번 다른 커밋 메시지가 나오는 정도를 조절합니다. 커밋 메시지처럼 형식이 정해진 출력에는 낮게 두는 편이 안정적이고, 값을 0으로 낮춰도 완전히 같은 결과가 보장되지는 않습니다.

## 코드 예

```text
이번 도구에서의 선택

  커밋 메시지   낮게 (0~0.3)   형식이 정해져 있고 흔들리면 곤란하다
  PR 설명 초안  중간 (0.5 근처) 문장을 다양하게 써 보는 편이 낫다

0 으로 두어도 완전히 같은 결과가 보장되지는 않는다.
같은 결과가 필요하면 결과를 저장해 두는 쪽이 확실하다.
```
