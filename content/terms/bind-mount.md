# 바인드 마운트

## 한 줄 설명

바인드 마운트는 호스트의 폴더나 파일을 컨테이너 안의 경로에 그대로 연결하는 방식입니다.

## 쉽게 설명하면

내 PC의 `./app` 폴더를 컨테이너의 `/app`에 연결하면, PC에서 파일을 고친 결과를 컨테이너에서도 바로 볼 수 있습니다.

## 정확한 설명

바인드 마운트는 Docker가 관리하는 별도 저장소가 아니라 호스트의 실제 경로를 마운트합니다. 따라서 호스트의 권한·경로·파일 존재 여부에 영향을 받습니다. 개발 중 소스 코드를 공유하기에는 편리하지만, 배포 환경에서 호스트 경로를 고정하는 방식은 이식성이 떨어질 수 있습니다.

## 코드 예

```sh
docker run -v "${PWD}:/app" my-image
```

## 이 미션에서는 왜 필요한가

예비 M01에서 호스트 파일을 바꾼 뒤 컨테이너 안에서도 변경이 보이는지 확인합니다.

## 관련 용어

- docker-container
- volume
- filesystem

## 흔한 오해

바인드 마운트와 Docker 볼륨은 같은 저장 방식이 아닙니다. 볼륨은 Docker가 관리하고, 바인드 마운트는 호스트 경로를 직접 씁니다.
