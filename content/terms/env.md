# .env

## 한 줄 설명

실행 환경별 설정값을 process에 전달하는 environment variable 파일 또는 값.

## 쉽게 설명하면

설정값과 비밀값을 적어 두고 프로그램이 읽어 가게 하는 파일입니다. 저장소에는 올리지 않습니다.

## 정확한 설명

키와 값의 쌍을 적어 두면 실행 시 환경 변수로 읽힌다. 환경마다 다른 값을 같은 코드로 쓰기 위한 수단이며, 파일 자체는 암호화되지 않은 평문이므로 저장소에 올리지 않고 권한도 본인만 읽도록 좁혀야 한다.

## 이 미션에서는 왜 필요한가

이 회차에서 비밀값을 코드 밖에 두는 자리입니다. 대신 이 파일은 공유되지 않으므로, 어떤 항목이 필요한지 알려 주는 예시 파일을 값 없이 따로 올려 두어야 다른 사람이 실행할 수 있습니다.

## 코드 예

```bash
# .env  (올리지 않는다)
API_KEY=sk-abc123...
DATABASE_URL=postgresql://...

# .env.example  (올린다 — 값은 비운다)
API_KEY=
DATABASE_URL=

# .gitignore
.env
!.env.example

chmod 600 .env        # 본인만 읽게

# 실행할 때 읽어 들인다
# from dotenv import load_dotenv; load_dotenv()
```

## 주의할 점 / 경계 조건

평문 파일입니다. 저장소에 안 올렸어도 화면 공유나 캡처로 새어 나갈 수 있습니다.

## 관련 용어

- `authentication`

## 흔한 오해

이 파일에 넣으면 안전하다고 생각하기 쉽지만, 코드에서 빼냈을 뿐 내용은 그대로 보입니다. 안전해지는 것은 저장소에 올리지 않았을 때뿐입니다.

## 동료평가 질문

이 파일을 공유하지 않으면서 다른 사람이 프로젝트를 실행하게 하려면 무엇이 필요한지 설명할 수 있나요?
