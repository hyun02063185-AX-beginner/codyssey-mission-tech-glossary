# JSONL

## 한 줄 설명

한 줄에 JSON object 하나씩 기록하는 streaming-friendly 형식.

## 쉽게 설명하면

한 줄에 JSON 하나씩 적는 형식입니다. 줄 단위로 읽고 쓸 수 있어 기록을 덧붙이기 좋습니다.

## 정확한 설명

각 줄이 독립된 JSON 값이며 파일 전체는 유효한 JSON이 아니다. 줄 단위로 처리할 수 있어 파일이 커져도 메모리에 전부 올리지 않아도 되고, 뒤에 한 줄을 덧붙이는 것만으로 기록을 추가할 수 있다. 중간 줄이 깨져도 나머지는 읽을 수 있다.

## 이 미션에서는 왜 필요한가

본과정 M03에서 기록을 파일로 남길 때 고를 수 있는 형식 가운데 하나입니다. 한 줄에 한 건씩 적으므로 뒤에 덧붙이기 쉽고, 파일을 끝까지 읽지 않아도 한 줄씩 처리할 수 있습니다.

## 코드 예

```python
with open("ledger.jsonl", "a", encoding="utf-8") as f:
    f.write(json.dumps(entry, ensure_ascii=False) + "
")   # 덧붙이기

with open("ledger.jsonl", encoding="utf-8") as f:
    for line in f:                                          # 한 줄씩
        entry = json.loads(line)
```

## 주의할 점 / 경계 조건

값 안에 줄바꿈이 들어가면 형식이 깨집니다. 저장할 때 줄바꿈을 문자열로 바꿔 주는 설정을 확인해야 합니다.

## 관련 용어

- `json`
- `streaming`

## 흔한 오해

한 줄에 한 건이라 파일 전체가 JSON 이라고 생각하기 쉽지만, 파일 자체는 유효한 JSON 이 아닙니다. 줄 단위로 읽어 각 줄을 따로 해석해야 합니다.
