# Issue

## 한 줄 설명

작업·bug·논의를 추적하는 repository 기록.

## 쉽게 설명하면

할 일이나 문제를 적어 두고 추적하는 기록입니다. 번호가 붙어 나중에 가리킬 수 있습니다.

## 정확한 설명

작업·버그·논의를 하나의 단위로 기록하고 담당자·라벨·마일스톤으로 분류한다. 번호로 참조되므로 커밋 메시지나 검토 요청에서 가리킬 수 있고, 그 연결이 "왜 이 작업을 했는가"의 출발점을 남긴다.

## 이 미션에서는 왜 필요한가

이 회차의 작업 추적 단위입니다. 누가 무엇을 하고 있는지가 여기 드러나므로 같은 일을 두 명이 하는 것을 막을 수 있고, 나중에 코드를 볼 때 그 변경의 출발점을 찾는 통로가 됩니다.

## 코드 예

```text
적을 것

  제목       무엇을 하는가 (동사로)
  배경       왜 필요한가
  완료 조건  무엇이 되면 끝인가
  담당자     누가 하는가
  라벨       bug / feature / docs

예
  제목: 로그인 실패 메시지를 통일한다
  배경: 지금은 "없는 아이디" 와 "비밀번호 틀림" 을 구분해 알려 준다.
        가입 여부가 노출된다.
  완료: 두 경우 모두 같은 메시지가 나온다. 테스트가 있다.
```

## 주의할 점 / 경계 조건

제목만 적고 내용을 비워 두면 며칠 뒤 본인도 무슨 뜻인지 모르게 됩니다. 무엇이 끝나면 완료인지를 함께 적어야 합니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

할 일 목록과 같다고 생각하기 쉽지만, 논의의 자리이기도 합니다. 결정한 이유가 여기 남으면 나중에 같은 논의를 반복하지 않습니다.
