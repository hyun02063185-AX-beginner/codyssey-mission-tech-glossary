# Template Engine

## 한 줄 설명

template에 data를 넣어 HTML 같은 text output을 만드는 도구.

## 쉽게 설명하면

`Template Engine`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

Jinja2 같은 engine은 variable·loop·escape를 제공해 presentation과 business logic 경계를 돕는다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
Template Engine
```

## 관련 용어

- `templateresponse`
- `server-side-rendering`
