# Vue

## 한 줄 설명

선언형 component와 reactive state로 UI를 만드는 JavaScript framework.

## 쉽게 설명하면

데이터가 바뀌면 화면이 따라 바뀌도록 만들어 주는 프레임워크입니다. 화면을 직접 고치는 대신 데이터를 고치면 되는 방식이며, React와 목적은 같고 문법이 다릅니다.

## 정확한 설명

React와 API·생태계는 다르지만 UI state 문제를 다루는 framework다.

## 이 미션에서는 왜 필요한가

이 회차에서 쓰지 않도록 정한 프레임워크 중 하나입니다. 지금은 데이터가 바뀔 때 화면을 직접 고치는 일을 해 보는 단계이고, 그 일이 왜 번거로운지 겪은 다음에 프레임워크를 만나야 무엇을 대신해 주는지 알 수 있습니다.

## 코드 예

```text
이번 회차 (직접)          프레임워크 (Vue·React)

  데이터를 바꾼다            데이터를 바꾼다
  화면도 직접 고친다         화면은 알아서 따라간다
  ↑ 둘을 맞추는 것이 일      ↑ 이 일을 프레임워크가 한다

직접 해 보면 "상태와 화면이 어긋나는" 문제를 겪는다.
프레임워크는 그 문제를 푼 결과물이다.
```

## 관련 용어

- `react`
- `virtual-dom-rendering`
