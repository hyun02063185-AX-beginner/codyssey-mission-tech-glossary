# Vue

## 한 줄 설명

선언형 component와 reactive state로 UI를 만드는 JavaScript framework.

## 쉽게 설명하면

`Vue`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

React와 API·생태계는 다르지만 UI state 문제를 다루는 framework다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.
