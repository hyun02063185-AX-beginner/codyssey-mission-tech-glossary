# 햄버거 메뉴

## 한 줄 설명

작은 화면에서 navigation 항목을 접었다 펼치는 메뉴 패턴.

## 쉽게 설명하면

`햄버거 메뉴`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

button의 열린 상태, aria-expanded, focus 이동을 함께 구현해야 한다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
햄버거 메뉴
```

## 관련 용어

- `interaction`
- `accessibility-a11y`
