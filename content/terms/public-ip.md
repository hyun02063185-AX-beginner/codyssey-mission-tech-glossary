# Public IP

## 한 줄 설명

공인 IP는 공용 인터넷의 라우팅에 쓰도록 배정된 IP 주소로, 인터넷의 다른 기기가 패킷의 목적지로 쓸 수 있는 주소입니다.

## 쉽게 설명하면

인터넷에서 찾아갈 수 있는 주소입니다. 사설 IP가 건물 안 내선 번호라면 공인 IP는 밖에서 걸 수 있는 대표 번호에 가깝습니다. 다만 번호가 있다고 누군가 전화를 받는 것은 아니듯, 공인 IP가 있어도 경로·허용 규칙·요청을 받는 프로그램이 함께 맞아야 접속됩니다.

## 정확한 설명

공용 인터넷의 라우팅에 쓰이도록 배정된 주소이며, 서로 겹치지 않게 관리된다. 주소가 공인이라는 것은 인터넷에서 목적지로 쓸 수 있다는 뜻이지, 실제로 닿는다는 보장은 아니다. 도달 여부는 경로와 방화벽·Security Group 같은 허용 규칙에 달려 있다. AWS EC2에 기본으로 붙는(자동 할당) 공인 IPv4는 인스턴스를 멈췄다 켜면 바뀌므로, 주소를 기록해 둔 곳이 있으면 함께 고쳐야 한다. 고정 주소가 필요하면 Elastic IP를 쓴다. 인스턴스 안에서 확인하면 사설 주소만 보이고 공인 주소는 보이지 않는다. IPv4에서는 인터넷 게이트웨이가 이 공인 주소와 인스턴스의 사설 주소를 1:1로 바꿔 준다.

## 이 미션에서는 왜 필요한가

B3-1(M05)에서 브라우저로 EC2에 접속할 때 쓰는 주소입니다. 접속하려면 공인 IP 외에도 Route Table의 인터넷 게이트웨이 경로, Security Group의 HTTP 80 허용, Nginx의 80번 수신이 함께 필요합니다. 인스턴스를 껐다 켰는데 접속이 안 된다면 이 주소가 바뀐 것일 수 있고, 고정하려면 별도의 자원(Elastic IP)을 할당해야 합니다.

## 코드 예

```bash
# 인스턴스 안에서: 네트워크 설정에는 사설 주소만 있다 (예: 10.0.1.23)
ip addr show

# 인스턴스에 할당된 공인 IPv4 — 메타데이터 서비스 IMDSv2 방식
# Amazon Linux 2023은 기본으로 토큰(IMDSv2)이 필요해 토큰 없는 요청은 401로 거절된다
TOKEN=$(curl -sS -X PUT "http://169.254.169.254/latest/api/token" \
  -H "X-aws-ec2-metadata-token-ttl-seconds: 300")
curl -sS -H "X-aws-ec2-metadata-token: $TOKEN" \
  http://169.254.169.254/latest/meta-data/public-ipv4
# 공인 IPv4가 할당되지 않았으면 값 대신 404 Not Found 응답이 온다

# 밖에서 본 출구 IP — 할당된 공인 IP와 같다는 보장은 없다
curl -s https://checkip.amazonaws.com

# 재부팅(reboot)  주소 유지
# 정지 후 시작      자동 할당 주소가 바뀐다
```

## 주의할 점 / 경계 조건

인스턴스를 멈췄다 켜면 기본 공인 주소가 바뀝니다. 재부팅은 유지되지만 정지 후 시작은 다릅니다. 또 공인 IP는 접속 조건 중 하나일 뿐입니다. 경로, 허용 규칙, 서버의 수신 중 하나라도 빠지면 접속되지 않습니다.

`checkip.amazonaws.com`이 돌려주는 값은 요청이 인터넷으로 나갈 때 보인 출구 IP입니다. B3-1처럼 인터넷 게이트웨이로 바로 나가면 보통 인스턴스의 공인 IP와 같지만, NAT Gateway나 프록시를 거치면 그 장치의 주소가 보이고, 내 PC에서 실행하면 내 PC의 출구 IP가 보입니다. 인스턴스에 할당된 주소를 확인할 때는 메타데이터나 EC2 콘솔을 봅니다.

## 흔한 오해

서버 안에서 주소를 확인하면 공인 주소가 보일 것 같지만, 네트워크 설정에는 사설 주소만 있습니다. 변환은 바깥에서 일어납니다. 또 Public Subnet에 두기만 하면 공인 IP가 생긴다고 생각하기 쉽지만, 공인 IP 할당은 Subnet의 자동 할당 설정이나 인스턴스를 만들 때의 설정으로 따로 정해집니다.

## 비슷한 개념과의 차이

공인 IP는 인터넷 라우팅에 쓰는 주소이고, 사설 IP는 내부 네트워크에서만 쓰는 주소입니다. Public Subnet은 주소의 종류가 아니라 인터넷 게이트웨이로 가는 경로가 있는 Subnet이라는 뜻이어서, 그 안의 EC2도 사설 IP를 가집니다. 자동 할당 공인 IP는 정지 후 시작하면 바뀌고, Elastic IP는 계정에 할당해 두는 고정 주소입니다.
