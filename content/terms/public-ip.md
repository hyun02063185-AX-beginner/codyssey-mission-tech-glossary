# Public IP

## 한 줄 설명

internet에서 route 가능한 IP address.

## 쉽게 설명하면

인터넷에서 찾아갈 수 있는 주소입니다. 이것이 없으면 밖에서는 서버가 존재하지 않는 것과 같습니다.

## 정확한 설명

인터넷에서 경로가 잡히는 주소다. 기본으로 붙는 주소는 인스턴스를 멈췄다 켜면 바뀌므로, 주소를 기록해 둔 곳이 있으면 함께 고쳐야 한다. 인스턴스 안에서 확인하면 사설 주소만 보이고 공인 주소는 보이지 않는다.

## 이 미션에서는 왜 필요한가

이 회차에서 브라우저로 접속할 때 쓰는 주소입니다. 인스턴스를 껐다 켰는데 접속이 안 된다면 대부분 이 주소가 바뀐 것인데, 고정하려면 별도의 자원을 할당해야 합니다.

## 코드 예

```bash
ip addr show                # 사설 주소만 보인다 — 10.0.1.23 같은

# 공인 주소는 메타데이터에서 확인한다
curl -s http://169.254.169.254/latest/meta-data/public-ipv4

# 또는 밖에서 본 내 주소
curl -s https://checkip.amazonaws.com

# 재부팅(reboot)  주소 유지
# 정지 후 시작      주소가 바뀐다
```

## 주의할 점 / 경계 조건

인스턴스를 멈췄다 켜면 기본 공인 주소가 바뀝니다. 재부팅은 유지되지만 정지 후 시작은 다릅니다.

## 관련 용어

- `http`
- `tcp`

## 흔한 오해

서버 안에서 주소를 확인하면 공인 주소가 보일 것 같지만, 네트워크 설정에는 사설 주소만 있습니다. 변환은 바깥에서 일어납니다.

## 동료평가 질문

인스턴스를 껐다 켠 뒤 접속이 안 될 때, 무엇이 바뀌었는지 어떻게 확인하겠습니까?
