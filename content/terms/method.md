# 메서드

## 한 줄 설명

클래스나 객체에 속해 그 객체의 데이터와 함께 동작하는 함수입니다.

## 쉽게 설명하면

객체가 자기 상태를 다루기 위해 가진 행동 목록과 같습니다.

## 정확한 설명

Method는 인스턴스에 바인딩되어 첫 인자로 인스턴스(`self`)를 받거나, classmethod·staticmethod처럼 다른 바인딩 규칙을 가질 수 있습니다. 일반 함수와 호출 문맥이 다릅니다.

## 이 미션에서는 왜 필요한가

예비 M02에서 클래스가 보유한 데이터를 읽고 바꾸는 동작을 책임 있게 묶습니다.

## 코드 예

```python
class Counter:
    def increment(self):
        self.value += 1
```

## 주의할 점 / 경계 조건

Method가 객체 상태를 바꾼다면 호출 순서와 불변 조건을 고려해야 하며, 모든 helper를 억지로 method로 만들 필요는 없습니다.

## 관련 용어

- `class`
- `attribute`
- `function`

## 흔한 오해

Method는 단순히 클래스 파일 안에 적힌 함수가 아니라 객체 또는 클래스와 바인딩된 호출 규칙을 가집니다.
