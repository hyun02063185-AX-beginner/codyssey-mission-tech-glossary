# 개인 액세스 토큰

## 한 줄 설명

사용자가 만든 API·Git 접근용 personal access token.

## 쉽게 설명하면

`개인 액세스 토큰`을(를) 누가 접근할 수 있고 어떤 정보가 노출되는지의 관점에서 확인하면 됩니다.

## 정확한 설명

사용자가 만든 API·Git 접근용 personal access token. 실제 적용에서는 신원, 권한, network 경계, 비밀값 보관 중 관련된 조건을 구분해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M01에서 증거를 캡처할 때 가려야 하는 대상이 바로 이 토큰입니다. 비밀번호 대신 쓰는 값이라 화면에 그대로 찍히면 같은 권한이 넘어가는 것과 같습니다.

## 코드 예

```text
캡처 전에 확인
  터미널 스크롤 위쪽에 ghp_ 로 시작하는 문자열이 남아 있지 않은지
  git remote -v 출력에 토큰이 박혀 있지 않은지
  노출됐다면 GitHub 설정에서 즉시 폐기(revoke)
```

## 관련 용어
