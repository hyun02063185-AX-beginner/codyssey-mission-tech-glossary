# Bash

## 한 줄 설명

명령을 해석하고 program을 실행하는 Unix shell.

## 쉽게 설명하면

명령을 받아 해석하고 실행해 주는 프로그램입니다. 명령을 파일에 적어 두면 그 파일이 그대로 프로그램이 됩니다.

## 정확한 설명

입력을 단어로 나누고 변수와 따옴표를 처리한 뒤 명령을 실행한다. 따옴표를 붙이지 않은 변수는 공백에서 다시 쪼개지고, 파이프로 이은 명령의 종료 상태는 기본적으로 마지막 것만 보이므로 중간 실패가 묻힌다.

## 이 미션에서는 왜 필요한가

이 회차의 점검 스크립트를 이 언어로 씁니다. 짧게 쓰기 쉬운 대신 조용히 실패하기도 쉬운 언어라, 실패하면 멈추도록 하는 설정을 맨 위에 두는 것이 실질적인 안전장치입니다.

## 코드 예

```bash
#!/usr/bin/env bash
set -euo pipefail
#  e  명령이 실패하면 멈춘다
#  u  정의하지 않은 변수를 쓰면 멈춘다
#  o pipefail  파이프 중간이 실패해도 알아챈다

LOG_DIR="/var/log/my app"       # 공백이 들어 있다
ls "$LOG_DIR"                   # 따옴표가 없으면 두 인자로 쪼개진다

if ! command -v jq >/dev/null; then
    echo "jq 가 필요합니다" >&2
    exit 1
fi
```

## 주의할 점 / 경계 조건

변수를 따옴표 없이 쓰면 공백이 든 값에서 깨집니다. 파일 경로를 다룰 때 특히 자주 문제가 됩니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

명령이 실패해도 스크립트가 멈출 것이라 생각하기 쉽지만, 기본 동작은 다음 줄로 넘어가는 것입니다. 실패한 채로 끝까지 실행됩니다.

## 동료평가 질문
