# 리스트 / 딕셔너리

## 한 줄 설명

순서 있는 리스트와 키로 찾는 딕셔너리의 선택 기준.

## 쉽게 설명하면

목록은 위치로, 딕셔너리는 이름표로 값을 찾는다.

## 정확한 설명

list는 순서·중복을 보존하고 index 접근이 빠르다. dict는 키-값 매핑을 평균 O(1)에 조회한다.

## 언제 쓰나

할 일 순서는 list, 사용자 ID별 프로필은 dict로 저장한다.

## 기억할 경계

순서가 필요하다는 이유만으로 모든 데이터를 list로 찾으면 탐색 비용이 커진다.

## 이 미션에서는 왜 필요한가

퀴즈 데이터를 어떻게 담을지가 이 회차의 첫 설계 결정입니다. 문제를 순서대로 내야 하니 목록이 필요하고, 답을 맞출 때는 보기 번호로 바로 찾아야 하니 딕셔너리가 편합니다. 둘 중 하나로 통일하려다 보면 어느 한쪽에서 코드가 번거로워집니다.

## 코드 예

```python
# 순서가 중요한 것 — 문제를 내는 차례
questions = [
    {'text': '파이썬의 주석 기호는?', 'answer': 'b'},
    {'text': '리스트의 첫 인덱스는?', 'answer': 'a'},
]

# 이름으로 찾는 것 — 보기 번호에서 내용으로
choices = {'a': '0', 'b': '#', 'c': '1'}

for q in questions:           # 목록은 순서대로 돈다
    print(q['text'], choices)  # 딕셔너리는 번호로 바로 찾는다
```
