# parent

## 한 줄 설명

현재 commit이 이전 history와 연결될 때 가리키는 바로 앞 commit.

## 쉽게 설명하면

어떤 커밋의 바로 앞 커밋입니다. 이 연결이 있어서 기록이 순서를 갖습니다.

## 정확한 설명

각 커밋이 저장하는 이전 커밋의 참조다. 보통 하나지만 합치기 커밋은 둘 이상을 갖는다. 화살표는 항상 과거를 향하므로 어떤 커밋에서 출발해도 최초 커밋에 도달하며, 반대 방향의 참조는 저장되지 않는다.

## 이 미션에서는 왜 필요한가

본과정 M10에서 커밋들을 이어 이력을 만드는 연결 고리입니다. 부모를 따라 거슬러 올라가면 그 시점까지의 전체 이력이 나오고, 부모가 둘이면 두 갈래가 합쳐진 지점이라는 뜻입니다.

## 코드 예

```bash
git log --graph --oneline -6

git cat-file -p HEAD | head -3
# tree ...
# parent d4e5f6a        ← 하나

git cat-file -p <머지커밋> | head -4
# parent d4e5f6a        ← 받은 쪽 (main)
# parent 9876fed        ← 합쳐진 쪽 (feature)

# HEAD~1  첫 번째 부모를 따라 1칸
# HEAD^2  두 번째 부모 (합치기 커밋에서만 의미가 있다)
```

## 주의할 점 / 경계 조건

합치기 커밋에서는 부모가 둘이라 `HEAD~1`이 어느 쪽인지 정해집니다. 되돌릴 때 기준을 지정해야 하는 이유입니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

커밋이 자식을 안다고 생각하기 쉽지만, 저장된 것은 부모뿐입니다. 자식을 찾으려면 전체를 훑어야 합니다.
