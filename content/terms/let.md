# let

## 한 줄 설명
`let`은 JavaScript에서 재할당 가능한 block-scoped binding을 선언하는 키워드입니다.

## 쉽게 설명하면
`let`으로 붙인 이름표는 `{}`로 감싼 구역 안에서만 통하고, 그 구역 안에서는 새 값을 붙일 수 있습니다.

## 정확한 설명
`let`은 block scope를 가지며 같은 scope 안에서 다시 선언할 수 없습니다. 값 자체는 바꿀 수 있으므로, 재할당이 필요한 지역 변수에 적합합니다.

## 이 미션에서는 왜 필요한가
M01의 입력 처리·상태 갱신 코드에서 값이 바뀌어야 하지만 바깥 코드와 섞이면 안 되는 경우를 표현합니다.

## 코드 예
```js
let score = 0;
score += 1;
```

## 주의할 점 / 경계 조건
`let`은 값을 immutable하게 만들지 않습니다. binding 재할당만 허용하며 객체의 내부 변경 여부는 별도로 결정됩니다.

## 관련 용어
- `scope`
- `var`
- `const`
- `variable`
- `javascript`

## 흔한 오해
`let`과 `const`의 차이는 scope가 아니라 재할당 가능 여부입니다. 둘 다 block scope입니다.
