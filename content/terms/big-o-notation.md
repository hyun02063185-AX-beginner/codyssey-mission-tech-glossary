# 빅오 표기법

## 한 줄 설명

입력 크기가 커질 때 알고리즘의 시간 또는 공간 사용량이 어떻게 증가하는지 상한의 형태로 나타내는 표기입니다.

## 쉽게 설명하면

손님 수가 늘 때 계산대 일이 얼마나 빠르게 늘어나는지 보는 성장률 표지판입니다.

## 정확한 설명

Big-O는 상수 계수와 작은 입력의 세부 비용보다 n이 커질 때 지배적인 증가 항을 비교합니다. 실제 실행 시간은 하드웨어·입력 분포·구현 상수에도 영향을 받습니다.

## 이 미션에서는 왜 필요한가

예비 M03에서 O(N²) 같은 표기를 읽고 데이터 규모에 맞는 구현을 고릅니다.

## 코드 예

```text
for a in values:
  for b in values: ...  # O(N²)
```

## 주의할 점 / 경계 조건

Big-O가 더 낮아도 작은 입력에서는 단순 구현이 더 빠를 수 있으므로 측정과 요구 규모를 함께 봐야 합니다.

## 관련 용어

- `time-complexity`
- `benchmark`
- `memoization`

## 흔한 오해

Big-O는 프로그램의 실제 초 단위를 보장하거나 코드 품질 전체를 점수화하는 표기가 아닙니다.

## 동료평가 질문
