# GitHub API

## 한 줄 설명

GitHub API는 GitHub의 사용자·저장소 같은 데이터를 HTTP 요청으로 가져오게 하는 인터페이스입니다.

## 쉽게 설명하면

포트폴리오 페이지가 GitHub에 "이 사용자의 저장소 정보를 주세요"라고 요청하는 공식 창구입니다.

## 정확한 설명

API는 정해진 URL과 응답 형식으로 다른 프로그램이 데이터를 주고받게 합니다. GitHub API의 응답은 HTTP 상태와 JSON 본문을 가지므로, 성공 데이터뿐 아니라 권한·요청 제한·없는 결과도 처리해야 합니다.

GitHub API 자체는 제공하는 서비스이고, 브라우저에서 요청을 보내는 도구는 `fetch`입니다. M01에서는 비인증 요청 한도와 403 가능성을 UI 상태로 사용자에게 안내합니다.

## 이 미션에서는 왜 필요한가

포트폴리오에 GitHub 데이터와 로딩·실패·빈 결과를 보여 줍니다.

## 관련 용어

- fetch-api
- async-await
- ui-state
- rate-limiting

## 흔한 오해

GitHub API와 `fetch`는 같은 것이 아닙니다. 하나는 데이터 서비스, 다른 하나는 요청 API입니다.
