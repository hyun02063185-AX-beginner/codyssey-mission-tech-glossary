# 403

## 한 줄 설명

HTTP 403은 서버가 요청을 이해했지만 현재 요청을 허용하지 않을 때 보내는 상태 코드입니다.

## 쉽게 설명하면

서버가 요청은 알아들었지만 지금은 이 요청을 처리해 줄 수 없다고 알려 주는 응답입니다.

## 정확한 설명

HTTP 상태 코드는 요청 처리 결과를 표현하는 표준 숫자입니다. 403 Forbidden은 접근이 허용되지 않는 경우에 쓰이며, API 정책과 인증 상태에 따라 세부 원인이 달라질 수 있습니다.

GitHub API의 비인증 요청 한도 초과도 403으로 나타날 수 있으므로 M01은 상태 코드만 보고 원인을 단정하지 않습니다. response.status를 확인하고 사용자가 이해할 수 있는 오류 상태로 바꿉니다.

## 이 미션에서는 왜 필요한가

GitHub API 제한 또는 접근 실패를 일반 빈 결과와 구분해 보여 줍니다.

## 관련 용어

- rate-limiting
- fetch-api
- ui-state

## 흔한 오해

403은 항상 로그인 권한 문제라는 뜻이 아닙니다.
