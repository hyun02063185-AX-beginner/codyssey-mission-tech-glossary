# 가중치

## 한 줄 설명

학습 과정에서 조정되어 모델의 계산 결과에 영향을 주는 파라미터.

## 쉽게 설명하면

모델이 데이터에서 배운 숫자 조절값이다.

## 정확한 설명

층의 weight는 입력과 곱해져 특징과 출력을 만든다. 학습은 손실을 줄이는 방향으로 이 값을 갱신한다.

## 언제 쓰나

훈련 후 저장된 weight 파일을 불러와 추론한다.

## 기억할 경계

weight 하나를 사람 언어의 규칙 하나로 대응시키기는 어렵다.

## 이 미션에서는 왜 필요한가

필터 안에 적힌 숫자들이 이것입니다. 시뮬레이터에서는 사람이 값을 정해 넣지만 실제 모델에서는 학습으로 정해지며, 같은 코드라도 이 값이 달라지면 무엇을 찾아내는지가 완전히 달라집니다.

## 코드 예

```python
# 같은 합성곱 코드라도 값이 다르면 찾아내는 것이 달라진다
EDGE   = [[0, 1, 0], [1, -4, 1], [0, 1, 0]]    # 가장자리
BLUR   = [[1, 1, 1], [1,  1, 1], [1, 1, 1]]    # 뭉개기
SHARP  = [[0, -1, 0], [-1, 5, -1], [0, -1, 0]] # 또렷하게

# 학습이란 이 숫자들을 데이터에 맞게 조금씩 고치는 일이다
```
