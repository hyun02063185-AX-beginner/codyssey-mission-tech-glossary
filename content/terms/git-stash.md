# git stash

## 한 줄 설명

working tree 변경을 임시 stack에 보관하는 명령.

## 쉽게 설명하면

작업하던 것을 잠깐 따로 치워 두는 명령입니다. 치우면 작업 디렉터리가 깨끗해집니다.

## 정확한 설명

작업 중인 변경을 별도 저장소에 쌓아 두고 작업 디렉터리를 마지막 커밋 상태로 되돌린다. 여러 개를 쌓을 수 있고 나중에 꺼내 되돌릴 수 있지만, 기본적으로는 추적되지 않는 파일을 포함하지 않으므로 새로 만든 파일은 그대로 남는다.

## 이 미션에서는 왜 필요한가

이 회차의 트러블슈팅 항목 중 하나입니다. 작업 도중에 급한 수정을 해야 할 때, 어중간한 상태로 커밋하지 않고 잠깐 치워 두는 방법입니다.

## 코드 예

```bash
git stash push -m "로그인 폼 작업 중"     # 메시지를 붙인다
git stash list
# stash@{0}: On feature/login: 로그인 폼 작업 중

git stash pop                # 꺼내면서 목록에서 지운다
git stash apply stash@{1}    # 꺼내되 목록에 남긴다

# 추적 안 하는 새 파일도 함께 치우려면
git stash push -u -m "새 파일 포함"

# 내용 확인
git stash show -p stash@{0}
```

## 주의할 점 / 경계 조건

새로 만들어 아직 추적하지 않는 파일은 함께 치워지지 않습니다. 별도 옵션이 필요합니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

쌓아 두면 안전하다고 생각하기 쉽지만, 브랜치에 속하지 않아 잊기 쉽습니다. 메시지를 붙여 두지 않으면 며칠 뒤 무엇인지 알 수 없습니다.
