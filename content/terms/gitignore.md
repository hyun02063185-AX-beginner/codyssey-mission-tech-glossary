# .gitignore

## 한 줄 설명

Git이 untracked file을 기본적으로 무시할 pattern을 적는 설정 file.

## 쉽게 설명하면

기록에 넣지 않을 파일의 규칙을 적어 두는 파일입니다. 여기 적힌 것은 변경해도 알려 주지 않습니다.

## 정확한 설명

무시할 경로 패턴을 적는다. 아직 추적하지 않는 파일에만 적용되므로, 이미 한 번 커밋한 파일은 여기 적어도 계속 추적된다. 그때는 추적 목록에서 먼저 빼야 한다.

## 이 미션에서는 왜 필요한가

이 회차에서 비밀 값이나 빌드 결과물이 저장소에 올라가지 않게 막습니다. 다만 이미 올린 파일에는 듣지 않으므로, 실수로 올린 비밀 값은 이 파일에 적는 것만으로 사라지지 않습니다.

## 코드 예

```bash
# .gitignore
# .env
# __pycache__/
# *.log
# !important.log        ← ! 는 예외 (무시하지 않는다)

# 이미 커밋한 파일은 계속 추적된다
git rm --cached .env      # 추적만 멈춘다 (파일은 남는다)
git commit -m "chore: .env 추적 해제"

# 과거 커밋에는 아직 남아 있다.
# 올린 비밀 값은 무효화하고 새로 발급하는 것이 실제 대응이다

git check-ignore -v config.json   # 어느 규칙에 걸리는지
```

## 주의할 점 / 경계 조건

이미 커밋한 파일에는 적용되지 않습니다. 추적을 멈추려면 별도 명령이 필요하고, 과거 커밋에서 지우는 것은 또 다른 일입니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

여기 적으면 저장소에서 사라진다고 생각하기 쉽지만, 앞으로 추가되지 않게 할 뿐입니다. 이미 올라간 것은 그대로 남아 있습니다.
