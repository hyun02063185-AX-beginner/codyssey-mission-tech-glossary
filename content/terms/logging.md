# Logging

## 한 줄 설명

프로그램이 실행 중에 일어난 사건과 상태를 나중에 관찰할 수 있도록 구조화해 남기는 작업입니다.

## 쉽게 설명하면

운영 중 무슨 일이 있었는지 남기는 항해 일지입니다.

## 정확한 설명

Logging은 시간, 수준, 메시지, 요청 식별자 같은 맥락을 기록해 디버깅·감사·운영 관찰을 돕습니다. 비밀값이나 개인정보는 기록하지 않도록 설계해야 합니다.

## 이 미션에서는 왜 필요한가

M07에서 CPU·메모리 상태와 종료 사유를 monitor.log에 남겨 재현 가능한 점검 근거를 만듭니다.

## 코드 예

```python
logger.warning('cpu threshold exceeded', extra={'cpu': cpu})
```

## 주의할 점 / 경계 조건

로그를 많이 남기는 것만으로 관찰성이 좋아지지 않습니다. 수준, 형식, 보존 기간과 민감정보 정책이 필요합니다.

## 관련 용어

- `log-rotation`
- `root-cause-analysis`
- `health-check`

## 흔한 오해

print를 여러 곳에 넣는 것은 검색·보존·수준 제어가 가능한 운영 logging과 다릅니다.
