# CPU Architecture

## 한 줄 설명

프로그램의 명령 형식과 바이너리 호환성을 결정하는 CPU 계열과 실행 환경의 규약입니다.

## 쉽게 설명하면

같은 설명서라도 서로 다른 규격의 부품에는 바로 맞지 않는 것과 같습니다.

## 정확한 설명

CPU architecture는 x86_64, ARM64처럼 instruction set과 ABI 특성을 포함합니다. 운영체제가 같아도 다른 architecture용으로 빌드된 바이너리는 직접 실행되지 않을 수 있습니다.

## 이 미션에서는 왜 필요한가

M07에서 실행 파일·컨테이너 이미지가 현재 서버의 x86/arm64 환경과 맞는지 확인합니다.

## 코드 예

```bash
uname -m  # 예: arm64 또는 x86_64
```

## 주의할 점 / 경계 조건

32/64비트, 운영체제, CPU architecture는 관련 있지만 같은 분류가 아니므로 오류 메시지의 실제 호환 축을 확인해야 합니다.

## 관련 용어

- `docker-image`
- `docker-container`
- `linux`

## 흔한 오해

ARM64가 항상 x86_64보다 빠르거나 호환된다는 일반화는 맞지 않습니다.
