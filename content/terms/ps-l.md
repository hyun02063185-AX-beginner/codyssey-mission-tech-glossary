# ps -L

## 한 줄 설명

process의 scheduling·priority 등 긴 형식 정보를 보는 ps option.

## 쉽게 설명하면

한 프로그램 안에서 돌고 있는 작업 갈래들을 따로 보여 주는 옵션입니다. 겉보기에 하나인 프로세스가 안에서는 여럿일 수 있습니다.

## 정확한 설명

프로세스 단위가 아니라 스레드 단위로 목록을 낸다. 한 프로세스의 CPU 사용률이 100%를 넘을 때 어느 스레드가 쓰고 있는지 나뉘어 보이므로, 프로세스 전체가 바쁜 것인지 한 갈래만 돌고 있는 것인지 구분할 수 있다.

## 이 미션에서는 왜 필요한가

이 회차의 스레드 확인이 이것입니다. 프로세스 단위로만 보면 "이 프로그램이 CPU를 많이 쓴다"까지밖에 말할 수 없는데, 스레드까지 나눠 보면 특정 작업 하나가 멈추지 않고 도는 상황을 찾아낼 수 있습니다.

## 코드 예

```bash
ps -L -p "$PID" -o pid,tid,pcpu,stat,comm
#          │    │    │    └ 상태 (R 실행중, S 대기, D 중단불가 대기)
#          │    │    └ 이 스레드의 CPU 비율
#          │    └ 스레드 번호 — PID 와 다른 값이다
#          └ 프로세스 번호 (모든 줄이 같다)

# 프로세스 전체가 380% 여도
#   스레드 4개가 95% 씩이면  → 정상적인 병렬 처리
#   스레드 1개가 100% 고정이면 → 무한 반복을 의심한다
```

## 주의할 점 / 경계 조건

스레드 번호와 프로세스 번호는 다른 값입니다. 스레드 번호로 프로세스를 다루는 명령을 쓰면 엉뚱한 대상이 됩니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

프로세스가 하나면 CPU도 하나만 쓴다고 생각하기 쉽지만, 스레드가 여럿이면 여러 코어를 동시에 씁니다. 그래서 100%를 넘는 값이 나옵니다.

## 동료평가 질문

한 프로세스의 CPU 사용률이 300%로 나올 때, 스레드 단위로 보면 무엇을 더 알 수 있는지 설명할 수 있나요?
