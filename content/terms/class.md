# class

## 한 줄 설명

class는 비슷한 데이터와 기능을 함께 묶어 새로운 객체를 만들기 위한 설계도입니다.

## 쉽게 설명하면

퀴즈 제목과 문제 목록, 정답 확인 기능을 한 덩어리로 다루고 싶다면 `Quiz`라는 class를 만들 수 있습니다.

## 코드 예

```python
class Quiz:
    def __init__(self, title):
        self.title = title
```

## 정확한 설명

class 안에는 객체마다 가질 값(속성)과 객체가 할 일(메서드)을 정의합니다. class를 실행해 얻는 실제 값이 인스턴스입니다. 같은 class에서 여러 인스턴스를 만들 수 있으며, 각 인스턴스는 서로 다른 상태를 가질 수 있습니다.

## 이 미션에서는 왜 필요한가

예비 M02와 본과정 M03에서 퀴즈나 가계부 데이터를 역할별 객체로 나누어 관리합니다.

## 관련 용어

- object-instance
- method
- attribute
- python

## 흔한 오해

class 자체는 실제 사용자 한 명이나 퀴즈 한 개가 아닙니다. 그런 실제 대상은 class로부터 만든 인스턴스입니다.
