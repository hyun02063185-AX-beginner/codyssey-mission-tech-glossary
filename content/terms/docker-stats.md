# docker stats

## 한 줄 설명

실행 중인 컨테이너의 CPU·메모리·네트워크 사용량을 표시하는 Docker 명령.

## 쉽게 설명하면

각 컨테이너가 자원을 얼마나 쓰는지 실시간으로 보는 계기판이다.

## 정확한 설명

`docker stats`는 cgroup 기반 사용량을 주기적으로 표시한다. 여러 컨테이너를 비교해 과도한 소비자를 찾을 수 있다.

## 언제 쓰나

메모리 급증 컨테이너를 식별한다.

## 기억할 경계

순간 수치만으로 memory leak을 확정하면 안 된다.

## 이 미션에서는 왜 필요한가

예비 M01의 4.5 항목에서 자원 사용량을 확인하는 명령입니다. 컨테이너별 CPU와 메모리를 실시간으로 보여 주며, 자원 제한을 걸어 두었다면 한도 대비 얼마나 쓰는지도 함께 나옵니다.

## 코드 예

```bash
docker stats --no-stream
# CONTAINER   CPU %   MEM USAGE / LIMIT   MEM %
# 한도를 걸지 않았으면 LIMIT 에 호스트 전체 메모리가 찍힌다
```

## 관련 용어

- `used-memory`
- `system-monitoring`
