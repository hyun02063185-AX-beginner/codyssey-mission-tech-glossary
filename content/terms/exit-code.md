# exit code

## 한 줄 설명

program 종료 결과를 caller에게 알리는 정수 상태값.

## 쉽게 설명하면

프로그램이 끝나면서 남기는 숫자입니다. 0이면 성공, 나머지는 실패를 뜻합니다.

## 정확한 설명

프로세스가 종료할 때 부모에게 남기는 0~255의 값이다. 0은 성공이고 나머지는 실패의 종류를 프로그램이 정한다. 신호로 강제 종료된 경우에는 128에 신호 번호를 더한 값이 되므로, 값 자체가 어떻게 끝났는지를 알려 준다.

## 이 미션에서는 왜 필요한가

본과정 M03은 오류가 나면 0이 아닌 종료 코드로 끝내라고 요구하고, 예비 M01에서는 컨테이너가 왜 죽었는지 판단하는 단서가 됩니다(메모리 부족이면 137 같은 값). 사람이 읽는 메시지와 달리 다른 프로그램이 바로 판단할 수 있는 신호입니다.

## 코드 예

```bash
python main.py; echo $?

# 128 + 신호 번호
#   130 = 128 + 2   Ctrl+C
#   137 = 128 + 9   강제 종료 (메모리 부족이 흔한 원인)
#   143 = 128 + 15  정상 종료 요청을 받고 끝남

docker ps -a --format "{{.Names}} {{.Status}}"
# web  Exited (137) 2 minutes ago    ← 메모리 한도를 의심한다
docker inspect --format="{{.State.OOMKilled}}" web
```

## 주의할 점 / 경계 조건

128보다 큰 값은 보통 신호로 종료됐다는 뜻입니다. 137은 메모리 부족으로 강제 종료된 경우입니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

실패하면 오류 메시지가 남는다고 생각하기 쉽지만, 강제 종료된 프로세스는 아무것도 남기지 못합니다. 종료 코드가 유일한 단서일 때가 있습니다.
