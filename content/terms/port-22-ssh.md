# SSH 22

## 한 줄 설명

SSH service가 관례적으로 사용하는 TCP port 22.

## 쉽게 설명하면

원격 접속에 관례적으로 쓰는 번호입니다. 번호를 바꿔도 동작하지만 다들 이 번호를 먼저 시도합니다.

## 정확한 설명

원격 접속 서비스의 기본 포트다. 인터넷에 열어 두면 자동화된 접속 시도가 끊임없이 들어오므로, 출처를 특정 주소로 제한하거나 비밀번호 인증을 끄는 것이 실질적인 방어가 된다. 포트 번호만 바꾸는 것은 시도 횟수를 줄일 뿐이다.

## 이 미션에서는 왜 필요한가

이 회차에서 서버에 접속하려면 열어야 하는 문입니다. 전체에 열면 접속은 되지만 전 세계의 자동 시도 대상이 되므로, 자기 IP로 제한하는 것이 방화벽 실습의 첫 판단이 됩니다.

## 코드 예

```text
보안 그룹 규칙

  유형  포트  출처              판단
  SSH   22    0.0.0.0/0         전 세계가 시도한다
  SSH   22    203.0.113.7/32    내 주소에서만

실제로 얼마나 시도되는지 보려면
  sudo grep "Failed password" /var/log/auth.log | wc -l

포트를 2222 로 바꾸면 이 숫자는 줄어든다.
하지만 포트 스캔에는 그대로 걸린다. 근본 방어는 키 인증이다.
```

## 주의할 점 / 경계 조건

집이나 카페의 IP는 바뀔 수 있습니다. 제한해 두면 주소가 바뀌었을 때 스스로 접속하지 못하게 됩니다.

## 관련 용어

- `http`
- `tcp`

## 흔한 오해

포트를 바꾸면 안전해진다고 생각하기 쉽지만, 훑어보면 찾아집니다. 줄어드는 것은 무작위 시도의 양이고 표적 공격에는 효과가 없습니다.
