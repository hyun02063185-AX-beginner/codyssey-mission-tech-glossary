# 인증

## 한 줄 설명

인증은 사용자가 주장한 신원을 확인하는 과정입니다.

## 쉽게 설명하면

로그인 화면에 아이디와 비밀번호를 넣는 행위 자체가 아니라, 서버가 그 정보나 토큰을 확인해 “이 사용자가 누구인가”를 판단하는 일입니다.

## 정확한 설명

인증에는 비밀번호 검증, 세션, JWT, OAuth처럼 여러 방식이 있습니다. 인증이 성공하면 서버는 이후 요청에서 사용자를 식별할 근거를 만들지만, 그 사용자가 무엇을 할 수 있는지는 인가에서 따로 판단합니다.

## 이 미션에서는 왜 필요한가

- main M02: Supabase/Firebase Auth 보너스 기능의 흐름을 이해합니다.
- main M13: 사용자 신원을 확인한 뒤 보호된 기능으로 연결합니다.

## 관련 용어

- `authorization`
- `login-session`
- `json-web-token`

## 흔한 오해

인증과 인가는 같은 말이 아닙니다. 인증은 “누구인가”, 인가는 “무엇을 해도 되는가”를 다룹니다.

## 동료평가 질문

로그인에 성공한 사용자라고 해서 관리자 기능까지 사용할 수 없는 이유는 무엇인가요?
