# 콘솔

## 한 줄 설명

명령을 입력하고 프로그램의 표준 출력·오류를 확인하는 텍스트 기반 인터페이스입니다.

## 쉽게 설명하면

프로그램과 짧은 문장으로 대화하는 창입니다.

## 정확한 설명

Console은 터미널 창, 브라우저 개발자 도구, REPL처럼 텍스트 입출력을 보여 주는 환경을 가리킬 수 있습니다. shell 자체나 실행 중인 프로그램과는 구분해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M02에서 메뉴형 프로그램의 입력·출력과 오류 메시지를 확인하는 관찰 창입니다.

## 코드 예

```python
print('saved')
```

## 주의할 점 / 경계 조건

브라우저 console의 JavaScript 실행 환경과 운영체제 terminal의 shell 명령 환경은 같은 명령을 항상 지원하지 않습니다.

## 관련 용어

- `terminal`
- `shell`
- `read-eval-print-loop`

## 흔한 오해

console.log가 남는다고 애플리케이션의 정식 logging 체계가 완성된 것은 아닙니다.
