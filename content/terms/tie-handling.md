# 동점 처리

## 한 줄 설명

여러 후보의 점수나 우선순위가 같을 때 결과를 일관되게 정하는 규칙입니다.

## 쉽게 설명하면

결승선을 동시에 통과한 선수에게 미리 정한 판정 규칙을 적용하는 것과 같습니다.

## 정확한 설명

Tie handling은 동점 시 입력 순서, 사전순, 보조 점수, 공동 결과 같은 deterministic policy를 적용하는 과정입니다. 규칙이 없으면 실행 순서에 따라 결과가 달라질 수 있습니다.

## 이 미션에서는 왜 필요한가

예비 M03의 UNDECIDED 판정에서 애매한 결과를 임의로 처리하지 않게 합니다.

## 코드 예

```python
# score가 같으면 이름 오름차순으로 결정
winner = min(candidates, key=lambda x: (-x.score, x.name))
```

## 주의할 점 / 경계 조건

보조 기준을 추가하면 공정성·도메인 의미가 달라질 수 있으므로 결과 형식에 명시해야 합니다.

## 관련 용어

- `sorting-algorithm`
- `stable-custom-comparator`
- `threshold`

## 흔한 오해

동점 처리는 단순 오류 처리가 아니라 결과 계약의 일부입니다.
