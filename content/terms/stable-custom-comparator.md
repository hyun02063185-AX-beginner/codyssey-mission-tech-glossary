# Stable / Custom Comparator

## 한 줄 설명

동점의 기존 순서를 지키는 안정 정렬과 사용자 정의 비교 규칙.

## 쉽게 설명하면

같은 점수의 사람 순서는 그대로 두고, 정렬 기준도 직접 정하는 방법이다.

## 정확한 설명

comparator는 두 값의 순서를 일관되게 반환해야 한다. stable sort는 비교상 같은 값의 입력 순서를 보존한다.

## 언제 쓰나

이름 오름차순, 점수 내림차순 같은 다중 기준 정렬을 작성한다.

## 기억할 경계

비교 규칙이 비대칭·비추이적이면 정렬 결과를 신뢰할 수 없다.

## 이 미션에서는 왜 필요한가

기록을 날짜순으로 정렬했는데 같은 날짜가 여럿이면, 그 안에서의 순서는 정렬 방식이 정합니다. 안정 정렬이면 원래 순서가 그대로 남고 아니면 뒤섞이므로, 정렬 기준을 날짜에서 작성자로 바꿨을 때 결과가 흔들리는지 여부가 여기서 갈립니다.

## 코드 예

```python
records = [('2026-03-01', 'kim'), ('2026-03-01', 'lee'), ('2026-02-28', 'park')]

# 파이썬 sorted 는 안정 정렬이다 — 날짜가 같으면 입력 순서가 유지된다
print(sorted(records, key=lambda r: r[0]))

# 두 기준을 쓰려면 약한 기준부터 정렬하거나 튜플로 한 번에 준다
print(sorted(records, key=lambda r: (r[0], r[1])))
```

## 관련 용어

- `sorting-algorithm`
- `lexicographical-order`
