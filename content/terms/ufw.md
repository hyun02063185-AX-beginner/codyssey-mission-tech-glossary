# UFW

## 한 줄 설명

Ubuntu에서 방화벽 규칙을 간단히 관리하는 command-line 도구.

## 쉽게 설명하면

우분투에서 방화벽 규칙을 쉬운 말로 적을 수 있게 해 주는 도구입니다. 복잡한 규칙 문법을 대신 써 줍니다.

## 정확한 설명

커널의 패킷 필터 규칙을 생성하는 앞단 도구다. 규칙은 위에서부터 평가되고 먼저 맞는 규칙이 적용되며, 기본 정책(들어오는 것은 거부, 나가는 것은 허용)을 먼저 정한 뒤 필요한 것만 여는 방식으로 쓴다.

## 이 미션에서는 왜 필요한가

이 회차에서 서버 자체에 방화벽을 거는 선택지입니다. 클라우드 쪽 방화벽이 이미 있어도 이것을 함께 쓰면 두 겹이 되는데, 둘 중 하나만 열려 있어도 통하지 않으므로 설정이 어긋나면 원인 찾기가 어려워집니다.

## 코드 예

```bash
sudo ufw allow OpenSSH        # 반드시 먼저. 순서를 바꾸면 스스로 잠긴다
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

sudo ufw status numbered      # 규칙과 활성 여부를 함께 확인
sudo ufw delete 3             # 번호로 지운다
```

## 주의할 점 / 경계 조건

활성화하기 전에 SSH 포트를 먼저 허용해야 합니다. 순서를 바꾸면 적용되는 순간 접속이 끊기고 다시 들어갈 방법이 없습니다.

## 관련 용어

- `authentication`

## 흔한 오해

규칙을 추가하면 바로 적용된다고 생각하기 쉽지만, 활성화하지 않으면 규칙만 저장됩니다. 상태를 함께 확인해야 합니다.

## 동료평가 질문

방화벽을 켜기 전에 반드시 해야 할 일과, 하지 않았을 때 무슨 일이 생기는지 설명할 수 있나요?
