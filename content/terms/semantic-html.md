# 시맨틱 태그

## 한 줄 설명

Semantic HTML은 콘텐츠의 역할을 드러내는 태그로 문서에 의미 있는 구조를 주는 방식입니다.

## 쉽게 설명하면

겉모양을 위한 `div`만 나열하는 대신, 여기는 머리말·본문·한 구역·바닥글이라고 태그 자체로 알려 주는 것입니다.

## 정확한 설명

시맨틱 요소는 문서의 landmark와 콘텐츠 구획을 표현합니다. 보조기술, 검색 도구, 다른 개발자는 요소 이름과 제목 계층을 통해 페이지 구조를 더 쉽게 해석할 수 있습니다.

시맨틱 태그가 자동으로 디자인을 만들지는 않습니다. HTML의 의미를 먼저 잡고 CSS로 표현을 더해야 하며, M01의 필수 섹션은 `main` 안에서 독립된 `section`과 적절한 heading으로 연결하는 것이 좋습니다.

## 이 미션에서는 왜 필요한가

포트폴리오의 Hero부터 Contact까지를 읽기 쉬운 문서 순서로 구성합니다.

## 코드 예

```html
<header>...</header><main><section aria-labelledby="about">...</section></main><footer>...</footer>
```

## 관련 용어

- html
- dom
- responsive-web-design

## 흔한 오해

class 이름만 `header`로 붙인 `div`가 시맨틱 태그가 되는 것은 아닙니다.
