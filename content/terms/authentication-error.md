# 인증 오류

## 한 줄 설명

인증 정보가 없거나 유효하지 않아 요청을 처리할 수 없다는 실패 상태.

## 쉽게 설명하면

`인증 오류`을(를) 누가 접근할 수 있고 어떤 정보가 노출되는지의 관점에서 확인하면 됩니다.

## 정확한 설명

인증 정보가 없거나 유효하지 않아 요청을 처리할 수 없다는 실패 상태. 실제 적용에서는 신원, 권한, network 경계, 비밀값 보관 중 관련된 조건을 구분해야 합니다.

## 이 미션에서는 왜 필요한가

본과정 M06에서 AI API 호출이 실패하는 여러 이유 가운데 하나이고, 대응이 다른 오류와 다릅니다. 재시도해도 소용이 없고 키나 권한을 고쳐야 하므로, 네트워크 오류와 구분해 처리해야 합니다.

## 코드 예

```python
if response.status_code == 401:
    raise SystemExit("API 키가 없거나 잘못되었습니다. 재시도해도 같습니다.")
if response.status_code == 403:
    raise SystemExit("키는 맞지만 이 작업에 대한 권한이 없습니다.")
```
