# Merge

## 한 줄 설명

Merge는 한 Git 브랜치의 변경 이력을 다른 브랜치에 합치는 작업입니다.

## 쉽게 설명하면

기능 브랜치에서 끝낸 작업을 검토한 뒤 `main`에 반영하는 과정입니다.

## 정확한 설명

Git은 두 브랜치가 공통으로 갈라진 지점을 찾아 변경을 합칩니다. 같은 부분을 서로 다르게 고쳤다면 자동으로 결정할 수 없어 충돌(conflict)을 표시합니다. 충돌을 해결한 뒤에는 결과가 의도한 대로 동작하는지 다시 확인해야 합니다.

## 이 미션에서는 왜 필요한가

예비 M02에서 브랜치를 합치고, 본과정 M04에서는 Pull Request 검토 후 변경을 병합합니다.

## 관련 용어

- branch
- git
- pull-request
- conflict

## 흔한 오해

merge는 파일을 무조건 덮어쓰는 명령이 아닙니다. 공통 이력을 기준으로 양쪽 변경을 조합하려는 작업입니다.
