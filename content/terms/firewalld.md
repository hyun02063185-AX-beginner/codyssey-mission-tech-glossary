# firewalld

## 한 줄 설명

Linux에서 zone과 service 기준으로 방화벽 규칙을 관리하는 도구.

## 쉽게 설명하면

연결을 구역(zone)으로 나눠 관리하는 방화벽 도구입니다. 같은 서버라도 어느 네트워크에 붙었는지에 따라 다른 규칙을 적용할 수 있습니다.

## 정확한 설명

네트워크 인터페이스나 출처를 구역에 배정하고, 구역별로 허용할 서비스와 포트를 정한다. 변경은 기본적으로 지금만 적용되며, 재부팅 뒤에도 남기려면 영구 적용을 따로 지정하고 다시 읽어야 한다.

## 이 미션에서는 왜 필요한가

이 회차의 방화벽 선택지 중 하나입니다. 우분투 계열에서는 보통 더 단순한 도구를 쓰고 이쪽은 레드햇 계열에서 기본인데, 어느 쪽을 쓰든 규칙이 두 군데에 나뉘지 않게 하나만 쓰는 것이 중요합니다.

## 코드 예

```bash
sudo firewall-cmd --get-active-zones
sudo firewall-cmd --zone=public --list-all

# --permanent 없이 하면 재부팅 때 사라진다
sudo firewall-cmd --permanent --zone=public --add-service=https
sudo firewall-cmd --reload        # 영구 설정을 지금 적용

# 우분투에서 ufw 를 쓰고 있다면 이것을 함께 켜지 않는다
```

## 주의할 점 / 경계 조건

영구 적용을 지정하지 않으면 재부팅 때 규칙이 사라집니다. 반대로 영구만 적용하고 다시 읽지 않으면 지금은 적용되지 않습니다.

## 관련 용어

- `authentication`
- `authorization`
- `security-group`

## 흔한 오해

두 방화벽 도구를 함께 켜면 더 안전하다고 생각하기 쉽지만, 같은 커널 규칙을 두 도구가 건드리면 어느 쪽이 적용됐는지 알 수 없게 됩니다. 하나만 씁니다.
