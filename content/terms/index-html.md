# index.html

## 한 줄 설명

웹 앱의 최초 HTML document로 자주 쓰이는 entry file.

## 쉽게 설명하면

`index.html`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

Vite에서는 script entry와 root element를 제공해 JavaScript 앱이 붙을 자리를 만든다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
index.html
```

## 관련 용어

- `html`
- `browser-rendering`
