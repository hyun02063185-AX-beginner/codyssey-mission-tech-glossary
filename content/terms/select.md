# SELECT

## 한 줄 설명

table에서 필요한 column과 row를 읽는 SQL 명령.

## 쉽게 설명하면

표에서 필요한 칸과 줄만 골라 읽는 명령입니다. 읽기만 하므로 데이터가 바뀌지 않습니다.

## 정확한 설명

어떤 열을 가져올지, 어느 표에서, 어떤 조건에 맞는 행을, 어떤 순서로, 몇 개까지 가져올지를 지정한다. 조건절이 없으면 모든 행을 읽으므로 표가 커질수록 비용이 커지고, 정렬을 지정하지 않으면 순서는 보장되지 않는다.

## 이 미션에서는 왜 필요한가

이 회차의 모든 조회가 이 명령입니다. `SELECT *`로 시작하기 쉽지만 필요한 열만 적는 습관을 들이면, 표에 열이 추가돼도 화면이 깨지지 않고 읽어 오는 양도 줄어듭니다.

## 코드 예

```sql
-- 필요한 열만 적는다
SELECT id, title, created_at
FROM   post
WHERE  author_id = 3
  AND  created_at >= '2026-03-01'
ORDER  BY created_at DESC
LIMIT  20;

-- 정렬을 적지 않으면 순서는 보장되지 않는다
SELECT id, title FROM post LIMIT 5;   -- 매번 같은 5개라는 보장이 없다
```

## 주의할 점 / 경계 조건

조건에서 문자열을 비교할 때 대소문자 처리는 데이터베이스와 설정에 따라 다릅니다. 같은 쿼리가 환경에 따라 다른 결과를 낼 수 있습니다.

## 관련 용어

- `sql`
- `table`

## 흔한 오해

조회는 가볍다고 생각하기 쉽지만, 조건이 없거나 색인을 타지 못하면 표 전체를 읽습니다. 읽기도 충분히 무거워질 수 있습니다.
