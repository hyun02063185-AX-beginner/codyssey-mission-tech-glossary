# Secret Management

## 한 줄 설명

key·token·password를 안전하게 저장, 전달, 회전, 폐기하는 운영 방식.

## 쉽게 설명하면

`Secret Management`을(를) 누가 접근할 수 있고 어떤 정보가 노출되는지의 관점에서 확인하면 됩니다.

## 정확한 설명

key·token·password를 안전하게 저장, 전달, 회전, 폐기하는 운영 방식. 실제 적용에서는 신원, 권한, network 경계, 비밀값 보관 중 관련된 조건을 구분해야 합니다.

## 이 미션에서는 왜 필요한가

본과정 M06에서 API 키를 안전하게 다루려면 "코드에 적지 않는다"만으로는 부족합니다. 그러면 어디에 두고 어떻게 전달할지를 정해야 하는데, 그 질문 전체를 가리키는 상위 개념입니다.

## 코드 예

```text
한 줄로 정리하면
  코드에 적지 않는다 → 환경 변수나 비밀 저장소에 둔다
  → 저장소에 올리지 않는다(.gitignore) → 새어 나가면 즉시 폐기하고 재발급
```
