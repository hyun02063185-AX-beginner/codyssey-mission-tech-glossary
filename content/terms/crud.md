# CRUD

## 한 줄 설명

CRUD는 데이터를 만들고(Create), 읽고(Read), 바꾸고(Update), 지우는(Delete) 네 가지 기본 작업을 묶어 부르는 말입니다.

## 쉽게 설명하면

할 일을 새로 추가하고, 목록에서 보고, 제목을 고치고, 끝난 일을 삭제하는 흐름이 CRUD입니다.

## 정확한 설명

CRUD는 화면·API·데이터베이스에서 반복되는 데이터 생명주기를 설명합니다. HTTP의 POST·GET·PATCH·DELETE와 자주 연결되지만, CRUD 자체가 HTTP 메서드나 데이터베이스 명령어는 아닙니다. 각 작업에서 입력 검증, 권한 확인, 없는 데이터 처리도 따로 설계해야 합니다.

## 이 미션에서는 왜 필요한가

본과정 M02·M03·M12에서 한 종류의 데이터를 생성·조회·수정·삭제하는 기능을 구현합니다.

## 관련 용어

- rest-api
- sql
- fastapi
- form-validation

## 흔한 오해

CRUD를 구현했다고 데이터가 안전해지는 것은 아닙니다. 삭제 권한이나 잘못된 입력 처리는 각 작업에 따로 필요합니다.
