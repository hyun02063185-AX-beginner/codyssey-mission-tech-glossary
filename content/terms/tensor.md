# 텐서

## 한 줄 설명

여러 차원의 수를 담아 벡터·행렬을 일반화한 배열.

## 쉽게 설명하면

숫자 표를 1차원, 2차원, 그 이상으로 확장한 상자다.

## 정확한 설명

shape와 dtype이 연산 가능 여부를 결정한다. 신경망에서는 입력, weight, 중간 feature를 tensor로 표현한다.

## 언제 쓰나

이미지 batch를 [batch, height, width, channel] 형태로 저장한다.

## 기억할 경계

차원 수가 많다고 자동으로 tensor 연산이 효율적인 것은 아니다.

## 이 미션에서는 왜 필요한가

시뮬레이터가 다루는 값이 1차원 배열에서 2차원 격자로, 다시 여러 장으로 늘어날 때 그것을 한 이름으로 부르는 말입니다. 차원이 늘어도 계산 규칙은 같고 모양(shape)만 맞으면 된다는 점이 핵심입니다.

## 코드 예

```text
0차원   3                         하나의 수
1차원   [1, 2, 3]                 벡터
2차원   [[1,2],[3,4]]             행렬 — 이번 회차의 입력 격자
3차원   [[[..]], [[..]]]          격자 여러 장

모양이 맞아야 계산된다
  (3,3) 과 (3,3) 의 원소별 곱  → 된다
  (3,3) 과 (2,2)               → 안 된다

"차원이 몇 개인가" 보다 "모양이 맞는가" 를 먼저 확인한다
```
