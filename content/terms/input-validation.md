# 입력 검증

## 한 줄 설명

외부에서 받은 값이 형식·범위·규칙에 맞는지 사용 전에 확인하는 과정입니다.

## 쉽게 설명하면

문 앞에서 초대장과 인원수를 확인하는 것처럼, 프로그램에 넣기 전에 값이 쓸 수 있는 것인지 확인합니다.

## 정확한 설명

Input validation은 HTTP 요청, CLI 인자, 파일, 폼 값처럼 신뢰할 수 없는 입력을 허용 목록·타입·길이·범위·도메인 규칙으로 검사하고 실패를 명확히 처리하는 작업입니다.

## 동작 원리

1. 입력의 출처와 기대 스키마를 정합니다.
2. 형식·범위·관계 규칙을 확인합니다.
3. 실패는 안전한 오류로, 성공 값만 다음 계층으로 전달합니다.

## 이 미션에서는 왜 필요한가

M03 API와 M12 서버 입력에서 잘못된 값이 비즈니스 로직이나 DB까지 들어가지 않게 합니다.

## 코드 예

```python
age = int(raw_age)
if not 0 <= age <= 150:
    raise ValueError('age 범위 오류')
```

## 주의할 점 / 경계 조건

클라이언트 검증은 UX를 위한 보조 수단입니다. 서버도 독립적으로 같은 핵심 규칙을 검증해야 합니다.

## 관련 용어

- `output-validation`
- `form-validation`
- `sql-injection`
- `authentication`

## 흔한 오해

타입 변환에 성공했다고 입력이 업무 규칙까지 만족하는 것은 아닙니다.
