# 로그아웃

## 한 줄 설명

현재 인증 session이나 token 사용을 끝내는 절차.

## 쉽게 설명하면

로그인할 때 받은 표식을 더는 쓰지 못하게 만드는 절차입니다. 화면에서 로그인 버튼으로 바꾸는 것만으로는 표식이 살아 있습니다.

## 정확한 설명

세션 방식이면 서버에 저장된 세션을 지우고 클라이언트의 쿠키도 만료시킨다. 토큰 방식이면 서버가 발급한 토큰을 회수할 수단이 기본적으로 없으므로, 폐기 목록을 두거나 수명을 짧게 하고 재발급 토큰 쪽을 무효화한다.

## 이 미션에서는 왜 필요한가

이 회차의 인증이 끝나는 지점입니다. 세션으로 만들었다면 지우면 끝이지만 토큰으로 만들었다면 이미 나간 토큰은 만료 전까지 유효하므로, 로그아웃을 어떻게 구현할지가 앞선 선택의 결과로 드러나는 자리입니다.

## 코드 예

```python
@app.post('/logout')
def logout(request: Request):
    request.session.clear()          # 서버 쪽 상태를 지운다
    response = RedirectResponse('/', status_code=303)
    response.delete_cookie('session', path='/')   # 발급할 때와 같은 path
    return response

# 토큰 방식이라면 지울 서버 상태가 없다.
# access token 은 만료를 기다리고, refresh token 쪽을 폐기 목록에 넣는다
```

## 주의할 점 / 경계 조건

쿠키를 지울 때는 발급할 때와 같은 경로와 도메인을 지정해야 합니다. 다르면 브라우저가 다른 쿠키로 보고 원래 것을 남겨 둡니다.

## 관련 용어

- `authentication`
- `authorization`
- `security-group`

## 흔한 오해

클라이언트에서 토큰을 지웠으니 로그아웃이 끝났다고 생각하기 쉽지만, 지운 것은 사본 하나뿐입니다. 그 토큰을 어딘가 복사해 둔 쪽에서는 만료 전까지 그대로 쓸 수 있습니다.

## 동료평가 질문

토큰 방식에서 로그아웃 직후에도 이전 토큰으로 요청이 통과하는지 확인하고, 통과한다면 어떻게 막을지 설명할 수 있나요?
