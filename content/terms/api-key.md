# API 키

## 한 줄 설명

API 키는 외부 서비스가 요청한 애플리케이션을 식별하고 사용량을 관리하기 위해 발급하는 비밀 값입니다.

## 쉽게 설명하면

서비스의 출입증에 가깝습니다. 키가 코드나 공개 저장소에 노출되면 다른 사람이 내 서비스 계정으로 요청을 보낼 수 있습니다.

## 정확한 설명

API 키는 보통 요청 헤더나 환경 변수로 전달합니다. 브라우저에 넣으면 사용자가 볼 수 있으므로, 비밀 키는 대개 서버 환경 변수에 보관하고 서버가 대신 외부 API를 호출합니다.

## 이 미션에서는 왜 필요한가

- main M02: 외부 서비스 연결에 필요한 민감정보를 구분합니다.
- main M06: AI API를 호출할 때 키를 안전하게 관리합니다.

## 관련 용어

- `environment-variable`
- `authentication`
- `authorization`

## 흔한 오해

API 키가 있다고 해서 사람 한 명의 로그인 정보를 뜻하는 것은 아닙니다. 사용자 인증과 서비스 키 관리는 목적과 보관 위치가 다릅니다.
