# 권한 숫자 표기

## 한 줄 설명

Unix file permission을 owner·group·other의 rwx bit로 적는 숫자 표기.

## 쉽게 설명하면

`권한 숫자 표기`은(는) 실행 중인 program과 operating system의 상태를 관찰할 때 구분해야 하는 개념입니다.

## 정확한 설명

Unix file permission을 owner·group·other의 rwx bit로 적는 숫자 표기. 실제 장애 판단에서는 값의 순간 변화와 지속 상태, process 범위와 system 범위를 나누어 봐야 합니다.

## 이 미션에서는 왜 필요한가

예비 M01은 권한 숫자를 읽고 그 뜻을 설명할 수 있어야 한다고 요구합니다. 755와 644를 외우는 것이 아니라 세 자리가 각각 소유자·그룹·나머지를 가리키고 각 자리가 읽기 4·쓰기 2·실행 1의 합이라는 규칙을 아는 것이 요구 사항입니다.

## 코드 예

```bash
chmod 755 run.sh     # 소유자 rwx(7) · 그룹 r-x(5) · 나머지 r-x(5)
chmod 644 note.txt   # 소유자 rw-(6) · 그룹 r--(4) · 나머지 r--(4)
ls -l                # 앞의 문자열로 확인
```

## 관련 용어

- `process`
- `linux`
