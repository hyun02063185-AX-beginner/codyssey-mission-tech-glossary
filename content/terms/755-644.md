# 권한 숫자 표기

## 한 줄 설명

Unix file permission을 owner·group·other의 rwx bit로 적는 숫자 표기.

## 쉽게 설명하면

권한을 숫자 세 자리로 줄여 적는 표기입니다. 각 자리가 주인·모임·나머지에 대응합니다.

## 정확한 설명

읽기 4, 쓰기 2, 실행 1을 더해 한 자리를 만들고, 세 자리를 나란히 놓아 세 부류의 권한을 표현한다. 디렉터리에서 실행 자리는 실행이 아니라 그 안으로 들어갈 수 있는지를 뜻하므로, 같은 숫자라도 파일과 디렉터리에서 의미가 다르다.

## 이 미션에서는 왜 필요한가

예비 M01은 권한 숫자를 읽고 그 뜻을 설명할 수 있어야 한다고 요구합니다. 755와 644를 외우는 것이 아니라 세 자리가 각각 소유자·그룹·나머지를 가리키고 각 자리가 읽기 4·쓰기 2·실행 1의 합이라는 규칙을 아는 것이 요구 사항입니다.

## 코드 예

```bash
# 읽기 4 + 쓰기 2 + 실행 1
#   7 = rwx    5 = r-x    6 = rw-    4 = r--

chmod 755 script.sh     # 주인은 전부, 나머지는 읽기·실행
chmod 644 notes.txt     # 주인은 읽기·쓰기, 나머지는 읽기
chmod 600 .env          # 주인만 읽고 쓴다

# 디렉터리에서는 x 의 뜻이 다르다
chmod 644 mydir         # 목록은 보이지만 안으로 못 들어간다
ls mydir                # 이름은 나오는데
cat mydir/a.txt         # Permission denied
chmod 755 mydir         # x 가 있어야 들어간다
```

## 주의할 점 / 경계 조건

디렉터리에서 실행 자리를 빼면 안의 파일에 접근할 수 없게 됩니다. 파일 권한만 보고 원인을 찾으면 헤맵니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

같은 숫자면 파일이든 디렉터리든 같은 뜻이라고 생각하기 쉽지만, 실행 자리의 의미가 다릅니다. 644를 디렉터리에 주면 들어갈 수 없습니다.
