# Verification

## 한 줄 설명

변경이나 조치가 기대한 결과를 실제 증거로 확인하는 과정입니다.

## 쉽게 설명하면

수리 뒤에 전등이 켜지는지 다시 스위치를 눌러 보는 일입니다.

## 정확한 설명

Verification은 요구사항·측정값·테스트·로그를 사용해 결과가 만족되는지 검사합니다. 구현했다는 사실과 원하는 효과가 있었다는 사실은 다릅니다.

## 이 미션에서는 왜 필요한가

M08에서 조치 전후 CPU·메모리·로그를 비교해 문제 해결을 주장할 근거를 만듭니다.

## 코드 예

```text
Before: CPU 98%
After: CPU 22%, 10분 동안 재발 없음
```

## 주의할 점 / 경계 조건

한 번의 성공만으로 모든 환경에서 해결됐다고 결론 내리기보다 관찰 기간과 실패 조건을 정해야 합니다.

## 관련 용어

- `root-cause-analysis`
- `benchmark`
- `health-check`

## 흔한 오해

Verification은 코드 리뷰나 배포와 동의어가 아닙니다. 각각 다른 증거를 제공합니다.

## 동료평가 질문

Before/After 수치를 기록하면 workaround와 근본 해결을 어떻게 구분하는 데 도움이 되나요?
