# Not Found Page

## 한 줄 설명

요청한 route나 resource가 없을 때 보여 주는 404 안내 화면.

## 쉽게 설명하면

`Not Found Page`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

SPA의 catch-all route와 server의 올바른 404 status를 함께 고려한다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
Not Found Page
```

## 관련 용어

- `client-side-routing`
- `http-status-code`
