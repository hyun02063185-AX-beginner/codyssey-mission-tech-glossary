# Not Found Page

## 한 줄 설명

요청한 route나 resource가 없을 때 보여 주는 404 안내 화면.

## 쉽게 설명하면

없는 주소로 들어왔을 때 보여 주는 안내 화면입니다. 빈 화면 대신 "여기는 없다"와 "그러면 어디로 갈 수 있다"를 알려 줍니다.

## 정확한 설명

SPA의 catch-all route와 server의 올바른 404 status를 함께 고려한다.

## 이 미션에서는 왜 필요한가

이 회차에서 주소를 잘못 입력한 사용자가 빈 화면을 만나면 앱이 고장 난 것으로 보입니다. 라우터에 어떤 경로에도 맞지 않을 때의 화면을 등록해 두어야 그 상황이 처리됩니다.

## 코드 예

```jsx
<Route path="*" element={<NotFound />} />

function NotFound() {
  return (
    <main>
      <h1>찾는 페이지가 없습니다</h1>
      <p>주소가 바뀌었거나 삭제된 글일 수 있습니다.</p>
      <Link to="/">목록으로 돌아가기</Link>
    </main>
  );
}

// 이 라우트가 없으면 오류가 아니라 "아무것도 안 그려진" 화면이 된다
```

## 주의할 점 / 경계 조건

SPA에서 이 화면을 보여 줘도 서버는 200을 돌려준 상태입니다. 검색 엔진이나 모니터링 도구는 정상 페이지로 인식하므로, 필요하면 서버 쪽에서도 404를 내야 합니다.

## 관련 용어

- `client-side-routing`
- `http-status-code`

## 흔한 오해

라우트를 등록하지 않았으니 자동으로 404 화면이 나온다고 생각하기 쉽지만, 아무것도 맞지 않으면 아무것도 그려지지 않습니다. 빈 화면이 나오는 것이지 오류가 나는 것이 아닙니다.

## 동료평가 질문
