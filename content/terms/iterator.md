# Iterator

## 한 줄 설명

컬렉션의 요소를 차례로 꺼내는 순회 인터페이스.

## 쉽게 설명하면

상자를 통째로 꺼내지 않고 다음 물건을 하나씩 요청하는 손잡이다.

## 정확한 설명

Python iterator는 `__next__`로 다음 값을 내고 끝에서 `StopIteration`을 발생시킨다. for문이 이를 소비한다.

## 언제 쓰나

큰 파일을 한 줄씩 읽어 메모리를 아낀다.

## 기억할 경계

iterator는 한 번 소진되면 보통 처음부터 다시 돌 수 없다.

## 이 미션에서는 왜 필요한가

가계부 기록이 많아지면 파일을 통째로 메모리에 올리지 않고 한 줄씩 처리하는 편이 낫습니다. 그 한 줄씩을 가능하게 하는 것이 이 구조이며, 한 번 끝까지 돌면 다시 쓸 수 없다는 성질이 "왜 두 번째 반복문이 빈 결과를 내는가"의 답이기도 합니다.

## 코드 예

```python
rows = iter(['1월 3000', '2월 4500'])

print(list(rows))   # ['1월 3000', '2월 4500']
print(list(rows))   # []  ← 이미 소진되었다

# 파일도 같은 성질을 가진다
with open('ledger.csv', encoding='utf-8') as f:
    for line in f:          # 한 줄씩 읽어 메모리를 아낀다
        pass
    print(sum(1 for _ in f))   # 0 — 이미 끝까지 읽었다
```
