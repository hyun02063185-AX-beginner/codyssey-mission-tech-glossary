# Human-in-the-loop

## 한 줄 설명

자동화 과정에 사람이 검토·승인·수정 단계로 참여하는 설계.

## 쉽게 설명하면

모델이 혼자 결정하지 않고 중요한 순간에 사람에게 넘기는 방식이다.

## 정확한 설명

신뢰도 임계값, 검토 UI, 피드백 기록, 책임 범위를 정의해 사람의 판단을 시스템 흐름에 넣는다.

## 언제 쓰나

고위험 답변을 게시하기 전에 운영자가 승인한다.

## 기억할 경계

사람을 넣었다고 지연·편향·책임 문제가 자동으로 사라지지는 않는다.

## 이 미션에서는 왜 필요한가

이 회차는 생성된 문구를 바로 쓰지 않고 사용자가 확인한 뒤 적용하도록 요구합니다. 자동으로 커밋해 버리면 잘못된 메시지가 기록에 남고 되돌리기 어려우므로, 사람이 보는 단계가 되돌릴 수 없는 동작 앞에 놓여야 합니다.

## 코드 예

```text
적용 순서

  생성 → 검증 → 화면에 보여 줌 → [사용자 확인] → 적용
                                       ↑
                        되돌릴 수 없는 동작 바로 앞에 둔다

확인 단계에서 할 수 있어야 하는 것
  그대로 쓰기 / 고쳐서 쓰기 / 다시 생성 / 취소

"확인하시겠습니까 (y/n)" 만 있으면 고칠 방법이 없다.
```
