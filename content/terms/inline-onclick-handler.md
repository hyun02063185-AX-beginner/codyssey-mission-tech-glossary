# inline onclick handler

## 한 줄 설명

HTML attribute에 JavaScript를 직접 적는 이벤트 처리 방식.

## 쉽게 설명하면

`inline onclick handler`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

markup과 behavior를 결합해 테스트·재사용·CSP 관리가 어려워질 수 있다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
inline onclick handler
```

## 관련 용어

- `add-event-listener`
- `interaction`
