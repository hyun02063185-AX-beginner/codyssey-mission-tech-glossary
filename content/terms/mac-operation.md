# MAC 연산

## 한 줄 설명

MAC 연산은 두 수를 곱한 뒤 이전 합계에 더하는 multiply-accumulate 계산입니다.

## 쉽게 설명하면

`sum += a[i] * b[i]`를 반복하는 계산입니다. 벡터의 각 원소를 곱해 더하는 내적이 대표적인 예입니다.

## 코드 예

```python
total = 0
for a, b in zip(xs, ws):
    total += a * b
```

## 정확한 설명

행렬 곱과 신경망의 선형층은 많은 곱셈과 누적 덧셈으로 이루어집니다. GPU·NPU 같은 가속기는 이 반복 계산을 많이 처리하도록 설계됩니다. MAC은 모델 전체나 신경망 자체가 아니라 그 안에서 반복되는 기본 계산 단위입니다.

## 이 미션에서는 왜 필요한가

예비 M03에서 반복문으로 MAC 연산을 직접 구현해 벡터와 행렬 계산의 기반을 익힙니다.

MAC 하나가 AI 모델 하나를 실행한다는 뜻은 아닙니다. 모델은 매우 많은 MAC 연산을 층마다 반복합니다.
