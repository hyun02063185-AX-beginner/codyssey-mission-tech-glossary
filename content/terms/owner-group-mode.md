# Owner / Group / Mode

## 한 줄 설명

Unix file의 owner, group, rwx mode로 구성된 기본 권한 모델.

## 쉽게 설명하면

파일마다 주인이 누구고, 어느 모임에 속하고, 각각 무엇을 할 수 있는지 적어 둔 것입니다. 세 부류(주인·모임·나머지)에 대해 읽기·쓰기·실행을 정합니다.

## 정확한 설명

파일마다 소유자 ID, 그룹 ID, 그리고 세 부류별 rwx 비트를 갖는다. 접근이 허용되는지는 요청한 프로세스의 사용자·그룹이 어느 부류에 해당하는지를 먼저 정하고 그 부류의 비트만 본다. 디렉터리에서 x는 실행이 아니라 그 안으로 들어갈 수 있는지를 뜻한다.

## 이 미션에서는 왜 필요한가

이 회차에서 점검 스크립트와 로그 파일의 권한을 정할 때 쓰입니다. 로그에 민감한 정보가 담길 수 있으므로 아무나 읽지 못하게 해야 하고, 스크립트는 실행 비트가 있어야 직접 실행됩니다.

## 코드 예

```bash
ls -l check.sh
# -rwxr-x---  1 ubuntu ops  1024 Sep 22 10:00 check.sh
#  │└┬┘└┬┘└┬┘   └─┬──┘ └┬┘
#  │ │  │  │      주인  모임
#  │ │  │  └ 나머지: 아무것도 못 한다
#  │ │  └─── 모임 ops: 읽기·실행
#  │ └────── 주인: 읽기·쓰기·실행
#  └──────── - 는 일반 파일, d 는 디렉터리

chmod 750 check.sh          # 위와 같은 상태
chmod 640 report.log        # 로그는 실행할 이유가 없다
```

## 주의할 점 / 경계 조건

디렉터리의 x 비트를 지우면 그 안의 파일 권한과 무관하게 접근이 막힙니다. 파일만 보고 원인을 찾으면 한참 헤맵니다.

## 관련 용어

## 흔한 오해

읽기 권한이 있으면 지울 수 있다고 생각하기 쉽지만, 파일을 지울 수 있는지는 그 파일이 아니라 담긴 디렉터리의 쓰기 권한이 정합니다.
