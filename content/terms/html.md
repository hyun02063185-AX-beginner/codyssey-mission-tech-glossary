# HTML

## 한 줄 설명

HTML은 웹페이지의 콘텐츠와 문서 구조를 표현하는 마크업 언어입니다.

## 쉽게 설명하면

HTML은 페이지에 무엇이 있는지와 각 콘텐츠가 어떤 역할인지 적는 뼈대입니다. CSS가 모양을, JavaScript가 동작을 더합니다.

## 정확한 설명

브라우저는 HTML의 element와 tag를 읽어 문서 구조를 만들고, 이를 DOM 트리로 표현합니다. 제목, 문단, 링크, 이미지, 폼처럼 콘텐츠의 의미와 순서를 HTML로 먼저 기술합니다.

`header`, `main`, `section`, `footer` 같은 시맨틱 요소는 화면 모양이 아니라 콘텐츠의 역할을 전달합니다. CSS와 JavaScript는 이 구조를 표현하거나 조작하지만 HTML 자체는 프로그래밍 언어가 아닙니다.

## 이 미션에서는 왜 필요한가

M01의 Hero·About·Skills·Projects·Contact·Footer를 논리적인 문서 구조와 제목 흐름으로 구성합니다.

## 코드 예

```html
<main>
  <section id="projects"><h2>Projects</h2></section>
</main>
```

## 관련 용어

- semantic-html
- css
- javascript
- dom

## 흔한 오해

HTML은 화면을 예쁘게 만드는 언어가 아니라 콘텐츠와 구조를 표시하는 언어입니다.
