# PII

## 한 줄 설명

개인을 직접 또는 다른 정보와 결합해 식별할 수 있는 개인정보.

## 쉽게 설명하면

`PII`을(를) 누가 접근할 수 있고 어떤 정보가 노출되는지의 관점에서 확인하면 됩니다.

## 정확한 설명

개인을 직접 또는 다른 정보와 결합해 식별할 수 있는 개인정보. 실제 적용에서는 신원, 권한, network 경계, 비밀값 보관 중 관련된 조건을 구분해야 합니다.

## 이 미션에서는 왜 필요한가

본과정 M06에서 마스킹 대상을 API 키에서 한 걸음 넓힐 때 만나는 개념입니다. 키만 가려도 코드 변경 내용에 이름·메일·전화번호가 섞여 있을 수 있어, 무엇이 개인을 식별하는 정보인지 먼저 정해야 어디를 가릴지가 정해집니다.

## 코드 예

```text
바깥으로 보내기 전에 확인할 것
  주석과 테스트 데이터에 실제 메일·전화번호가 들어 있지 않은지
  로그 예시에 사용자 식별자가 그대로 있는지
  샘플 데이터가 실제 데이터를 복사한 것은 아닌지
```
