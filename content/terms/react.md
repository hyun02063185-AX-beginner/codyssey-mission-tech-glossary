# React

## 한 줄 설명

React는 화면을 작은 컴포넌트로 나누고, 상태가 바뀌면 필요한 UI를 다시 그리도록 돕는 JavaScript 라이브러리입니다.

## 쉽게 설명하면

화면을 통째로 고치는 대신 버튼, 카드, 메뉴처럼 역할별 조각을 만들고 조합하는 방식입니다. 데이터가 바뀌면 React가 달라진 화면을 계산해 반영합니다.

## 정확한 설명

React 컴포넌트는 props를 입력으로 받고 UI를 반환합니다. state가 바뀌면 React는 새 UI 결과를 계산하고 실제 DOM에 필요한 변경만 적용합니다. React 자체가 서버나 라우팅을 자동으로 제공하는 것은 아닙니다.

## 이 미션에서는 왜 필요한가

- main M02: React로 SPA 화면과 컴포넌트를 구성합니다.
- main M01: 외부 UI 프레임워크 없이 구현한다는 요구와 대비해 역할을 이해합니다.

## 관련 용어

- `reusable-component`
- `react-state`
- `client-side-routing`

## 흔한 오해

React를 쓰면 HTML이 사라지는 것이 아닙니다. React는 결국 브라우저의 DOM에 화면을 반영합니다.
