# sudo

## 한 줄 설명

허가된 명령 하나를 다른 사용자, 보통 root 권한으로 실행하는 명령.

## 쉽게 설명하면

평소에는 일반 권한으로 일하다가, 필요한 명령 하나만 관리자 권한으로 실행하는 방법입니다. 권한을 켜 두는 것이 아니라 그때만 빌립니다.

## 정확한 설명

설정 파일에 적힌 규칙에 따라 어떤 사용자가 어떤 명령을 어떤 권한으로 실행할 수 있는지 판단하고, 실행 내역을 기록에 남긴다. 명령 단위로 권한이 올라가므로 그 명령이 끝나면 원래 권한으로 돌아온다.

## 이 미션에서는 왜 필요한가

이 회차는 관리자 권한을 필요할 때만 쓰도록 요구합니다. 관리자로 계속 작업하면 잘못 친 명령 하나가 시스템 전체를 건드릴 수 있는데, 이 방식은 권한이 필요한 순간이 언제인지 스스로 드러내 주기도 합니다.

## 코드 예

```bash
sudo systemctl restart nginx     # 이 명령만 관리자 권한으로
whoami                           # 끝나면 원래 계정으로 돌아와 있다

sudo -l                          # 내가 무엇을 할 수 있는지 확인

# 환경이 달라진다
echo $PATH
sudo env | grep PATH             # 값이 다르다 — 스크립트에서 문제가 된다

# 기록이 남는다
sudo journalctl -e | grep sudo
```

## 주의할 점 / 경계 조건

실습 환경에 따라 이 명령 자체가 막혀 있을 수 있습니다. 그때는 권한이 필요 없는 대체 도구를 쓰고, 무엇이 막혀 어떻게 우회했는지 기록에 적습니다.

## 흔한 오해

앞에 붙이면 무엇이든 된다고 생각하기 쉽지만, 설정 파일이 허용한 명령만 실행됩니다. 또 환경 변수와 현재 경로가 달라지므로 같은 명령이 다르게 동작할 수 있습니다.
