# Asynchronous Programming

## 한 줄 설명

비동기 프로그래밍은 오래 걸리는 작업의 완료를 기다리는 동안 프로그램이 다른 일을 계속 처리하도록 흐름을 구성하는 방식입니다.

## 쉽게 설명하면

배달을 주문한 뒤 문 앞에서 멈춰 서 있지 않고 다른 일을 하다가, 도착 알림을 받는 방식입니다.

## 정확한 설명

네트워크 요청·파일 I/O·타이머 같은 작업은 완료 시점이 바로 정해지지 않습니다. JavaScript에서는 callback, Promise, async/await로 완료·실패 이후의 처리를 연결합니다. 비동기는 병렬 처리와 동의어가 아니며, 작업을 맡긴 뒤 결과가 준비되었을 때 이어서 처리하는 제어 흐름입니다.

## 동작 원리

- 실행 환경에 시간이 걸리는 작업을 요청합니다.
- 현재 JavaScript 실행 흐름은 다른 동기 작업을 계속할 수 있습니다.
- 완료 뒤 후속 함수가 대기열을 거쳐 실행되고 UI나 상태를 갱신합니다.

## 이 미션에서는 왜 필요한가

M01에서 GitHub API를 기다리는 동안 로딩 상태를 보여 주고, 성공·실패 결과에 따라 화면을 바꿉니다.

## 관련 용어

- `event-loop`
- `callback`
- `promise`
- `async-await`

## 흔한 오해

`await`를 썼다고 브라우저 전체가 멈추는 것은 아닙니다. 해당 async 함수의 다음 단계가 기다릴 뿐, 다른 이벤트 처리는 계속될 수 있습니다.
