# git diff

## 한 줄 설명

두 Git 상태 사이의 line 단위 차이를 보는 명령.

## 쉽게 설명하면

무엇이 어떻게 바뀌었는지 줄 단위로 보여 주는 명령입니다. 무엇과 무엇을 비교할지 지정할 수 있습니다.

## 정확한 설명

기본은 작업 디렉터리와 스테이지의 차이이며, 옵션에 따라 스테이지와 마지막 커밋, 또는 두 커밋 사이를 비교한다. 비교 대상을 지정하지 않으면 스테이지에 올린 변경은 결과에 나오지 않으므로, 커밋될 내용을 보려면 대상을 따로 지정해야 한다.

## 이 미션에서는 왜 필요한가

이 회차의 AI 도우미가 커밋 메시지를 만들 근거로 수집하는 내용입니다. 비교 대상을 잘못 지정하면 이미 스테이지에 올린 변경이 빠진 채로 수집되어, 실제 커밋과 다른 메시지가 만들어집니다.

## 코드 예

```bash
git diff                  # 작업 디렉터리 ↔ 스테이지 (올린 것은 안 나온다)
git diff --staged         # 스테이지 ↔ 마지막 커밋 (커밋될 내용)
git diff main...HEAD      # 갈라진 뒤 내 브랜치에서 생긴 변경

# 양이 많을 때는 요약부터
git diff --staged --stat
# src/app.py   | 42 ++++++++-----
# 2 files changed, 30 insertions(+), 12 deletions(-)

# 도구에 넘길 때는 잘라서
git diff --staged | head -c 8000
```

## 주의할 점 / 경계 조건

차이가 크면 모델에 보낼 수 있는 양을 넘습니다. 파일 목록과 통계만 먼저 보내거나 잘라서 보내야 합니다.

## 관련 용어

- `git`
- `commit`

## 흔한 오해

아무 인자 없이 쓰면 커밋될 내용이 보인다고 생각하기 쉽지만, 스테이지에 올린 것은 빠집니다. 커밋될 내용은 다른 옵션으로 봐야 합니다.
