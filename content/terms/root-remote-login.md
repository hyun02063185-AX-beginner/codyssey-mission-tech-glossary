# Root 원격 로그인

## 한 줄 설명

root 계정으로 network를 통해 직접 로그인하는 방식.

## 쉽게 설명하면

모든 권한을 가진 계정으로 곧바로 원격 접속하는 방식입니다. 이름이 어디서나 같아서 공격자가 계정 이름을 추측할 필요가 없습니다.

## 정확한 설명

이 계정은 이름이 고정돼 있고 권한 제한이 없으므로, 원격 접속을 허용하면 추측 대상이 비밀번호 하나로 줄어든다. 일반 계정으로 접속한 뒤 필요할 때만 권한을 올리면 접속 단계와 권한 상승 단계가 나뉘어 기록도 남는다.

## 이 미션에서는 왜 필요한가

이 회차는 이 접속을 막도록 요구합니다. 서버를 인터넷에 올리면 이 계정을 노린 자동 접속 시도가 곧바로 들어오는데, 막아 두면 공격자는 계정 이름부터 알아내야 하고 로그에도 누가 무엇을 했는지 남습니다.

## 코드 예

```bash
# /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no

# 적용 전에 문법을 확인하고
sudo sshd -t

# 다른 창에서 일반 계정 접속이 되는지 먼저 확인한 뒤 적용한다
sudo systemctl reload ssh

# 막혔는지 확인
ssh root@서버주소        # Permission denied 가 나와야 한다
```

## 주의할 점 / 경계 조건

설정을 바꾼 뒤 서비스를 다시 시작하기 전에, 다른 창에서 일반 계정 접속이 되는지 먼저 확인해야 합니다. 확인 없이 적용하면 스스로 들어갈 길을 막을 수 있습니다.

## 관련 용어

- `authentication`
- `authorization`
- `security-group`

## 흔한 오해

비밀번호를 길게 하면 열어 둬도 괜찮다고 생각하기 쉽지만, 남는 것은 시도 기록이 계속 쌓인다는 문제입니다. 누가 무엇을 했는지 구분되지 않는 것도 그대로입니다.
