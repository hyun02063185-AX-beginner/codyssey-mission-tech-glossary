# expire_at

## 한 줄 설명

값이나 record가 만료되는 시각을 저장한 timestamp.

## 쉽게 설명하면

언제 만료되는지를 시각으로 적어 두는 값입니다. 남은 시간이 아니라 끝나는 시점을 저장합니다.

## 정확한 설명

만료 시점을 절대 시각으로 저장한다. 남은 시간을 저장하면 저장 이후 흐른 시간을 따로 계산해야 하지만, 시점을 저장하면 현재 시각과 비교하는 것으로 끝난다. 대신 어느 기준의 시각인지 정해 두지 않으면 서버와 클라이언트가 다른 시점을 가리킨다.

## 이 미션에서는 왜 필요한가

본과정 M09에서 만료를 힙으로 관리할 때 각 키가 들고 있는 값입니다. "앞으로 몇 초"를 그대로 두면 매번 다시 계산해야 하지만, 만료할 시각으로 바꿔 두면 가장 이른 것부터 꺼내 처리할 수 있습니다.

## 코드 예

```python
import heapq
heapq.heappush(expiry_heap, (expire_at, key))

now = time.time()
while expiry_heap and expiry_heap[0][0] <= now:
    _, key = heapq.heappop(expiry_heap)
    store.pop(key, None)
```

## 주의할 점 / 경계 조건

시간대가 다른 환경에서는 같은 문자열이 다른 시점이 됩니다. 기준을 정해 두거나 시간대를 포함해 저장해야 합니다.

## 관련 용어

- `time-to-live`
- `min-heap`

## 흔한 오해

시각으로 저장하면 안전하다고 생각하기 쉽지만, 기준 시계가 다르면 값의 뜻이 달라집니다. 어느 기준의 시각인지 정해 두지 않으면 서버와 클라이언트가 서로 다른 시점을 가리킵니다.
