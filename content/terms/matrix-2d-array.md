# 행렬 / 2차원 배열

## 한 줄 설명

행과 열 인덱스로 값을 저장하는 2차원 배열.

## 쉽게 설명하면

`행렬 / 2차원 배열`은(는) 값을 가로줄과 세로줄로 늘어놓아 "몇 번째 줄 몇 번째 칸"으로 찾을 수 있게 한 구조입니다.

## 정확한 설명

행과 열 인덱스로 값을 저장하는 2차원 배열. 파이썬에서는 보통 리스트의 리스트로 만들며, 바깥 리스트가 행이고 안쪽 리스트가 그 행의 칸들입니다. 크기가 커져도 접근 방식은 같습니다.

## 이 미션에서는 왜 필요한가

예비 M03의 Mini NPU 시뮬레이터에서 입력이 이 형태로 들어옵니다. 모드 1은 3×3이고 크기별로 3·5·13·25까지 커지므로, 크기가 달라져도 같은 코드로 다룰 수 있게 인덱스로 접근하는 습관이 필요합니다.

## 코드 예

```python
grid = [[0, 1, 0],
        [1, 1, 1],
        [0, 1, 0]]

n = len(grid)
for r in range(n):
    for c in range(n):
        value = grid[r][c]      # 행 먼저, 열 나중
```

## 주의할 점 / 경계 조건

크기가 정사각형이면 행과 열을 바꿔 써도 오류가 나지 않고 결과만 틀립니다. 또 곱셈으로 한 번에 만들면 같은 행이 여러 번 참조돼 한 칸을 고쳤는데 여러 줄이 함께 바뀌는 일이 생깁니다.
