# state

## 한 줄 설명

React의 state는 컴포넌트가 기억해야 하고, 바뀌면 화면도 다시 그려져야 하는 값을 관리하는 방법입니다.

## 쉽게 설명하면

검색어, 불러오는 중인지 여부, API 오류 메시지처럼 사용자의 행동이나 요청 결과에 따라 화면을 바꾸는 값이 state입니다.

## 코드 예

```jsx
const [count, setCount] = useState(0);
setCount(count + 1);
```

## 정확한 설명

state를 갱신하면 React는 새 값을 기준으로 컴포넌트를 다시 렌더링합니다. 값을 직접 바꾸는 대신 setter를 사용해야 React가 변경을 알 수 있습니다. 화면 계산에만 필요한 값은 state가 아니라 렌더링 중 계산하거나 다른 저장 위치를 검토할 수 있습니다.

## 이 미션에서는 왜 필요한가

본과정 M02에서 폼 값, 데이터, 로딩·성공·오류 상태를 화면과 함께 관리합니다.

## 관련 용어

## 흔한 오해

state를 바꾼 직후 다음 줄에서 새 값을 바로 읽을 수 있다고 단정하면 안 됩니다. React의 렌더링 시점과 갱신 방식을 고려해야 합니다.
