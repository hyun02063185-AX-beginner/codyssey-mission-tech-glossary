# Free Tier

## 한 줄 설명

AWS 서비스의 제한된 무료 사용량 정책.

## 쉽게 설명하면

`Free Tier`은(는) 실행 중인 program과 operating system의 상태를 관찰할 때 구분해야 하는 개념입니다.

## 정확한 설명

AWS 서비스의 제한된 무료 사용량 정책. 실제 장애 판단에서는 값의 순간 변화와 지속 상태, process 범위와 system 범위를 나누어 봐야 합니다.

## 이 미션에서는 왜 필요한가

본과정 M05에서 비용을 관리하는 기준입니다. 무료 한도는 서비스마다 조건과 기간이 다르고, 실습을 마친 뒤 자원을 지우지 않으면 한도를 넘겨 과금될 수 있으므로 "무료"라는 말을 조건과 함께 읽어야 합니다.

## 코드 예

```text
확인 순서
1. 쓰려는 서비스가 무료 한도 대상인지
2. 한도의 단위가 시간인지 요청 수인지 저장 용량인지
3. 기간 제한이 있는지 (가입 후 12개월 등)
4. 실습 후 지워야 할 자원 목록
```

## 관련 용어

- `process`
- `linux`
