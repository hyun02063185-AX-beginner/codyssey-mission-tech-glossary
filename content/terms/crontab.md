# crontab

## 한 줄 설명

cron job의 schedule과 command를 적는 설정 file.

## 쉽게 설명하면

언제 무엇을 실행할지 적어 두는 표입니다. 앞의 다섯 칸이 시각이고 그 뒤가 명령입니다.

## 정확한 설명

분·시·일·월·요일의 다섯 칸으로 시각을 표현하며, 일과 요일을 모두 지정하면 둘 중 하나만 맞아도 실행된다. 계정마다 따로 관리되고, 편집 명령으로 저장할 때 문법 검사를 거치므로 파일을 직접 고치는 것보다 안전하다.

## 이 미션에서는 왜 필요한가

이 회차에서 점검 일정을 등록하는 자리입니다. 다섯 칸의 의미를 잘못 읽으면 매분 돌아야 할 것이 하루 한 번만 돌거나 그 반대가 되므로, 저장한 뒤 실제로 언제 돌았는지 확인하는 단계가 필요합니다.

## 코드 예

```bash
crontab -e         # 편집. 저장할 때 문법을 검사한다
crontab -l         # 확인

# ┌ 분 (0-59)
# │ ┌ 시 (0-23)
# │ │ ┌ 일 (1-31)
# │ │ │ ┌ 월 (1-12)
# │ │ │ │ ┌ 요일 (0-7, 0과 7은 일요일)
  * * * * *  매분
  0 3 * * *  매일 새벽 3시
  */5 * * * *  5분마다

# % 는 줄바꿈으로 해석된다
* * * * * echo $(date +\%Y-\%m-\%d) >> /tmp/d.txt
```

## 주의할 점 / 경계 조건

퍼센트 기호는 줄바꿈으로 해석됩니다. 날짜 형식을 쓰는 명령에서는 반드시 앞에 역슬래시를 붙여야 합니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

파일을 직접 고치는 것과 같다고 생각하기 쉽지만, 편집 명령은 저장할 때 문법을 검사하고 반영까지 해 줍니다. 파일을 고치면 반영되지 않을 수 있습니다.
