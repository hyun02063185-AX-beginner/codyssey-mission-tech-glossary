# GitHub Pages

## 한 줄 설명

GitHub Pages는 GitHub 저장소의 정적 파일을 웹사이트로 공개 배포하는 호스팅 기능입니다.

## 쉽게 설명하면

내 컴퓨터에서 만든 HTML·CSS·JavaScript 파일을 다른 사람도 URL로 열 수 있게 하는 GitHub의 배포 기능입니다.

## 정확한 설명

GitHub Pages는 정적 파일을 제공하므로 서버에서 코드를 실행하는 배포와는 다릅니다. 저장소 설정과 배포 대상 branch 또는 workflow를 통해 사이트 URL을 만들며, HTML의 자원 경로는 배포 경로에서도 맞아야 합니다.

M01은 로컬 화면만 아니라 배포 URL에서 새로고침, 반응형, 메뉴·폼·API 상태가 동작하는지 확인합니다. 로컬에서 되더라도 상대 경로나 API 요청 조건 때문에 배포 환경에서 달라질 수 있습니다.

## 이 미션에서는 왜 필요한가

동료평가자가 실제 URL에서 M01 결과물을 확인할 수 있게 합니다.

## 관련 용어

- html
- responsive-web-design
- github-api

## 흔한 오해

GitHub Pages는 서버 데이터베이스나 비밀값을 안전하게 제공하는 백엔드가 아닙니다.
