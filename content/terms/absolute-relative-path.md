# 절대 경로 / 상대 경로

## 한 줄 설명

절대 경로는 파일 시스템의 시작점부터 적고, 상대 경로는 현재 위치를 기준으로 파일을 찾는 방법입니다.

## 쉽게 설명하면

`C:\\project\\README.md`처럼 주소를 처음부터 쓰면 절대 경로입니다. `./README.md`처럼 지금 있는 폴더에서 얼마나 이동할지만 쓰면 상대 경로입니다.

## 정확한 설명

절대 경로는 운영체제의 루트(Windows에서는 드라이브 포함)에서 대상까지의 전체 위치를 가리킵니다. 상대 경로는 명령을 실행한 현재 작업 폴더나, 코드를 불러오는 파일의 위치처럼 정해진 기준점에서 해석됩니다. `.`은 현재 폴더, `..`은 부모 폴더를 뜻합니다.

## 이 미션에서는 왜 필요한가

예비 M01에서 파일을 만들고 실행할 때, 현재 폴더와 대상 파일의 위치를 구분해 명령을 정확히 입력해야 합니다.

## 코드 예

```sh
cd project
python ./src/main.py
```

## 관련 용어

- directory
- filesystem
- cli

## 흔한 오해

상대 경로가 항상 짧거나 안전한 것은 아닙니다. 기준 폴더가 바뀌면 같은 경로 문자열도 다른 파일을 가리킬 수 있습니다.
