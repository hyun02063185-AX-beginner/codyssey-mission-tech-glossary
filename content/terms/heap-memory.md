# Heap Memory

## 한 줄 설명

동적으로 할당한 object가 보관되는 process memory 영역.

## 쉽게 설명하면

프로그램이 실행 중에 필요할 때마다 빌려 쓰는 메모리 영역입니다. 크기가 미리 정해져 있지 않습니다.

## 정확한 설명

실행 중에 할당하고 해제하는 영역으로, 함수가 끝나면 자동으로 정리되는 스택과 달리 명시적으로 또는 가비지 컬렉션으로 회수된다. 언어 런타임이 운영체제에서 크게 받아 두고 나눠 쓰므로, 프로그램 안에서 해제해도 운영체제 기준 사용량은 바로 줄지 않을 수 있다.

## 이 미션에서는 왜 필요한가

이 회차의 메모리 누수 조사를 한 단계 깊이 보는 개념입니다. 사용량이 줄지 않는 것이 프로그램이 안 놓아서인지 런타임이 붙잡고 있어서인지가 다른 문제인데, 이 구분을 모르면 엉뚱한 곳을 고치게 됩니다.

## 코드 예

```python
import tracemalloc, os, resource

tracemalloc.start()
# ... 의심되는 작업 ...
current, peak = tracemalloc.get_traced_memory()
print(f'파이썬 기준 현재 {current/1e6:.1f}MB / 최대 {peak/1e6:.1f}MB')

# 운영체제 기준
print('RSS', resource.getrusage(resource.RUSAGE_SELF).ru_maxrss, 'KB')

# 두 숫자가 다르면 런타임이 붙잡고 있는 것이다.
# 어디서 늘었는지 보려면 스냅샷을 비교한다
# snapshot.compare_to(before, 'lineno')
```

## 주의할 점 / 경계 조건

런타임 안에서는 해제됐는데 운영체제 기준 사용량은 그대로일 수 있습니다. 두 숫자를 함께 봐야 합니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

변수를 `None`으로 바꾸면 메모리가 바로 돌아온다고 생각하기 쉽지만, 참조가 사라지는 것과 운영체제에 반환되는 것은 다른 단계입니다.
