# Redis

## 한 줄 설명

메모리 기반 key-value 저장소로 cache·queue·pub/sub 등에 쓰이는 Redis.

## 쉽게 설명하면

빠르게 꺼내는 메모리 서랍을 서버 형태로 제공하는 도구다.

## 정확한 설명

자료형, TTL, persistence 옵션을 제공하며 network를 통해 여러 process가 공유할 수 있다.

## 대표 사용

세션 cache에 만료 시간이 있는 값을 저장한다.

## 주의할 점

Redis를 무조건 영구 데이터베이스 대체재로 쓰면 내구성 요구를 놓칠 수 있다.

## 이 미션에서는 왜 필요한가

이 회차에서 흉내 내는 대상입니다. 원본이 어떤 명령을 제공하고 만료와 메모리 한도를 어떻게 다루는지 알아야, 내가 만든 저장소가 어디까지 같고 어디서부터 다른지 말할 수 있습니다.

## 코드 예

```text
흉내 내는 명령            이번 구현에서
  SET key value            해시맵에 넣는다
  GET key                  해시맵에서 꺼낸다
  EXPIRE key seconds       만료 시각을 최소 힙에 넣는다
  INFO memory              used_memory 를 계산해 돌려준다

흉내 내지 않는 것
  여러 프로세스가 네트워크로 공유 / 디스크 저장 / 복제
  → 구현하지 않았다는 것을 보고에 적는 편이 정확하다
```

## 관련 용어

- `cache-eviction`
- `used-memory`
