# exit 1

## 한 줄 설명

일반적으로 command 실패를 알리는 non-zero 종료 상태.

## 쉽게 설명하면

명령이 끝나면서 남기는 숫자입니다. 0이면 성공, 0이 아니면 실패라는 약속입니다.

## 정확한 설명

프로세스가 종료할 때 부모에게 0~255의 값을 남긴다. 0이 성공이고 나머지는 실패를 뜻하며, 셸의 조건문과 논리 연산자가 이 값을 보고 다음 동작을 정한다. 값의 구체적 의미는 프로그램마다 다르게 정한다.

## 이 미션에서는 왜 필요한가

이 회차의 점검 결과를 표현하는 방법입니다. 화면에 "실패"라고 찍는 것만으로는 자동 실행 환경에서 아무도 읽지 않으므로, 종료 상태로 남겨야 다른 도구가 그 결과를 이어받을 수 있습니다.

## 코드 예

```bash
if ! curl -fsS --max-time 3 http://localhost/healthz >/dev/null; then
    echo "health check 실패" >&2
    exit 1                      # 화면 출력만으로는 아무도 못 읽는다
fi
exit 0

# 부르는 쪽에서 이어받는다
./check.sh && echo "정상" || echo "이상"
echo $?                         # 직전 명령의 종료 상태

# 파이프는 마지막 것만 보인다
false | true; echo $?           # 0 — 앞의 실패가 묻힌다
set -o pipefail; false | true; echo $?   # 1
```

## 주의할 점 / 경계 조건

파이프로 이은 명령의 종료 상태는 기본적으로 마지막 것만 보입니다. 중간이 실패해도 전체는 성공으로 보입니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

성공을 1, 실패를 0으로 두는 것이 자연스러워 보이지만 반대입니다. 0이 성공이고, 실패의 종류를 여러 숫자로 나눌 수 있게 되어 있습니다.
