# 인라인 스타일

## 한 줄 설명

HTML element의 style attribute에 CSS 선언을 직접 쓰는 방식.

## 쉽게 설명하면

`인라인 스타일`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

재사용과 media query 설계를 어렵게 하므로 예외적인 한 요소 스타일인지 판단한다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
인라인 스타일
```

## 관련 용어

- `css-cascade`
- `css-media-query`
