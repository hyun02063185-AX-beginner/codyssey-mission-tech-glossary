# sorting algorithm

## 한 줄 설명

여러 값을 비교 기준에 따라 일정한 순서로 재배치하는 알고리즘.

## 쉽게 설명하면

흩어진 카드를 번호나 이름 순으로 줄 세우는 방법이다.

## 정확한 설명

비교 기반 정렬은 비교 연산으로 순서를 결정하며, 안정성·추가 메모리·최악 시간 복잡도가 알고리즘마다 다르다.

## 실행 관점

정확성뿐 아니라 데이터 크기, 메모리, 갱신 빈도, 실패 조건을 함께 고려해야 한다.

## 사용 장면

점수 목록을 내림차순으로 정렬한 뒤 상위 N명을 표시할 수 있다.

## 경계와 오해

숫자를 문자열로 정렬하면 10이 2보다 앞서는 등 기대와 다른 결과가 날 수 있다.

## 동료평가 질문

직접 구현한 정렬에서 날짜가 같은 두 기록의 순서가 입력 순서와 같게 유지되는지, 그것이 왜 중요한지 설명할 수 있나요?

## 이 미션에서는 왜 필요한가

이 회차는 표준 정렬 함수를 쓰지 않고 직접 구현하도록 요구합니다. 그래서 어떤 방식을 골랐는지, 최악의 경우 몇 번 비교하는지, 같은 값의 순서가 유지되는지를 스스로 설명해야 합니다. 정렬을 쓸 줄 아는 것과 정렬이 무엇을 보장하는지 아는 것은 다릅니다.

## 코드 예

```text
                   평균        최악       추가 메모리   안정성
삽입 정렬          O(n²)      O(n²)      O(1)         있음
병합 정렬          O(n log n) O(n log n) O(n)         있음
퀵 정렬            O(n log n) O(n²)      O(log n)     없음

기록이 대체로 시간순으로 들어온다면 삽입 정렬이 실제로는 빠를 수 있다.
표의 숫자만 보고 고르면 이 경우를 놓친다.
```
