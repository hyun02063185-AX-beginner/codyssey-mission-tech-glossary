# IEEE 754

## 한 줄 설명

컴퓨터가 부동소수점 수를 저장하고 계산하는 표준.

## 쉽게 설명하면

소수를 제한된 비트로 근사해 담는 약속이다.

## 정확한 설명

부호·지수·가수로 값을 표현하므로 0.1 같은 10진 소수를 정확히 나타내지 못할 수 있다. NaN과 infinity도 정의한다.

## 언제 쓰나

금액 외의 측정값을 비교할 때 허용 오차 epsilon을 둔다.

## 기억할 경계

두 float를 `==`로 비교하는 것이 항상 안전하지 않다.

## 이 미션에서는 왜 필요한가

시뮬레이터가 계산한 값과 손으로 계산한 값이 미세하게 다를 때, 코드가 틀린 것인지 표현 방식의 한계인지 구분하는 근거입니다. 0.1을 세 번 더하면 0.3이 되지 않는 이유가 여기서 나오며, 그래서 결과 비교에 허용 오차가 필요해집니다.

## 코드 예

```python
print(0.1 + 0.2)             # 0.30000000000000004
print(0.1 + 0.2 == 0.3)      # False

# 비교할 때는 허용 오차를 둔다
import math
print(math.isclose(0.1 + 0.2, 0.3))          # True
print(math.isclose(0.1 + 0.2, 0.3, abs_tol=1e-9))

# 출력할 때 자리를 고정하면 사람이 보기에도 일정하다
print(f'{0.1 + 0.2:.4f}')    # 0.3000
```

## 관련 용어

- `floating-point`
- `epsilon`
