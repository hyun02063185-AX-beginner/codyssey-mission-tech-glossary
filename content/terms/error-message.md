# 에러 메시지

## 한 줄 설명

실패 원인과 사용자가 다음에 할 행동을 알려 주는 문구.

## 쉽게 설명하면

`에러 메시지`의 역할을 실제 화면과 요청 흐름에서 분리해 생각하면 됩니다.

## 정확한 설명

사용자가 고칠 정보를 주되 stack trace나 비밀값 같은 내부 정보는 노출하지 않는다.

## 이 미션에서는 왜 필요한가

현재 미션의 구현 요구에서 이 용어가 맡는 책임과 다른 단계의 경계를 확인합니다.

## 코드 예

```text
에러 메시지
```

## 관련 용어

- `input-validation`
- `email-validation`
