# 그룹

## 한 줄 설명

Linux에서 user 권한과 file 접근을 함께 관리하는 group.

## 쉽게 설명하면

여러 계정을 한 묶음으로 만들어 권한을 함께 주는 방법입니다. 사람마다 권한을 따로 주지 않아도 됩니다.

## 정확한 설명

계정은 기본 그룹 하나와 추가 그룹 여럿에 속할 수 있다. 파일 권한의 그룹 부분은 파일에 지정된 그룹에 대해서만 적용되며, 추가 그룹에 넣은 변경은 이미 로그인한 세션에는 반영되지 않아 다시 로그인해야 한다.

## 이 미션에서는 왜 필요한가

이 회차는 공용 그룹과 핵심 그룹을 나눠 구성하도록 요구합니다. 로그 파일을 어느 그룹이 읽을 수 있게 할지를 정하면, 계정이 늘어나도 파일 권한은 건드리지 않고 그룹에만 넣으면 됩니다.

## 코드 예

```bash
sudo groupadd agent-common
sudo usermod -aG agent-common agent-admin     # -a 를 빼면 기존 그룹이 날아간다

id agent-admin                # 현재 세션 기준 — 아직 안 보인다
groups agent-admin            # 설정 기준 — 여기에는 보인다

# 파일 쪽 설정
sudo chgrp agent-common /var/log/agent.log
sudo chmod 640 /var/log/agent.log    # 그룹은 읽기만
```

## 주의할 점 / 경계 조건

그룹에 추가한 뒤 바로 확인하면 반영되지 않은 것처럼 보입니다. 이미 열려 있는 세션에는 적용되지 않기 때문입니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

그룹에 넣으면 즉시 권한이 생긴다고 생각하기 쉽지만, 로그인할 때 정해진 그룹 목록이 그대로 유지됩니다. 다시 로그인해야 합니다.
