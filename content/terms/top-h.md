# top -H

## 한 줄 설명

thread별 CPU 사용을 보여 주도록 top을 실행하는 option.

## 쉽게 설명하면

실시간 화면을 프로세스가 아니라 작업 갈래 단위로 보여 주는 방식입니다. 프로그램 안에서 무엇이 도는지 보입니다.

## 정확한 설명

같은 실시간 화면을 스레드 단위로 전환한다. 프로세스 하나가 여러 코어를 쓰고 있을 때 그 부하가 스레드에 어떻게 나뉘어 있는지 보이므로, 고르게 퍼져 있는지 한 갈래에 몰려 있는지를 즉시 구분할 수 있다.

## 이 미션에서는 왜 필요한가

이 회차의 스레드 단위 관제입니다. 프로세스 화면에서 범인을 하나로 좁힌 다음 이 화면으로 넘어가는 순서인데, 한 스레드만 계속 100%라면 그 지점에 무한 반복이 있다는 강한 단서가 됩니다.

## 코드 예

```bash
# 1) 프로세스 단위로 범인을 좁힌다
top -bn2 -d1 | head -15

# 2) 그 프로세스의 스레드를 본다
top -H -p "$PID"

# 읽는 법
#   스레드 8개가 40% 씩      → 병렬 처리. 정상일 수 있다
#   스레드 1개만 100% 고정   → 그 갈래에서 빠져나오지 못하고 있다

# 3) 그 스레드가 무엇을 하는지
sudo cat /proc/$PID/task/$TID/stack 2>/dev/null
```

## 주의할 점 / 경계 조건

스레드가 많은 프로그램에서는 화면이 가득 차 읽기 어렵습니다. 조사할 프로세스를 지정해 좁히는 편이 낫습니다.

## 관련 용어

- `process`
- `linux`

## 흔한 오해

스레드 화면의 합이 프로세스 화면의 값과 정확히 맞아떨어질 것 같지만, 측정 시점이 달라 어긋날 수 있습니다. 대략적인 분포를 보는 용도입니다.
