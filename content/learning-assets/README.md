## M03 MAC sliding window

| 파일 | 역할 | 서비스 실행 여부 |
| --- | --- | --- |
| `mac_sliding_window_demo.original.html` | 사용자가 전달한 역사적 원본 보존본 | 아니오 |
| `../../public/learning-assets/mac_sliding_window_demo.standalone.html` | 오프라인 실행형 Visual Learning Asset | 예, `/learning-assets/mac-sliding-window` iframe 안에서만 |

원본은 SHA-256 `b348416f03437fd08390ff976a9875f72bd1469da39c725593311e21c9722b57`로 보존한다. 내용을 수정하지 않는다.

Standalone은 원본의 `pattern`/`filter` 데이터와 `computeMac`, `preview`, `commitAndAdvance` 함수, 0.3초 전환 및 650ms 자동 재생 로직을 유지한다. 서비스 맥락에 맞는 설명 문구만 독립적으로 수정할 수 있다.
