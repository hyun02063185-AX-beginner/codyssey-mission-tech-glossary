## 5단계 상세의 문구와 시각 순서

1. **요청 · 로컬 Python → 외부 AI API**

   HTTPS POST로 보냅니다. 환경변수에서 읽은 API 키는 인증 헤더에 사용합니다. JSON 본문에는 모델 ID와 메시지가 들어갑니다. `system`은 초안 작성 규칙이고, `user`는 4단계에서 검사한 Git 문맥입니다.
2. **응답 · 외부 AI API → 로컬 Python**

   응답 JSON을 Python이 읽어 `choices[0].message.content`의 초안 텍스트를 꺼냅니다. 꺼낸 글은 6단계의 검증으로 들어갑니다.
3. **근거 표시**

   모델 실행 위치는 미확인입니다. 요청 모양은 재현 기록을, 결과 예문은 2026년 10월 20일 터미널 출력 발췌를 사용합니다. 원본 응답 JSON은 미확보입니다. [요청 재현](assets/evidence/demo-request.json) · [실제 터미널 출력](assets/evidence/real-output-2026-10-20.txt)

5단계의 소스 링크는 `AIClient.generate()`를 앞에 둡니다. “작성 규칙”을 자세히 보려는 학습자는 `prompts.py`와 학습가이드 02장으로 이어 갑니다. 초안 텍스트를 읽는 과정과 검증·후처리 과정의 경계에서 S3-2와 S4-1을 연결합니다.

로컬 Git 명령 자체의 실패는 2단계 상세와 S2-2에서 설명합니다. 성공했지만 변경이 없는 3단계의 정상 종료와 구별합니다.

## 강의 순서와 복습 동선

- **실행 순서**는 명령 입력이 첫 단계입니다. **강의 순서**는 Scene 1에서 활용 목적과 설명에 필요한 정보를 먼저 소개하고, Scene 2에서 명령 입력과 Git 수집부터 따라갑니다. 이 때문에 S1-2가 실행 단계 2와 연결되고, 뒤의 S2-1이 실행 단계 1과 연결됩니다.
- 강의에서는 기존 **순서대로 보기**로 실행 순서를 한 번 확인하고, 5단계의 S3-2에서 요청과 응답을 각각 짚습니다. 복습에서는 **자유 탐색**으로 5단계나 원하는 단계에 바로 들어갑니다.
- 기존 슬라이드 ID와 주소를 사용합니다. 슬라이드에서 브라우저 뒤로 가기로 선택한 단계에 돌아오고, 미리보기의 **전체 흐름으로**로 선택을 해제하는 기존 시안의 동선을 이어 씁니다.
- P 레이어에는 현재 슬라이드에 해당하는 원고의 **화면 해설**과 **더 읽기** 링크를 사용합니다. 발표자 노트와 학습자 접힘 설명은 각각 기존 위치를 사용합니다. P 키와 터치로 열 수 있는 진입점은 원고 승인 후 웹 통합에서 검토합니다.
