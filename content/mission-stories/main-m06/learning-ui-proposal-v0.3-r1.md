## 3. 학습 동선

### 3-1. 화면 ↔ Lab 왕복 (U4 · U5)

```text
 [S1-2 화면]  ──① 칩 클릭──▶  [Lab 03 · A 핵심 실습]  (복귀 띠: ← S1-2)
                                   │ 실행 → 관찰 → 해설 펼침 → 도식 01 (add 전/후 전환)
                                   ▼
                              [돌아가기 카드]  복귀 화면 S1-2 · 다시 볼 곳: F3 ` M`과 “--cached 이번에는 없다”
                                   │
 [S1-2 화면]  ◀──② 클릭──────────┘
   그림 위 안내 한 줄: “Lab 03 결과와 맞춰 볼 곳 — ` M`의 위치 · --cached 이번에는 없다”
   확인 질문: “Python이 두 종류의 diff를 수집하는 이유는?”   (예시 답 접힘)
   다음 순환(선택): Lab 03 B-1 · S3-1로
```

- 왕복은 **두 번의 클릭**(칩 → 돌아가기)으로 끝나야 합니다(1280×720 강의 화면 포함).
- 복귀한 화면의 안내 한 줄과 확인 질문은 **그 왕복으로 돌아왔을 때만** 보이고, 화면을 넘기거나 닫기 단추를 누르면 사라집니다. 일반 진입에서는 보이지 않습니다(8화면 흐름을 바꾸지 않음).
- 안내 한 줄은 P 패널과 겹치지 않는 그림 위쪽에 둡니다.

### 3-2. “다시 볼 그림 부분”을 보여 주는 방법

| 방식 | 내용 | 제안 |
| --- | --- | --- |
| 글자 안내 | 안내 한 줄에 그림 요소의 이름을 그대로 적음(예: “F6 ‘검사를 마친 글’의 글자 수”) | **기본** — 구현 비용 낮음, 그림 변경 없음 |
| 그림 강조 | 그림 SVG의 해당 요소(`data-topic`)에 강조 테두리를 잠시 표시 | 선택 — Owner 결정 O10. 기존 SVG에 `data-topic`이 있는 요소(F6 `prepared-context`, F7 `response-status`·`response-example` 등)부터 가능 |

### 3-3. 세 가지 진입 경로 (v0.3 §6 유지)

| 학습자 | 시작 | 이동 |
| --- | --- | --- |
| 설명 중심 | 인트로 → S1-1 … | 각 화면의 칩 → Lab A → 돌아가기 → 같은 화면 → 다음 화면 |
| 실습 중심 | Lab 목차 → Lab 01 | Lab A 끝의 돌아가기 → 화면 → (다음 Lab 링크) |
| 미션 완료 | 결과로 찾아보기 (출력 한 줄) | 해당 Lab의 접힌 해설만 펼침 → 돌아가기 → 화면 → S4-2 마무리 빈칸 |

### 3-4. 주소 (제안 — 공개 route는 Owner Gate)

| 이동 | 주소 예 | 검증 |

## 4. PC와 모바일

**PC (교육장 · 강의)**

- 약 640px 폭에서 Lab 본문이 한 단으로 읽혀야 합니다(브라우저와 터미널 좌우 분할). 표는 가로 스크롤 허용.
- 1280×720 강의 화면에서 왕복 2클릭. 강사가 시연할 때 해설이 미리 펼쳐지지 않음.
- 복귀 띠·안내 한 줄과 P 패널이 동시에 그림을 가리지 않음.

**모바일 (360 · 390px)**

- 기본 보기는 **실행 기록과 도식 복습**: 출발 질문 → (명령은 접힌 “PC에서 실습” 상자) → 실행 기록(접힘 해제 가능) → 도식 → 돌아가기 카드.
- 비교 표(Lab 03 전후, 결과로 찾아보기)는 카드형으로 쌓기. 도식 상태 전환 단추는 도식 위에 가로로.
- 글자 크기는 줄이지 않음. 명령 블록은 가로 스크롤.

**공통 접근성** 접힘·상태 전환은 실제 버튼 요소(키보드·스크린 리더). 배지·색 구분에 글자 라벨. 라이트·다크 대비 확인([정책 §5](../../../docs/mission-guides/learning-operation-policy.md)).

## 5. 강의 운영과의 연결

- 대면 강의 끝 “안내된 첫 실습”: 강사가 S1-2 화면에서 칩으로 Lab 03에 들어가 함께 실행하고, 돌아가기로 S1-2에 복귀해 확인 질문을 묻습니다(K2). 이것이 학습자에게 왕복의 첫 시범입니다.
- 키 배부 시점에 Lab 07 머리의 비용 안내와 실습 정리 단계를 강사가 함께 읽습니다.

## 6. 데이터와 개인정보

| 대상 | 처리 |
| --- | --- |
| API 키 | 입력칸을 만들지 않음. 화면 어디에도 키를 받거나 표시하지 않음 |
| 학습자의 실행 결과·출력 | 붙여넣기 칸을 만들지 않음(키가 섞인 출력을 붙여넣을 위험) |
| 자유 입력(예측·확인 질문의 답) | 입력칸을 만들지 않음. 질문만 보이고 답은 학습자 노트에 |
| 관찰 목록 체크·펼친 상태 | **기본: 저장하지 않음**(새로고침하면 초기화). `localStorage` 저장은 Owner 결정 O9 — 허용하더라도 기기 안에만, 공용 PC용 “기록 지우기” 단추 필수 |
| 사용 기록 수집 | 학습자 입력·결과를 수집하지 않음. 페이지 방문 통계 같은 운영 지표는 기존 사이트 정책을 따르며 이 작업에서 새로 추가하지 않음 |
