## Lab 03 · git add 전후 관찰 (출력 원문은 지시서에 표로만 기록됨)
| 항목           | add 이전          | add 이후          |

| diff           | 변경 내용 출력    | 출력 없음         |

## Lab 07 · API 오류와 해결 (요약 기록. 응답 원문·키 값은 기록하지 않음)
- 기존 키 길이 64자 → HTTP 400, JSON이 아닌 HTML 오류 페이지
- Python 직접 호출에서도 같은 오류, curl 최소 요청에서도 같은 오류
- 키 재입력 후 길이 56자 → HTTP 200, JSON 응답 성공
- 잘못된 입력에 어떤 문자가 들어 있었는지는 확인하지 못함
- 56자는 당시 사용한 키의 사례일 뿐, API 키 길이의 일반 규칙이 아님
- B3-2 프로그램(main.py)이 400 상황에서 출력한 문구, curl 200 응답 JSON 원문은 지시서에 포함되지 않음
