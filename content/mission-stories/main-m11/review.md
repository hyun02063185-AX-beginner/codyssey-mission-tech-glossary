## 5. 학습가이드로 넘긴 내용

스토리는 원리의 흐름만 보여 주고 아래는 다루지 않는다. 각 화면에서 해당 장으로 연결한다.

- SQL 문법(`SELECT … FROM … WHERE`, ON 조건 작성법) → 5·6장
- 제약조건과 무결성(NOT NULL · UNIQUE · CHECK, 150점 거절, `PRAGMA foreign_keys = ON`) → 4장
- N:M과 연결 표의 자세한 설명 → 3장 보조 V03
- 집계·HAVING, 서브쿼리·인덱스, UPDATE·DELETE 안전 수칙 → 7~9장
- SQLite가 Mac에 있는 이유, 실행 방법 2가지, JPA/ORM → 1·5·10장 (노트 6·7장)

## 7. 남은 일과 미검증

- **미검증:** 실제 웹 렌더러 통합(인라인 SVG 상태 전환, 전환 애니메이션, `PresentationThemeSelector`의 Light 전환), 실기기, 강의실 프로젝터 대비.
- **확인 필요:** HTML 카드 3개(S03-1·S04-1·S04-2)의 최종 시각 디자인은 렌더러에서 정한다. 미리보기의 카드는 배치 참고용이다.
- **확인 필요:** 학습가이드 V02(부모 → 자식 화살표)와 이 스토리의 ERD 기호(까마귀발)가 다르다. 두 자료를 오가는 학습자를 위해 독립 검토에서 표기 통일 여부를 판단해 달라.
- **미구현:** B6-1 개념지도가 없어 스토리 → 지도 연결은 없다.
- 이번 작업은 콘텐츠와 그림만 만들었다. 웹 코드·라우트·기존 B6-1 가이드·용어 데이터·B2-1/B3-1은 바꾸지 않았다.
