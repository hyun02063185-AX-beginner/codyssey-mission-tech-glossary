# Curated Data

중복 제거, 표준명 정리, 분야/유형 정규화, 출처 상태 검수까지 완료한 데이터를 저장합니다.

초기 목표 파일:

- `glossary-master-v0.1.yaml` 또는 `glossary-master-v0.1.json`
- `mission-term-map-v0.1.yaml`

현재 산출물:

- `glossary-master-v0.1.yaml` — canonical term과 미션별 출처 관계
- `mission-term-map-v0.1.yaml` — 미션 중심 탐색용 연결 맵
- `glossary-stats.md` — Master DB 기준 자동 집계
- `normalization-review.md` — 사람 판단이 필요한 표준화 결정
- `validation-report.md` — DB·콘텐츠·웹툰 Pilot 파일 검증 결과
