# B3-1 네트워크 보강자료 — 기술용어사전 운영 채팅 인계

기준일: 2026-10-28 KST

## 인계 목적

B3-1 미션 채팅에서 정리한 네트워크 기초와 사용자가 긍정 확인한 ‘패킷의 여행’ 애니메이션을 기술용어사전 운영 작업으로 이어간다. 이 묶음은 보강 기획과 동작 시안이며, 저장소 반영·운영 배포 완료 자료는 아니다.

대상 저장소: https://github.com/hyun02063185-AX-beginner/codyssey-mission-tech-glossary

평가 자료 저장소 `Codyssey_B3-1` 및 실제 AWS 설정은 이번 보강 대상이 아니다. 공식 미션 ID는 B3-1이다. 기존 저장소의 내부 경로·ID를 전역 치환하지 않는다.

## 사용자 의도와 확인된 방향

- 기술 기반이 없는 입문자가 고등학생 수준의 설명으로 네트워크를 이해하게 한다.
- 기존 기업 네트워크 전체 구성도를 보면서 외부 접속, 회사 경계, 방화벽, DMZ와 내부 네트워크의 역할을 연결해 배운다.
- 패킷·IP·공인/사설 IP·라우팅·NAT·포트·프로토콜을 보강하고 관련 용어와 개념지도도 함께 연결한다.
- 텍스트와 표만으로 정리하는 데서 더 나아가, 패킷이 이동하고 주소·경로표가 바뀌는 장면을 직접 보여준다.
- 사용자는 이번 시안에 대해 ‘단계별로 누군가에게 설명하기 좋고 가시적으로 보인다’고 확인했다. 자동 재생보다도 멈추고 한 단계씩 설명할 수 있다는 점이 핵심 가치다.
- 이 확인은 동작·학습 방향에 대한 긍정 확인이다. 통합된 실제 페이지의 최종 승인이나 배포 승인을 대신하지 않는다.

## 시안의 네트워크와 26단계

1. DNS 조회: PC → 공유기 → R1 → R2 → DNS 서버 (5단계)
2. DNS 응답: DNS 서버 → R2 → R1 → 공유기 → PC (5단계)
3. 웹 요청: PC → 공유기 → R1 → R2 → R4 → 회사 경계 라우터 → 방화벽/NAT → DMZ 웹 서버 (8단계)
4. 웹 응답: DMZ 웹 서버 → 방화벽/NAT → 회사 경계 라우터 → R4 → R3 → R1 → 공유기 → PC (8단계)

전체 연결망은 계속 보인다. 현재 위치와 이미 지난 경로를 표시하며, 아래에 해당 장비 처리 후의 출발지·목적지 IP:포트, 통신 종류, 내용과 선택한 경로표/처리 기준을 보여준다. 재생·일시정지·한 단계 진행·완료 후 재시작을 지원한다.

## 설명용 주소

| 대상 | 값 |
|---|---|
| PC 사설 IP | `192.168.0.20` |
| 방문자 측 공유기 공인 IP | `203.0.113.10` |
| DNS 서버 | `192.0.2.53` |
| 접속 도메인 | `example.com` |
| 웹 서비스 공인 IP | `198.51.100.80` |
| DMZ 웹 서버 사설 IP | `10.20.10.20` |

공인 IP 표기는 문서용 예시 주소다. 실제 B3-1 AWS 리소스나 실제 example.com의 DNS 결과를 재현한 것이 아니다. 실제 패킷 캡처나 통신 측정 결과로 소개하지 않는다.

## 반드시 유지할 개념 구분

### DNS 조회와 웹 요청

PC가 설정된 DNS 서버에 도메인의 A 레코드를 조회한다. DNS 응답을 받은 PC가 확인한 IP로 별도의 웹 접속을 한다. DNS가 웹 요청을 대신 전달하거나, 라우터가 웹 패킷을 임의로 DNS 조회로 전환하는 그림을 만들지 않는다. DNS는 전체 URL의 경로가 아니라 도메인 이름에 대응하는 정보를 조회한다. 시안은 DNS 캐시에 답이 있는 상황이며 루트/TLD/권한 DNS로의 추가 조회는 생략했다.

### 라우팅·NAT·방화벽

- 라우팅: 목적지 IP와 경로표를 기준으로 다음 전달 방향을 선택한다. 모든 라우터가 전체 경로를 한 번에 정하는 것으로 표현하지 않는다.
- NAT: 출발지/목적지 주소와 필요 시 포트를 변환한다. 라우팅과 별개 기능이다.
- 방화벽: 정책에 따라 통신을 허용·차단한다. NAT와 별개 기능이며 이 예시에서는 같은 방화벽 장비가 NAT도 수행한다.
- 장비와 기능을 구분한다. 일반 공유기에는 라우팅·NAT·방화벽 등 여러 기능이 함께 있을 수 있다.

### 왕복 경로와 상태

웹 요청은 인터넷의 R2를 거치고 응답은 R3를 거친다. 응답의 목적지 경로가 요청 경로의 단순 역순으로 고정되는 것은 아니다. 동시에 이 예시의 요청·응답은 같은 NAT와 방화벽을 모두 거친다. 아무 경로로 돌아와도 되는 것으로 일반화하지 않고, NAT 매핑과 상태 추적 방화벽의 연결 상태가 유지되어야 한다는 조건을 설명한다. 같은 상태를 공유하는 별도 장비 구성 등은 이번 입문 범위에서 확대하지 않는다.

### 패킷·프로토콜·포트

IP 헤더의 출발지/목적지 IP와 TCP·UDP 헤더의 포트를 구분한다. 모든 IP 패킷에 포트가 있다고 표현하지 않는다. IP·TCP/UDP·HTTP/SSH는 역할이 다른 프로토콜이며 함께 사용될 수 있다. 포트와 서비스의 연결은 대표적인 기본 사용 관례이고 포트가 서비스 종류를 강제하는 것은 아니다.

### 단순화 범위

전통적인 UDP DNS와 TCP HTTP 예시다. TCP 연결 설정, TLS, 전체 페이지의 여러 요청·패킷, ARP, 실제 라우팅 프로토콜의 경로 학습은 생략했다. HTTP 데이터 통신을 대표 패킷으로 보여준다. 한 패킷에 전체 페이지가 항상 들어간다고 설명하지 않는다.

## 용어·개념지도 보강 후보

네트워크, 인터넷, 패킷, IP 주소, 공인 IP, 사설 IP, 라우터, 라우팅, 라우팅 테이블, NAT, 방화벽, DMZ, 포트, 프로토콜, TCP, UDP, HTTP, HTTPS, DNS, SSH 및 AWS 대응 개념을 검토한다. 후보는 신규 용어 확정 목록이 아니다. 최신 저장소의 기존 항목·상세 원고·연결 관계를 먼저 확인해 중복을 피한다.

관계 예시:

- 패킷 ↔ 출발지·목적지 IP
- 라우터 ↔ 라우팅 테이블 ↔ 다음 전달 경로
- TCP·UDP ↔ 포트 ↔ 통신할 서비스
- HTTP·SSH ↔ TCP 이용
- 방화벽 ↔ 출발지·목적지·프로토콜·포트·연결 상태
- NAT ↔ IP·포트 변환
- 일반 네트워크 ↔ AWS의 경로·접근 통제·주소 변환 역할 비교

‘용어를 모두 나열한 지도’ 대신, 각 개념이 이 통신에서 무엇을 하는지 관계를 표현한다. 기존 기업망 설명과 AWS 비교 자료를 연결한다. AWS SG를 NAT 기능으로 묘사하거나 Route Table을 별도 물리 장비처럼 직렬 배치하지 않는다.

## 운영 채팅방에서 이어갈 순서

1. 해당 운영 채팅방의 현재 작업 순서·역할 분담·승인 절차를 먼저 확인한다. 이 묶음에서 미확인된 최신 브랜치나 담당 모델을 지정하지 않는다.
2. 최신 저장소와 적용되는 AGENTS.md를 확인하고 B3-1 가이드·관련 용어·개념지도·공통 UI가 현재 어떻게 연결되는지 조사한다.
3. 원본 동작을 확인하고, 기존 가이드에 어느 장면으로 넣을지와 필요한 용어/지도 변경 범위를 제안한다. 기존 원고·정적 도식을 보존하고, 애니메이션을 표로 대체하지 않는다.
4. 가이드·용어·개념지도 연결을 한 묶음으로 설계하되 입문 범위를 유지한다. 코드 세부 리뷰나 OSI 전체 강의로 확대하지 않는다.
5. 운영 채팅방의 합의된 순서에 따라 구현·검증·Owner 검토를 진행한다. 이 인계 자체를 main 병합·배포의 최종 승인으로 사용하지 않는다.

넓은 화면에서는 전체 네트워크 공간을 활용하고, 모바일에서는 글자를 과도하게 축소하지 않는 배치·확대 방식을 검토한다. 시안 원본은 680px 미만에서 세로 배치로 바꾸며, 반응형이란 복잡한 구성 자체를 없앤다는 뜻이 아니다.

## 검수에서 확인할 동작

- 자동 재생과 한 단계 설명이 모두 가능하고 일시정지·계속 진행·재시작이 정상 동작한다.
- 단계와 실제 패킷 위치, 경로 선택, IP:포트 정보가 일치한다.
- NAT 직전·직후의 주소 변화를 정확히 확인할 수 있다.
- DNS 조회와 웹 요청이 별도 통신으로 읽힌다.
- 요청·응답의 인터넷 경로 차이와 NAT·방화벽 상태 유지 조건이 함께 전달된다.
- 넓은 화면과 모바일에서 주소·장비 이름·경로선이 가려지거나 읽기 어려워지지 않는다.
- 감속 동작 설정, 키보드 조작, 접근 가능한 레이블을 확인한다.
- 실제 브라우저와 배포 빌드에서 기존 가이드·용어·개념지도 링크까지 확인한다.
