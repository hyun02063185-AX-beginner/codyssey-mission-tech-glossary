# 시안 검증 범위

기준일: 2026-10-28 KST

## 확인한 것

- HTML 내 JavaScript 구문 검사 통과.
- JavaScript DOM 모사 환경에서 26단계 진행, DNS/웹 단계 전환, 출발지·목적지 주소/포트 변경을 확인.
- R4의 응답 경로가 R3로 선택되는 것과 최종 PC 주소로의 복원을 확인.
- 같은 환경에서 재생·일시정지·한 단계 진행·재시작 상태 처리를 확인.
- 폭 288/320/358/390/600/679/680/736/1024px의 SVG 좌표에서 장비 박스의 뷰박스 이탈·서로 겹침이 없는지 확인.
- SVG 래스터 미리보기를 생성해 전체 배치를 검토.
- 사용자는 채팅에서 시안을 보고 단계별 설명에 유용하다고 긍정 확인.
- 원본은 변경하지 않고 제공된 내보내기 절차로 standalone HTML을 생성.

## 미검증·한계

- 실행 환경에 브라우저 엔진이 준비되지 않았고 다운로드도 실패해 Playwright 기반 실제 브라우저 검증은 수행하지 못함. DOM 모사 검사를 실제 브라우저 테스트로 표현하지 않는다.
- 로컬 SVG 래스터 미리보기는 한글 폰트가 충분하지 않아 한글 가독성의 최종 승인 근거로 사용하지 않음.
- 실제 휴대전화, 다크/라이트별 전체 화면, 화면 낭독기, 호스트 외 standalone의 실제 브라우저 재생 검증은 미완료.
- 내보낸 HTML은 렌더러의 스타일·실행 래퍼를 포함한다. React 프로젝트 통합 시 원본의 핵심 동작을 추출하고 최신 공통 UI와 결합해야 함.
- 기술용어사전 저장소에 소스를 반영하거나 GitHub Pages/AWS에 배포하지 않음.
- 실제 네트워크 패킷 캡처·실제 DNS 질의·AWS 구성 재현이 아닌 교육용 시뮬레이션임.

운영 페이지 반영 전에 실제 브라우저·모바일·빌드 결과·회귀 동작을 검증한다.
