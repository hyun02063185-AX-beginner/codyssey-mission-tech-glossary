## 정확성 경계

- JSONL 형식 자체에 메모리 절약 효과를 부여하지 않는다. Generator를 써도 전부 리스트에 모으면 메모리가 필요하다.
- Type Hint·형 변환·실제 값 검증을 같은 기능으로 설명하지 않는다.
- Decorator가 모든 예외를 처리하거나 원래 기능을 항상 실행한다고 설명하지 않는다. 감싸는 그림은 그 방식의 함수 Decorator 예시다.
- 역할별 모듈 구분은 설계 예시다. 파일은 합치거나 다르게 나눌 수 있고 Python이 네 역할의 파일명을 요구하지 않는다.
- `__init__.py`는 일반 패키지 초기화 파일이다. 모든 패키지에 반드시 존재한다고 설명하지 않는다. `__init__()` 문법 수업으로 연결하지 않는다.
- 기존 원고의 공식 목표 문구는 독립 원문 대조 전이라는 상태를 유지한다. 클래스 선수 학습을 마쳤다는 사실로 공식 클래스 구조화 요구의 구현·검증을 대체하지 않는다.

## 물리적 보호 범위

이번 추적 변경은 `drafts/b2-1-story-map/v3/`의 새 파일뿐이다. v2의 9학습단위 무결성 검사, Manifest, React, Owner Preview, 운영 데이터·공개 URL·package/lock·배포 설정은 변경하지 않는다. v3는 Manifest에 등록하지 않는다. `npm run b21:preview`는 v2용이고 새 HTML은 별도 파일로 연다.
