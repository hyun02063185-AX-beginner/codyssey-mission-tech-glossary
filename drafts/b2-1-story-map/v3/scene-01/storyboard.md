# Scene 01 v3.1 — 버튼과 명령에서 네 블록으로

2026-10-24 · 질문: **명령 한 줄은 누구에게 어떤 일을 부탁하는 말일까?**

목표는 GUI/CLI 차이와 실행 도구·실행할 프로그램·할 일·조건을 읽고 argparse의 해석 역할을 말하는 것이다. 가상 todo 예시이며 실제 명령 실행 화면이 아니다. 전체 4~5분 계획, **A2 + B5 = 7단계**.

## A — 같은 요청의 두 방법 (1~2/7, 약 1분)

큰 비교 그림: 왼쪽 GUI의 '목록 보기 · 최대 5개', 오른쪽 CLI의 `python -m todo list --limit 5`. 카드 자체가 실제 강조 버튼이다. 가짜 기록 목록이나 실행 결과는 만들지 않는다.

| 단계 | 가리킬 요소 | 현재 한 문장 |
| --- | --- | --- |
| 1/7 | GUI 카드 | GUI는 화면의 버튼과 메뉴를 눌러 프로그램에 일을 부탁하는 방식입니다. |
| 2/7 | CLI 카드 | CLI는 명령을 문자로 입력해 같은 일을 부탁하는 방식입니다. |

강사 첫 질문: “목록을 최대 다섯 개 보고 싶다면 화면에서 무엇을 누를까요?”

꼭 설명할 세 문장: GUI는 버튼/메뉴로 요청한다. CLI는 문자로 요청한다. 같은 요청을 네 블록으로 나누어 읽는다. 학생 화면에는 이 세 문장을 고정 노출하지 않는다.

혼동/예외(강사 노트): GUI는 가상 화면이고 선택은 비교 강조만 바꾼다. CLI와 GUI는 반드시 서로 다른 프로그램이라는 뜻이 아니다.

연결: “다음 단계를 눌러 이 명령이 어떤 말로 이루어졌는지 봅시다.” A 끝에는 확인 질문·정리를 띄우지 않는다.

## B — 명령 네 블록과 마지막 해석 (3~7/7, 약 3~4분)

기존 큰 네 블록을 유지한다. 명칭은 **실행 도구 / 실행할 프로그램 / 할 일 / 조건**이다. Python 인터프리터·-m 옵션·하위 명령·옵션/값은 작은 보조 라벨로 둔다.

| 단계 | 강조 | 현재 한 문장 |
| --- | --- | --- |
| 3/7 | python | python은 Python 코드를 실행하는 도구를 시작합니다. |
| 4/7 | -m todo | -m todo는 Python에게 todo라는 이름의 실행 대상을 찾아 시작하라고 요청합니다. |
| 5/7 | list | list는 todo에게 목록을 보여 달라고 요청하는 말입니다. |
| 6/7 | --limit 5 | --limit 5는 목록을 최대 다섯 개 보여 달라는 조건입니다. |
| 7/7 | 할 일·조건 묶음과 argparse | argparse는 프로그램이 정한 규칙으로 할 일과 조건을 해석합니다. |

argparse는 별도 화면이 아니다. 7/7에서만 같은 명령 아래에 해석 표식을 보여 준다. 중간 단계는 선택한 블록 설명 한 문장만, 마지막은 해석 대상 두 블록을 함께 강조한다.

강사 첫 질문: “이 명령에서 도구, 프로그램, 할 일, 조건을 하나씩 가리켜 볼까요?”

꼭 설명할 세 문장: 도구/대상은 python과 -m todo다. 할 일/조건은 list와 --limit 5다. argparse는 프로그램의 규칙에 따라 할 일/조건을 해석한다.

강사 노트: -m은 Python 옵션이다. --limit는 옵션, 5는 값이다. 모든 옵션에 값이 필요한 것은 아니다. 숫자 변환은 설정된 규칙에 따른다. argparse가 모든 CLI의 필수 도구이거나 데이터 처리를 대신하는 것은 아니다. 모든 -m 대상이 패키지인 것도 아니다. 명령 이름은 환경마다 다를 수 있다. 함수/API 목록이나 내부 호출을 읽지 않는다.

## 마지막 이해 확인과 정리 — 7/7에서만

- **기본:** 이 명령에서 할 일과 조건은 어느 부분인가요? → list / --limit 5
- **새 상황 적용:** 최대 3개를 보려면 어느 블록을 어떻게 바꿀까요? → 조건을 --limit 3으로
- **정리:** 명령은 실행 도구·실행할 프로그램·할 일·조건으로 읽고, argparse가 할 일과 조건을 해석합니다.

답은 마지막 단계의 선택 보충 안에 접어 둔다. 중간에 돌아가면 확인·정리·답을 숨긴다. 적용 질문은 기존 예제도 지원하는 list --limit 값 변경이다. 미지원 하위 명령을 새로 넣을 때는 가상 확장 예시임을 명확히 표시해야 한다.
