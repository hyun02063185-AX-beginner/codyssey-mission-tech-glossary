# B2-1 Story v3.7 — Scene 01~08 강의 미리보기 (Scene 05·06 교수 순서 재구성)

2026-10-24 · v3.6 승인본 `9e884d9` 위에서 Scene 05·06을 입문자 교수 순서로 다시 짬 · **Scene 05·06 재구성 Owner 검토 대기**

이것은 독립 강의 미리보기의 콘텐츠 완성이며, React 통합이나 공식 서비스 배포가 아니다.

v3 교육 원고([Scene 01](../scene-01/storyboard.md), [02](../scene-02/storyboard.md), [03](../scene-03/storyboard.md), [04](../scene-04/storyboard.md), [05](../scene-05/storyboard.md), [06](../scene-06/storyboard.md), [07](../scene-07/storyboard.md), [08](../scene-08/storyboard.md))를 v3.3에서 승인된 디자인과 조작 체계로 보여 주는 **대면 강의용 화면**이다. 독립 HTML 한 파일이며 React·운영 서비스에 등록하지 않았다.

Scene 01~04·07의 원고·그림·순서·조작·주소는 v3.6과 같다. Scene 08은 단계와 주소는 같고, Scene 05의 Iterable·Iterator를 반영해 영역 05 이름·뜻, ‘종류’ 예(R23·R41), 확인 질문 1개, 복습 주소를 바꿨다. 자동 회귀 검사로 확인한다([qa.md](qa.md)).

**주소 규칙 (v3.7):** 대부분의 장면은 `#장면-번호`(예: `#7-3`)이다. 교수 순서를 다시 짠 Scene 05·06은 단계 ID 주소(`#5-pause`, `#6-rebind`)를 쓴다. v3.6의 숫자 주소(`#5-1`~`#5-16`, `#6-1`~`#6-13`)로 열면 의미가 대응하는 새 단계로 자동 이동한다(대응표: [Scene 05 원고 1절](../scene-05/storyboard.md), [Scene 06 원고 1절](../scene-06/storyboard.md)).

## 여는 방법

서버·인터넷·Python이 필요 없다. 외부 글꼴·스크립트 요청도 없다.

**Windows** (저장소 루트, PowerShell):

```powershell
Start-Process .\drafts\b2-1-story-map\v3\teaching-preview\index.html
```

**Mac** (저장소 루트, 터미널):

```bash
open drafts/b2-1-story-map/v3/teaching-preview/index.html
```

특정 단계로 바로 열려면 주소 끝에 `#3-1`(Scene 03 첫 단계)처럼 붙인다. 탐색기/Finder에서 더블클릭해도 된다. 발표 화면은 1280×720 이상 또는 전체 화면(F11 / ⌃⌘F).

**Scene 05 — Python은 여러 값을 어떻게 하나씩 꺼내고, Generator는 그 과정에서 어떤 역할을 할까? (22단계, v3.7 재구성)**

**Scene 06 — 함수를 그대로 사용하면서 앞뒤에 새로운 일을 붙일 수 있을까? (18단계, v3.7 재구성)**
