# B2-1 Story v3.3 — Scene 01·02 강의 미리보기

2026-10-24 · 시작 `e358f17a8a2a6a814c90b8254a9d4d915396585c` · **Owner 검토 대기**

v3.2 교육 원고([Scene 01](../scene-01/storyboard.md), [Scene 02](../scene-02/storyboard.md))를 디자인 탐색 추천안(A 프레젠테이션형 위계 + B 역할 아이콘)으로 만든 **대면 강의용 전체 화면**이다. 독립 HTML 한 파일이며 React·운영 서비스에 등록하지 않았다. 기존 v2·v3 자료는 바꾸지 않았다.

## 여는 방법

서버·인터넷·Python이 필요 없다. 외부 글꼴·스크립트 요청도 없다.

**Windows** (저장소 루트, PowerShell):

```powershell
Start-Process .\drafts\b2-1-story-map\v3\teaching-preview\index.html
```

**Mac** (저장소 루트, 터미널):

```bash
open drafts/b2-1-story-map/v3/teaching-preview/index.html
```

탐색기/Finder에서 더블클릭해도 된다. 발표 화면은 브라우저를 1280×720 이상 또는 전체 화면(F11 / ⌃⌘F)으로 맞춘다.

## 조작

| 하고 싶은 것 | 방법 |
| --- | --- |
| 다음·이전 설명 | `→`/`←` (또는 `PageDown`/`PageUp`, 프레젠터 리모컨), 아래 `다음 ›`·`‹ 이전` |
| 장면 처음·끝 | `Home`/`End` |
| 그림의 특정 영역 설명 | 명령의 부분, 역할, 파일, 상황 카드, `todo/` 폴더 이름을 클릭 (Tab → Enter/Space) |
| 전체 구조로 돌아가기 | 선택된 영역을 다시 클릭하거나 `전체 구조` |
| 현재 위치 | 아래 `Scene 01 · 4 / 13 · 실행 도구 python`과 진행 막대 |
| 강사 대본·노트·심화 | `강사 노트` — 이 단계 대본, (확인 단계) 기대 답과 흔한 오답, 정확성 경계, 선택형 심화 |
| 전체 개념 한눈에 / 장면 이동 | `목차` — 두 장면 30단계의 제목과 화면 한 문장. 누르면 그 단계로 이동 |
| 패널 닫기 | `Esc` 또는 `닫기` |
| 확인 질문의 답 | 확인·적용 단계의 `답 보기` (학습자가 먼저 답한 뒤) |

Scene 01 마지막 단계에서 `→` 또는 `Scene 02로 ›`를 누르면 Scene 02로 이어진다. 현재 위치는 주소 끝(`#1-4`)에 남아서 새로 고침해도 같은 단계로 돌아온다.

강사 노트는 화면 오른쪽(모바일은 아래)에 열리므로, 프로젝터와 강사 화면을 나누지 않은 경우 학습자에게도 보인다. 강의 중에는 필요할 때만 연다.

## 강의 단계

**Scene 01 — 명령 한 줄로 프로그램에 어떻게 일을 부탁할까? (13단계)**

| 단계 | 그림 | 내용 |
| --- | --- | --- |
| 1–2 | F1 비교 | GUI / CLI |
| 3–7 | F2 구조 | 명령 전체 → `python` → `-m todo` → `list` → `--limit 5`(옵션) |
| 8 | F3 흐름 | 같은 명령이 Python이 읽는 부분 / todo가 받는 부분으로 갈라지고, 넘겨줌 화살표 1개 |
| 9–10 | F4 흐름 | argparse ①→②→③, 그리고 ‘여기까지 argparse’ 경계 |
| 11 | 이해 확인 | 질문 3개, `답 보기` |
| 12 | 적용 | 같은 명령에서 `답 보기` → `--limit 3`, 바뀐 칸 하나만 강조 |
| 13 | 정리 | F2+F3를 합친 명령 구조 + 한 문장 정리 + 다음 장면 질문 |

**Scene 02 — 프로그램은 왜 역할을 나누고 여러 파일로 만들까? (17단계)**

하나의 2×2 구조도가 단계마다 바뀐다. 네 역할은 모든 단계에서 같은 자리에 있다(왼쪽 위 Model, 오른쪽 위 Repository, 왼쪽 아래 Service, 오른쪽 아래 CLI).

| 단계 | 그림 | 구조도의 변화 |
| --- | --- | --- |
| 1 | F1 관계 | 점선 말풍선 4개 + 가운데 부탁 `list --limit 5`, ‘순서표가 아닙니다’ |
| 2–6 | F2 구조 | 말풍선 → 역할 이름. 전체 → Model → Repository → Service → CLI, 옆에 todo 예시 |
| 7–9 | F3 비교 | 상황 질문 → 저장 형식 변경: Repository / 표시 변경: CLI에 ‘먼저 볼 곳’ |
| 10–12 | F4 구조 | 같은 자리에 파일 이름, 폴더 `todo/` → 파일 한 장 = 모듈 → 폴더 = 패키지 |
| 13 | F5 관계 | `cli.py`–`services.py` 사이 점선(화살표 없음) + ‘실행 순서가 아닙니다’ |
| 14 | F6 흐름 | `__main__.py` 줄 등장, 옆에 실제 실행 흐름 ①→④(이 장면 유일한 화살표) |
| 15 | F7 구조 | 같은 자리, **실제 사례 · ledger/** 라벨과 갈색 테두리, 따로 둔 파일 4개 |
| 16 | 이해 확인 | 질문 4개, `답 보기` |
| 17 | 정리 | 역할 + 파일 이름 + `__main__.py`를 한 그림에 + 한 문장 정리 |
