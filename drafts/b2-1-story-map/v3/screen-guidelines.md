# v3.1 대면 강의 화면 기준

2026-10-24 · Scene 01·02 보정. 실제 강의 시간·학습 효과는 시범 운영 전 미검증이다.

## 정보와 강조

- 핵심 그림이 가장 큰 영역을 차지한다. 그림 아래에 **현재 개념 한 문장**을 표시하며 별도의 고정 요점 세 개·긴 설명 패널은 없다.
- 학습 질문 하나는 제목에 유지한다. 이해 확인 질문 두 개(기본1·새 상황 적용1)와 한 문장 정리는 **Scene 전체 마지막 단계에서만** 표시한다. A 화면 끝은 장면 끝이 아니다. 이전 단계로 돌아가면 다시 숨긴다. 답도 마지막 단계의 선택 보충에서만 연다.
- 기본 화면에는 긴 Python 코드·함수 목록·실행 로그·세부 추적이 없다. 한 번에 새 전문 용어를 하나씩 설명한다. 예외·구현 한계·공식 목표 유보는 강사 노트로 이동하되 실제 예시의 출처·가상 여부는 상단 문맥 라벨에 표시한다.
- 명령은 실행 도구 / 실행할 프로그램 / 할 일 / 조건 네 블록을 유지한다. 기술 용어는 작은 보조 라벨로 두고 argparse는 마지막에만 추가한다.
- 책임 그림은 모델·저장소·서비스·CLI를 같은 중요도의 블록으로 두며 번호·실행 화살표를 쓰지 않는다. 선택한 책임만 굵은 테두리·선택 글자·색으로 강조한다. 비선택 글자를 흐리게 지우지 않는다. 단순 hover가 다른 책임의 선택처럼 보이지 않게 한다.

## 화면과 강의 단계

| 장면 | A | B | Scene 총 단계 |
| --- | --- | --- | ---: |
| 01 | GUI/CLI 비교 2 | 네 블록4 + argparse1 | 7 |
| 02 | 네 책임4 + 변경 상황2 | 모듈·패키지·import·시작 파일4 | 10 |

이전/다음과 좌/우 방향키는 A/B 경계를 넘어 순서대로 이동한다. 첫 단계의 이전과 마지막 단계의 다음은 비활성화한다. A/B 버튼은 해당 화면의 첫 단계로, Scene 버튼은 해당 장면 첫 단계로 이동한다. Home/End는 **장면 전체**의 처음/마지막이다. 이 번호는 강의 진행이며 실행 순서가 아니다.

## PC

1280×720, 선택 보충/강사 노트 닫힘을 기준으로 **모든 기본 단계의 문서 높이≤720px**, 페이지 가로 넘침0을 확인한다. 그림은 폭 대부분을 쓰고 설명은 아래에 둔다. 명령4블록은 가로, 책임4블록은2×2, 패키지의4모듈은 가로다. 제목 약30px, 명령34px, 책임28px, 현재 설명22px를 기본으로 한다. 좁은 화면·확대에서는 내용을 자르지 않고 자연스럽게 재배치/스크롤한다.

## 모바일

390/360px에서 명령2×2·책임세로·모듈2×2로 재배치한다. 그림 다음 현재 문장·조작부를 세로로 둔다. PC 전체 그림을 작게 축소하지 않는다. 본문/보조 설명16px 기준, 명령24px, 책임25px, 현재 문장20px. 블록 이름과 --limit 5는 읽기 어렵게 분리되지 않도록 실제 화면을 확인한다. 누를 영역 최소44px, 페이지 가로 넘침0. 복습용 세로 스크롤을 허용한다.

## 조작·접근성과 강사 보조

실제 button, aria-pressed, 보이는 focus-visible, aria-live=polite 현재 설명을 쓴다. Tab/Shift+Tab과 Enter/Space로 선택하고, 강의 영역에서만 좌/우·Home/End를 처리한다. 입력 요소와 modifier 조합, 보충 자료 읽기에는 단축키를 가로채지 않는다. 같은 화면의 단계 변경은 초점을 유지하고 화면 전환은 질문 제목으로 초점을 옮긴다.

자동 재생·장식 애니메이션·외부 API·가짜 실행 결과는 없다. GUI 그림의 선택은 요청 방법 비교 강조, 상황 선택은 먼저 볼 책임 강조다. 실제 todo/ledger를 실행하거나 바꾸지 않는다.

강사 노트에는 처음 던질 질문, 가리킬 순서, 꼭 말할 세 문장, 예외·혼동, 다음 연결을 둔다. __init__.py는 선택 보충에만 두며 클래스 문법으로 확장하지 않는다. 화면 낭독기·실물 기기·프로젝터·200% 확대·실제 강의 효과는 수행 여부를 별도로 기록한다.
