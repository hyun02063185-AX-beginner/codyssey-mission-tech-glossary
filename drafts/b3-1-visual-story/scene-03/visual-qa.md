중간 실행에서 고친 것:
- SG → ENI 점선이 EC2 제목 글자와 SG 설명 글자를 지나갔다. EC2를 담는 상자로 바꾸고, 점선과 제목 위치를 옮겼다.
- B 부분의 ENI 칸(폭 150)과 화살표 시작점이 맞지 않았다.
- 휴대전화 역할 카드에 같은 요소 ID가 두 번 쓰여 접촉 검사가 잘못된 상자를 봤다.
- 휴대전화 "Subnet에 연결" 라벨이 Route Table 상자에 걸쳤다.

**자동 검사가 놓친 것:** IGW 상자 안의 이름표가 상자 오른쪽 밖으로 나간 것을 렌더링 화면에서 발견해 고쳤다. 검사기는 이름표 상자가 부모 카드 안에 있는지까지는 보지 않는다(남은 한계).

## 3. 렌더링을 눈으로 확인

미리보기: `preview/desktop-1280.png`, `preview/desktop-1000.png`, `preview/mobile-390.png`, `preview/mobile-360.png`(2배), 검토 페이지 `preview/index.html`(Scene 01·02와 함께 표시).

| 확인 항목 | 결과 |
| --- | --- |
| 비교선이 통신 경로처럼 읽히는가 | 화살촉이 없고, 보라 점선과 양끝 마름모, "≈ 이름" 알약으로 표시했다. 초록 요청 화살표와 색·모양·위치(A/B 부분)가 모두 다르다. 범례와 각주에 "통신 방향 아님"을 적었다 |
| 비교선 교차 | 노트북용 7개 모두 수평이며 교차가 없다. 휴대전화용은 카드마다 짧은 세로선 1개다 |
| AWS를 장비처럼 그렸는가 | 라우터·방화벽·스위치 아이콘을 쓰지 않았다. AWS 쪽에는 케이블(회색 실선)도 쓰지 않았다(방문자–인터넷 구간 제외) |
| 설명자가 짚으며 발표할 수 있는가 | A는 위에서 아래로 비교선 7개를 차례로 짚는다. B는 두 줄의 흐름을 같은 세로 위치끼리 비교한 뒤 조건표 ①~④로 정리한다 |
| 복잡도 | 노트북용 1280 × 1904 단위로 길다. A만 보면 1280 × 1010 단위 정도다. 휴대전화용은 약 4.7화면이다 |
| 색만으로 구별하지 않는가 | 비교선(점선 + 마름모 + 알약 글자), 설정 연결(긴 점선), 미구현(점선 상자 + 문구), 흐림(범례 문구) |
