## 2. 정보 구조 — SVG 1장에 두 부분

지시서의 두 계층을 **한 SVG 안의 A·B 두 부분**으로 담았다. 파일 수는 장치당 1개다.

| 부분 | 질문 | 내용 |
| --- | --- | --- |
| **A 전체 구조 비교** | 같은 문제를 어떤 구성으로 해결했나? | 왼쪽 일반 기업망(구역 1~5), 오른쪽 B3-1 AWS(리전 ⊃ VPC ⊃ Public Subnet ⊃ EC2 ⊃ ENI·Nginx, IGW·Route Table·SG). 가운데 비교선 7개. 아래에 "같다고 보면 틀리는 점" 4줄 |
| **B 공개 웹 접속 비교** | 외부 방문자가 홈페이지에 접속하려면? | 두 줄의 요청 흐름(역할이 비슷한 칸을 같은 세로 위치에 둠), Route Table 카드(화살표와 연결하지 않음), 필요한 조건 ①~④ 표 |

**한 장에 둔 이유:** B의 조건표가 A의 비교선을 "왜 필요한가"로 다시 읽게 해 준다. 둘을 나누면 발표자가 파일을 오가야 한다. 다만 노트북용 높이가 1904 단위로 길다. Owner가 원하면 같은 생성기에서 A·B를 파일 둘로 나누는 것은 쉽다(승인 대기 2).

## 3. 선과 표식의 약속

| 표현 | 뜻 | Scene 01·02와의 관계 |
| --- | --- | --- |
| 회색 실선 + 끝점 원 | 장비 사이의 실제 연결(케이블) | 같음. **AWS 쪽에는 쓰지 않았다**(물리 케이블처럼 보이지 않게). 인터넷 구간의 방문자–인터넷만 예외 |
| **회색 점선** | AWS 설정상의 연결: IGW–인터넷(VPC에 연결), Route Table → Subnet(연결), Security Group → ENI(적용) | 새로 추가. 응답(갈색 점선)과는 색·간격이 다르다 |
| **보라 점선 + 양끝 마름모 + "≈ 이름" 알약** | 비슷한 역할(비교선). 화살촉이 없다 | 새로 추가. 통신 방향이 아니다(범례·각주 두 곳에 명시). 검사기가 비교선에 화살촉이 없음을 확인한다 |
| 초록 화살표 | 요청 방향(B 부분만) | Scene 02와 같음 |
| 흐림 | B3-1과 비교할 대상이 없는 일반망 구역(4·5) | Scene 02의 흐림("이번 흐름에 안 씀")과 뜻이 다르다. 범례에 이번 뜻을 따로 적었다 |
| 회색 점선 상자 | B3-1에서 구현하지 않음 | Scene 01의 "설명용 예시" 상자와 같은 모양. "AWS에서 불가능하다는 뜻 아님"을 함께 적었다 |
| AWS 색 | VPC(파랑), Public Subnet(초록), AWS 카드(파랑 테두리) | DMZ(황색)와 일부러 다른 색이다. 같은 개념으로 보이지 않게 했다 |

**AWS 쪽에 물리 장비를 추가하지 않았다.** IGW는 게이트 아이콘, Route Table은 표 아이콘, SG는 방패 아이콘이며 라우터·방화벽·스위치 아이콘을 쓰지 않았다. IGW는 VPC 경계선 위에 걸쳐 그려 "VPC에 연결된 구성요소"로 보이게 했다. SG는 Subnet 밖 VPC 안의 규칙 카드로 두고 ENI에 적용선을 그었다. "Subnet 전체에 걸린 방화벽"으로 보이지 않게 하기 위해서다.

## 4. 비교선 배치 — 교차 없음

일반망과 AWS의 요소를 같은 높이에 맞춰 비교선 7개가 모두 수평이고 서로 교차하지 않는다. 이를 위해 다음과 같이 배치했다.

- 방화벽 이름표를 NAT → 구역 사이 길 안내 → 허용·차단 판단 순서로 세웠다.
- IGW(인터넷 연결, 1:1 변환)를 위에, Route Table과 SG를 그 아래에 두었다.
- SG를 Subnet 위(VPC 안)에 두었다.

## 5. 휴대전화용

두 구조를 나란히 줄이지 않고 **대응 관계별 카드**로 나눴다.

1. A-1 실제 B3-1 AWS 구성(세로). 일반망 전체는 Scene 01 그림을 보도록 안내한다.
2. B3-1에서 구현하지 않음.
3. A-2 역할 비교 카드 7장: 일반망 요소 위, AWS 요소 아래, 보라 점선과 "≈ 이름", 한 줄 주의.
4. B3-1에 없음(구역 4·5).
5. 같다고 보면 틀리는 점.
6. B 두 열의 요청 흐름(역할이 비슷한 칸을 같은 높이에), Route Table 카드, 조건 카드 ①~④.

노트북용과 비교선 7개, 설정 연결 3개, 요청 흐름 9개, 미구현 4개, 조건 4개, AWS 요소 11개가 같다(검사기 확인). 길이는 360 × 3756 단위다(390px 화면에서 약 4.7화면, 승인 대기 3).

## 7. 편집 방법

`_tools/build.py`의 `COMPARE`·`ASSOC`·`MISSING`·`FLOW_*`·`CONDITIONS`를 고치면 두 그림에 함께 반영된다. `python3 -I _tools/build.py`를 실행한 뒤 `_tools/check.cjs`로 검사한다. Scene 01 생성기를 불러 쓰므로, Scene 01의 스타일을 바꾸면 Scene 03도 다시 생성한다.
