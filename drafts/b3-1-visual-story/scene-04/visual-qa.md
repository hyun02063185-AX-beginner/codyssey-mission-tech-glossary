중간 실행에서 고친 것:
- 휴대전화 C 영역의 참조 상자에서 이름과 "↑ B"가 겹쳤다 → 표식을 둘째 줄로 내렸다.
- 역할 노드의 보조 설명이 상자 밖으로 나갔다 → 휴대전화용 문구를 줄였다.
- 노트북용 15단위 글자를 16으로 올렸다.
- **검사기가 놓친 것 두 가지**를 화면에서 찾았다. 휴대전화 범례에서 "AWS 자원" 글자와 옆 견본 상자가 겹쳤고, B 영역의 "주소 변환"·"1:1 짝" 이름표가 맞닿았다. 범례를 두 줄로 바꾸고 이름표를 선 위로 옮긴 뒤, 이름표·견본 상자 겹침 검사를 검사기에 추가했다.

## 5. 교육적 QA — **미검증(사용자 검증 대기)**

실제 교육생 시험은 하지 않았다. 아래는 답의 근거가 그림 어디에 있는지만 확인한 것이다.

| 질문 | 근거 | 결과 |
| --- | --- | --- |
| 1. VPC와 Subnet은 어떤 관계인가? | VPC 영역 안의 Subnet 영역, "VPC 안에 포함" | 미검증 |
| 2. EC2와 Nginx는 어떤 관계인가? | EC2 영역 안의 Nginx, "포함 · 실행" | 미검증 |
| 3. Route Table과 Security Group은 왜 서로 다른 설정인가? | Route Table → "Subnet에 연결"·"경로 대상", SG → "적용"(ENI). 대응: 경로 선택 / 접근 통제 | 미검증 |
| 4. IGW와 Public·Private IPv4는 어떻게 연결되는가? | IGW —"주소 변환"— Public IPv4 —"1:1 짝"— Private IPv4 —"할당"— ENI | 미검증 |

| 6. 일반망의 세 역할과 AWS는 어떻게 비교되는가? | C 영역의 ≈ 대응선 3개, "같은 장비·서비스 아님" | 미검증 |
