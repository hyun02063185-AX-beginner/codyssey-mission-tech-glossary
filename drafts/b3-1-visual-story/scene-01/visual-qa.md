## 4. 기술 검증 요약

장비 역할, 구역 사이 연결, 단순화 표시, 지시서 §5 제약별 판정은 [terminology-review.md](terminology-review.md)에 있다. 모순 0건이며, 기존 승인 그림 0에서 수정을 권장할 점 2건을 보고만 했다.

선의 종류는 세 가지이고 모두 범례에 있다.
- 회색 선: 장비 사이 물리 연결. 통신 허용 여부와는 별개다.
- 색 면 + 번호: 논리적인 구역.
- 초록 실선 화살표: 실제 통신 방향(요청만).

기능 관계는 선 대신 이름표로 나타냈다.

## 6. 미검증·개선 필요

- 실물 휴대전화, 다크 테마의 웹 페이지 안 표시, 화면 낭독기의 `<desc>` 읽기, 흑백 인쇄.
- Pretendard 글꼴로 표시했을 때의 글자 폭(시스템 글꼴로만 측정했다). 폭이 달라지면 여유가 가장 적은 곳은 노트북용 NAT 카드와 휴대전화용 "내부 관리 서버" 상자다.
- 웹 가이드 안 실제 표시 폭과 노트북·휴대전화판 전환 방식(웹 통합 단계의 일).
- 900px 표시에서 노트북용 글자가 10.5~11.3px다. 개선 후보: 카드 글자를 줄여 가로 폭을 1144로 되돌리거나, 웹에서 1144px 이상의 넓은 그림 영역을 유지한다.
- RFC 1918·5737 원문 재대조, GPT 독립 콘텐츠 검토, Owner 시각 승인.
